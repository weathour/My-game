# 小怪、精英与 Boss 的镜头取景

日期：2026-11-06

状态：修复与工程验收完成。用户确认普通小怪攻击不必触发镜头取景变化，精英与 Boss 保留；此前复现、原因和局限见[镜头晃动诊断](../camera-mob-jitter-20261106/README.md)。用户当时的具体关卡仍不确定，尚无修复后的该场景实玩反馈。

## 已确认的修复范围

普通与重型小怪的预警、持续危险不再单独争用镜头的平移、缩放或安全点取景；场域精英和 Boss 保留原有取景与 Boss 震动规则，不新增精英震屏。真正属于存活精英或 Boss 的代理攻击应按实际攻击来源处理；普通召唤兵不能仅因有精英或 Boss 的父级就继承其镜头优先级。

当精英或 Boss 的危险确实需要搜索安全路线时，普通小怪已生效的危险仍须参与路线避让，不能将路线引向毒地等危险；这些普通危险本身不独立启动搜索，也不单独扩张镜头取景。攻击预警、碰撞、伤害、动画与存档不因镜头修复改变。
