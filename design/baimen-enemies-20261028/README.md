# 白门楼敌人美术

2026-10-29：白门楼 41 组敌人／对象素材与 8 组新特效已接入，源图、测量和输出哈希逐项复核；Godot 三尺寸、实际界面和临时 PCK 资源检查已通过。完整角色形象尚未由用户逐张审美确认，战斗数值与动作手感仍需人工体验。敌人职责、参数和应对见[敌人图鉴与战斗规格](../../docs/18_白门楼敌人图鉴与战斗规格.md)，程序和验收进度见[制作记录](../../docs/implementation/2026-10-28_白门楼敌人完整制作.md)。

## 范围与使用

本轮的 39 个角色／演出形象包括 12 名普通敌人、6 名特殊规则精英、18 关首领的形象、B10 右锁卫，以及高顺和陈宫的两种协同战相；这是美术口径，不是 39 种行为或 39 条首领血条。灯锚 D03 与待孵棺 D05 另有 2 套对象素材，共 **41 套新素材**。有限援军 D01 明确复用 E01，运行侧共 **42 个资源槽**；基础精英 L00 直接引用 E01，不再增加一套。

游戏路线节点详情中可选「查看敌情」，打开只读的敌情图鉴；在战斗节点可切换本关与全部敌人，查看立绘、动作预览、基础属性和应对提示。动作与效果使用当前选中的素材，缺失内容会标明临时状态。查看图鉴不推进路线或发放奖励。

41 套素材含 41 张立绘、804 个实际选用的独立源姿态、207 个动画片段和 828 个导出动画帧槽；灯锚与棺卵不适用的行为槽明确复用静态帧，**828 不是 828 个独立动作**。主体／立绘共 248 个 PNG 与 289 个 Aseprite 文件，未计下述特效。

本轮另制作八组敌方特效：骨箭、冲锋尘、棺烟、号令印、治疗印、灯波、雷击与落罐瘴气；共 32 个帧槽、8 个 PNG 与 8 个 Aseprite 文件；并复用贾苇索既有横斩、突刺、横扫三组刀枪特效。预告形状与伤害判定由战斗逻辑提供，特效不得擅自扩大实际伤害范围。特效源图、提示词、测量及输出的哈希见[特效清单](effects/manifest.json)，既有素材参考见[特效来源盘点](vfx-reuse-audit.json)。

## 来源与文件

- 敌人与对象的源图及提示词按 ID 保存在 `characters/<ID>/`，各自的 `export-manifest.json` 记录选用来源、切分和导出；不同批次的源图或修订命名不完全相同，以各自记录为准。
- 使用内置 ImageGen 制作图像源，由 Aseprite 进行测量裁切、调色、配准和动作导出；最终运行素材与可编辑文件位于 [`assets/enemies/baimen/`](../../assets/enemies/baimen/)。动作依具体角色包含待机、移动、攻击、特殊动作与受击；有额外动作时以各自清单为准。
- 曹休、曹纯、张辽、吕布、高顺与陈宫的脸部、头冠和代表色从现用[具名人物肖像图集](../../assets/ui/chronicle/cards/named-transparent.png)寻找身份线索，再发展各自异形战相。该图集是 ImageGen 生成的临时肖像，造型参考《火凤燎原》，并非逐人已获用户批准的专属人物母版；其来源及发行授权核查／替换边界见[人物卡面说明](../../assets/ui/chronicle/cards/README.md)和[图集清单](../card-rarity-20261027/manifest.json)。参考图集不代表已取得相应发行授权。
- [视觉接口](visual-api.md)定义运行资源、动作与锚点规则；[总体清单](manifest.json)、[生产状态](production-state.json)和各 ID 的清单记录制作范围、哈希与复用关系。源图、透明导出、动作帧及复用关系以总体清单和各自导出记录为准。
