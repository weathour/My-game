# 贾苇索诸侯战斗形象与亲征制作

日期：2026-11-05

状态：用户确认的亲征 v2 战斗形态已制作接入，专项、包内和完整工程检查通过。亲征版 v1 因用户认为档次不够高、像小兵而否决；常备版 v1 尚未获得用户评价，不纳入本轮制作。

起家成功后，可以按场合考虑不同着装：巡视、出行和遭遇突袭时的诸侯常备服，以及正式出征的亲征军装。用户本轮确认并授权制作的是亲征形象；常备服仍为未评价的提案。

## 人物依据

沿用约 27—30 岁的贾苇索身份母版：黑色高束发与红带，短胡茬，精悍而带几分痞气。[现有诸侯立绘](../jia-weisuo-20261027/jia-lord-smirk-v1.png)中的深绛锦袍、黑纹金边、小冠、玉佩、腰间小苇索结和佩刀，是服装延续的主要依据。人物与既有各形态见[形象素材记录](../jia-weisuo-20261027/README.md)。

| 方向 | 适用场景 | 服装与轮廓 | 战斗气质 |
| --- | --- | --- | --- |
| 诸侯常备 | 城内巡视、外出和突然遇袭 | 深绛锦袍保留织纹与质感，配小冠、收袖护腕和开衩袍摆；可在袍下藏轻甲。腰间留小苇索结，佩刀突出。 | 动作轻快，起手利落、收势有余裕，仍带熟悉的痞气。 |
| 诸侯亲征（v2 已确认） | 正面领军、正式征战 | 凤翅将盔配双赤翎，金饰兽首肩甲与胸甲、层叠鳞甲战裙、长绛红披风和雕饰长枪。沿用红、黑、金配色，保留贾苇索的脸、短胡茬、红发带、小苇索结和玉佩。 | 借鉴项目吕布的威势与赵云式英武、利落的枪将轮廓；动作可沉稳有力，出枪和转身带出甲胄与披风的余势。 |

常备服是可以随时应战的正式外出装，与现有[浅色宽袍居家立绘](../jia-weisuo-20261027/jia-casual-laugh-v1.png)分工不同：后者更适合放松、生活场景。两套诸侯服均不沿用起家时的破衣和巨大绳圈；亲征的新设计可以使用更醒目的翎饰和宽肩甲，仍须保留贾苇索本人的面貌与辨识点。

## 战斗表现边界

常备候选以佩刀展示，亲征形象以长枪展示；这只是形象展示重点。本轮制作的亲征形象须支持现有刀、枪装备，不以服装锁定武器。当前主角的自动普攻、J 横扫和 K 破阵沿用现有作用，造型本身不增加技能、数值或骑马设定。

后续可用重心变化、武器轨迹、衣摆或披风与简短刀光，呈现亲征发力；命中与敌方预警应保持可辨。避免新增满屏持续辉光，以免遮挡战斗并增加持续绘制负担。像素画面需保留亲征服装的主要轮廓与人物识别点，动作是否成立以实际制作和检查为准。
