# 白门楼战役原型

Godot 4.6.2 实时肉鸽游戏：玩家操作固定主角贾苇索，携带最多两名可切换的辅助，在征战、人物收集和培养中推进三国鬼城战役。游戏正式名称尚未确定。

## 当前范围

白门楼包含 36 个路线节点、18 个战斗节点，单次路线经过 12—15 场战斗；主角与 37 名可收集人物已有初版战斗定义和档案。22 个主线／泉水／战后剧情承载点、32 场人物故事、48 条条件短反应及 17 条地点器物资料已接入。18 个战斗节点使用六种地面主题；战斗含命中、盾挡、击杀、拾取与升级反馈，配乐和短音效已接入。具体内容与测试状态见[当前状态](docs/08_当前实现状态与后续重点.md)。

玩家从单人开局，首关胜利后先完成选卡，再进入艾玛剧情；她在剧情结束后加入，其余人物通常须先达成剧情入池条件，再通过选卡获得。关间可从符合条件的已获存活人物中配置辅助。战斗只在当前小关失败时回到进关前，已取得的此前成果保留。

## 运行

在仓库根目录用 Godot 4.6.2 打开 `project.godot` 并运行，从标题选择“启程白门楼”。界面用 Tab／方向键、Enter、Esc 导航；战斗用 WASD／方向键移动，Q／E 切人，J／K 使用当前人物的关键技能，Esc 暂停。普攻、常规技能和攻击方向自动处理。

项目配置仍使用 `survivor_like` 兼容标识；正式进度使用 `user://chronicle_campaign_v1/`，与设置数据一起保留兼容。清理和迁移期间不得主动删除用户数据或因项目命名变化让已有数据不可见。
