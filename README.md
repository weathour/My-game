# survivor-like

Godot 4.6.2 实时肉鸽战斗原型，正在转向“固定主角＋两名辅助＋人物卡培养＋主线战役”的新设计。

## 当前阶段

白门楼主线已有 36 个路线节点、18 个战斗节点及主角与 37 名人物的初版定义；单次路线经 12—15 场战斗。敌人机制、美术及四名重点 Boss 的两阶段已接入，22 个剧情承载点和 32 场人物故事已有文本。全作通用与白门楼的 70 个配乐混音资产已接入，主观听审待完成。默认三角头像 HUD，可选三行版；旧版战斗保留独立入口。范围和验证见[当前状态](docs/08_当前实现状态与后续重点.md)。

- [当前设计共识](docs/00_当前设计共识.md)：已定规则、未定边界与被替代方案。
- [当前状态](docs/08_当前实现状态与后续重点.md)：实际完成范围、风险与下一步。
- [文档索引](docs/README_文档索引.md)：按设计、运行基线和证据分类。

新设计保留一个强近战主角，配置至多两名可后台帮助也可直接操作的辅助；开局单人，首关后艾玛直接加入；人物卡和战斗经验培养人物，技能到等级自动解锁。每小关有可绕开的四角场域，必须击败Boss才通关，关末抽人物卡。人物持有收益、装备与主线进度构成长远选择；状态跨关延续，失败回到进关前状态。

主线采用三国背景和两层地图：天下图查看州域、局势和战役；区域路线图沿小关、精英与事件走向最终 Boss。一次大战役对应一次出征，阶段行动有限。随行人数无限，关间可从全部符合战役条件的人物中更换两辅助；返营全员恢复。首战为白门楼鬼城，已配置路线，后续战役仍在设计。

## 运行新界面与旧版战斗

在仓库根目录用 Godot 4.6.2 打开 `project.godot`，直接运行即可进入新界面（`scenes/chronicle/chronicle_shell.tscn`）。标题选择“启程白门楼”，击败首领并完成事件和选卡推进。新正式存档位于 `user://chronicle_campaign_v1/`，与旧版和界面演练档隔离。详见[当前状态](docs/08_当前实现状态与后续重点.md)。

新界面操作：Tab/方向键导航、Enter确认、Esc返回；真实战斗使用WASD/方向键移动、Q/E切人、J/K关键技能、Esc暂停。标题中的“旧版战斗”进入 `scenes/main_menu.tscn`，与新行军档案互相独立。

新战斗普攻、常规技能和攻击方向自动，关键技能手动，关内不需要鼠标。以下是**旧版战斗入口**的默认操作：

| 操作 | 默认输入 |
| --- | --- |
| 移动 | WASD |
| 鼠标跟随模式下瞄准 | 鼠标 |
| 自动索敌／鼠标跟随 | Tab |
| 切换角色 | Q / E |
| 大招 | R |
| 手动模式的技能槽 | 1–6 |
| 技能自动／手动切换 | Ctrl＋技能键，或右击技能槽 |
| 同角色技能槽排序 | 拖拽技能槽 |
| 人物面板 | C |
| 营地／教学交互 | F |
| 暂停 | Esc |

旧版战斗菜单还包含设置、存档、成就、开发者工具和旧 14 曲音乐鉴赏；挑战模式仍关闭。新主线的音乐鉴赏可从标题、菜单或设定进入，收录本轮 70 个混音资产。旧版详细差距见[重构前运行基线](docs/implementation/2026-10-26_重构前运行基线.md)。

## 获取与检查

只需当前 `main` 版本时，可用浅克隆减少历史下载：

```bash
git clone --depth 1 https://github.com/weathour/My-game.git
```

也可[下载 main 的 ZIP](https://github.com/weathour/My-game/archive/refs/heads/main.zip)，ZIP 不包含 Git 历史。普通完整克隆仍会下载历史对象；即使当前文件树删除旧证据，旧提交里的文件仍在历史中。

当前文件树保留运行资源、制作母版及精选证据；部分旧截图、回放和派生预览已移入本地归档，可从旧提交恢复。历史制作记录的截图数量反映当时验证范围，当前仓库不保证包含全部原图。整理范围见[资源审计](docs/implementation/2026-10-31_资源体积审计与公开仓库同步.md)。

运行代码位于 `scripts/`，场景位于 `scenes/`，敌人/特效/运行素材位于 `enemies/`、`effects/`、`assets/`；制作源档在 `design/`。入口见[工程架构](docs/02_工程架构与代码入口.md)。

代码改动后按 [AGENTS.md](AGENTS.md)执行检查；完整项目检查：

```bash
./scripts/check_project.sh
```

纯文档改动可执行：

```bash
python3 scripts/tests/check_docs_links.py
git diff --check
```

完整检查包含旧运行版本的行为合同，其通过不代表新规则已经实现。Graphify当前缺少GDScript提取能力，旧图已标过期，详见[工具说明](docs/GRAPHIFY.md)。
