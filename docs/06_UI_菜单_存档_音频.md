# 界面、存档与音频

规则见[设计共识](00_当前设计共识.md)，实际完成情况见[当前状态](08_当前实现状态与后续重点.md)。

## 主要界面

标题按主要操作、资料鉴赏和系统入口组织：有自动档时提供继续行军，并可启程、读取存档、查看敌情与音乐鉴赏。标题读档只读取；行军菜单中的行军档提供保存和读取。标题 Esc 打开退出确认，子页返回其来源；敌情和音乐鉴赏关闭后回到入口，音乐恢复此前播放状态。调整与验证范围见[菜单记录](implementation/2026-10-31_标题与行军菜单调整.md)。

天下页展示地区、局势和可参加战役；区域路线按真实连接展示分岔与合流。查看节点不推进，确认前往才进入剧情或整备。战斗、精英和终战节点可查看敌情；整备展示主角、至多两名辅助、人物可用性和全队共享装备。

人物详情区分前台、后台与持有能力；阵亡、未获得和战役禁入必须清楚。战斗 HUD 默认当前头像居中抬高、切换目标位于左右，可选三行队伍状态带，实际队伍不足三人时不补造角色。战斗预警、受伤与盾挡、关键技能及精英收益须清楚表达；精英收益在本关胜利后兑现。

剧情以场景、透明立绘和逐句对白呈现。首玩和只读回顾可查看本段已显示的对白，不泄露未来句。见闻提供符合条件的人物故事及资料；多个故事支持各自断点，已读回顾与资料不重新触发奖励。主线短反应按首次进入时的条件确定，续读与回顾沿用相同上下文。

## 存档和设置

正式档位于 `user://chronicle_campaign_v1/`，包含自动及手动槽。战斗中退出恢复本关进场前；已获胜但未选完的奖励恢复原候选和已选进度，不重复发奖。手动读档恢复该档全部进度与人物状态。写盘失败提供重试或返回，不以半提交状态覆盖有效存档；临时文件与主备恢复共同保护数据。

维护现有正式档与设置兼容，迁移验证用隔离副本；仓库清理不主动删除用户磁盘上的旧数据。更换项目展示名或用户数据路径前须验证原路径仍可读取。

## 输入和声音

菜单用 Tab／方向键、Enter、Esc；战斗用 WASD／方向键、Q／E、J／K 与 Esc。普攻和方向自动，关键技能手动。当前键位编辑能力以设置页面为准。

主线音乐按标题、地图、剧情、战斗和 Boss 阶段切换；音乐鉴赏展示曲名并支持播放与拖动。战斗短音效按实际事件播放并限频，减闪、减震、音量、静音和暂停需与表现同步。现有配乐生产来源见[音乐制作说明](../design/music-20261030/README.md)；技术检查不代替主观听审。
