## 界面要表达的信息

| 场合 | 需要表达 |
| --- | --- |
| 天下图 | 全部州或大模块的宏观地图；点击查看区域与战事信息、天下局势和可参加的大战役。 |
| 战役区域图 | 在地理背景上连续展示本次战役的节点与真实连接，标明当前节点、查看选中节点、可走前路、已通关及未走分支；左下呈现选中节点详情，右侧列出前路和主要操作。未解锁和暂未开放的节点可查看信息，但不能前往。 |
| 关前与关间整备 | 主角、至多两名已选辅助、全部已拥有人物的可用性和战役禁入原因；显示独立生命／魔法／阵亡状态与全队共享护甲／武器／饰品3槽装备。无随行人数上限，辅助空位合法；开局两槽为空。 |
| 人物查看 | 等级、经验、技能与解锁；分别说明人物机制、前台、后台与持有能力，未持有仅作入手等级预览。候补冻结状态，存活人物升级回满资源，阵亡人物不会因升级复活。 |
| 战斗HUD | 当前操作角色、主角的生存状态、两辅助的状态、当前角色关键技能的按键/耗魔/冷却与可用性、公共切换冷却、Boss出现进度与限时奖励条件。双形态首领显示当前形态、阶段与变身状态。默认当前头像居中抬高、切换目标在左右下方的三角布局，可选三行队伍状态带；单人和两人只显示实际成员，阵亡头像保留且切人时跳过。门槛与限时规则在关前／暂停查看，吕布独战有对应说明。 |
| 四角场域 | 普通遭遇显示本处收益与挑战、是否已选择、其他场域失效状态；B18 独战没有场域。 |
| 通关结算 | 普通五选二、抽卡精英成功五选三；B18 章末七选三且至少两张重要候选，无新增精英名额。旧档已生成七选四仍保留。先结清本关剩余经验与升级结果，并显示新获得／重复升级与各项收益。首关完成选卡后进入艾玛剧情，她在剧情结束后直接加入并入池，不占选卡名额；章末仍先完成影响开池的相关剧情，再生成候选。 |
| 剧情演出 | 场景背景叠加透明人物立绘，底部对白框按句推进；显示说话者姓名并突出其立绘，旁白不虚构姓名。表情姿态可随内容变化，转场与音乐由事件安排；素材和视觉效果以实际制作及验收为准。 |
| 历史对白 | 首玩与剧情回顾均可上滚或通过入口打开当前段历史，舞台保留并暗化；依次显示已读句、当前句已显示部分及对应发言人或旁白，不显示后续句。历史只读、不可跳转，关闭后回到原句与原显示位置。 |
| 剧情回顾 | 从当前存档已完成且有正式脚本的事件、泉水或指定战后剧情节点进入，路线详情和见闻均提供入口。标明回顾状态，从首句按句观看，可结束并返回；不显示重新发放人物或开池的结果提示。 |
| 泉水与路线 | 回复/复活结果、可前往的下一关、不可返回的已通关节点。 |
| 失败 | 回到进关前状态的结果，不能把当前小关未保留收益显示成已入库。 |

天下图与战役区域图两个地图层次已确定。此前框架使用上方导航、中央地图、右侧行动和下方队伍带；依[兰斯10逐页研究](design-reviews/2026-10-27_兰斯10界面结构与信息减法研究.md)进行的重排覆盖人物卡、编队、奖励、行装、地图与菜单。这套固定框架不是所有页面的规范。

整备上方为固定主角及两辅助位，下方为人物卡库；拖卡可上阵、替换、换位或拖回卡库移出，键盘也可拾卡、选位、放下和取消。预览名称旁只有一个「详情」入口，原位弹层内查看能力、属性·成长与人物；不再在人物详情里设置辅助位／候补操作。无效或取消拖放不提交，保存失败回滚；具体实现与验证见[本轮记录](design-reviews/2026-10-29_整备拖卡与人物原位检视.md)。

区域路线连续展示 36 个节点及真实连接，分岔与合流按数据展开；地图保留拖动、滚轮、悬停、键盘选择和定位当前。节点类型图标与状态分别表达，已通过、可前往、尚未解锁、未走支路、待选奖励与暂未开放有文字说明。用户认为此前地图界面过于简单，现已依[主页面逐模块复核](design-reviews/2026-10-29_兰斯10主页面逐模块复核与重排.md)重新组织章节、局势、人物、地图、任务说明、前路和底部队伍；新布局去掉图例、重复目录及「来自／通往」列表。天下主屏默认显示地图，任务栏按需打开；右侧前路卡用于查看，确认「前往 · 节点名」才选择节点。三尺寸与只读检查范围见该记录；此前导航与图鉴的自动及渲染检查见[当时记录](design-reviews/2026-10-29_敌情图鉴与地图导航改版.md)，更早的路线测试保留在[历史记录](implementation/2026-10-28_横向战役路线图.md)。

战斗、精英和终战节点提供本关「查看敌情」，打开后可切换到全部敌人；菜单也可直接进入全部图鉴。图鉴显示分类目录、短说明和大幅立绘，在同一区域切换「立绘／招式」，「战斗情报」按需展开基础属性与应对。曹休、曹纯、张辽、吕布的图鉴已有「人形／战相」切换，并随形态展示对应描述与应对；三尺寸真实渲染与按钮、形态、只读交互 **704 项**通过，见[本轮记录](implementation/2026-10-29_Boss深化与双形态战斗.md)。编队与行装置于同一整备的页签内，返回时保留来源和战前整备上下文。图鉴与地图浏览不推进节点，不改战役进度、奖励或存档；此前图鉴的表现及验证见[当时记录](design-reviews/2026-10-29_敌情图鉴与地图导航改版.md)，主地图新布局另见上述逐模块复核。

待选奖励时须先完成选卡；已获胜分支的其他互斥道路显示为未走支路，其合流后继在选卡完成前仍显示尚未解锁。底层待结算期间保留的可选节点集合不直接等同于界面上可以前往的节点，也不因此改变存档或战役规则。

选择大战役后进入区域路线图，确认前往战斗节点后进入整备和实时战场，结算后回到路线继续；战役终战完成后返营并回到天下层。天下图点击信息不等于开始出征或消耗主线行动。取消为旧技能点、5/10级天赋选卡和108节点树预留强制入口。技能到等级自动解锁，不通过新的选卡弹窗替代旧弹窗。

文案应明确生效对象、条件、数值与消耗，不提示所谓正确养成顺序或推荐最优答案。操作提示与规则说明仍然需要清楚，不能把“不教玩家如何权衡”理解为隐藏必要信息。关键状态不能只靠颜色或悬停传达。

编队摘要区分全体已持有人物的数值加成、已配置辅助的后台支援及三槽装备的作用对象和触发条件；阵亡人物的持有加成保留，其后台支援停止。换人或装备后同步刷新，演练夹具不显示伪造的实战数值；详细数值来源可查看，960 宽时长内容允许滚动。人物卡保留独立稀有度标识，不能以颜色或稀有度替代开池、保底说明；此前稀有度及摘要的检查见[当时记录](implementation/2026-10-27_人物稀有度与编队加成.md)，当前编队布局见上述本轮记录。

女性角色相关氛围现与征战并列成为核心体验，直接参考《兰斯》的成人冒险与人物事件风格，详见[背景与人物事件](16_世界背景与风格.md)。上述剧情演出形式已经获得用户确认；本轮先使用现有常态立绘，整体实现与视觉验收情况见[状态入口](08_当前实现状态与后续重点.md)。后续按实际事件安排会面、对白与返营呈现；不预设好感度条、礼物菜单、关系行动点或完整恋爱系统。

## 存档语义

后续实现至少要区分以下状态；此处不决定文件拆分、字段名或schema版本。

- 已提交的主线成果：已获得人物及等级、已完成的剧情开池条件与人物抽取资格、可保留装备、已通关节点和路线进度。人物入池和实际拥有是不同状态。
- 天下与出征状态：当前主线阶段、已结算行动、可参加战事、当前战役与路线、人物禁入条件及本关两辅助配置；不保存有限随行名单或满员驱逐状态。
- 关间状态：人物生命、魔法与阵亡状态、当前配置，以及恢复事件的结果。
- 进关前快照：本次失败时恢复的依据，不得被关内临时收益覆盖。
- 关内尝试：经验和掉落等尚未成功带出的收益、场域选择、战斗进度与角色临时状态。
- 待完成的成功结算：人物卡抽取、额外奖励和推进结果，须能够恢复且不得重复授予。

失败或战斗中退出撤销本次尝试，回到本关进场前，保留此前成功关卡成果，不额外消耗主线行动。胜利待结算恢复同一候选；手动读旧档则整体恢复该档的主线状态，详见下方。主动放弃、未生成结果的随机与旧档迁移另定。

可复用的工程经验包括原子写盘、主备恢复、提交成功后再更新界面、奖励幂等、暂停原因分离。旧实现仍有“小Boss奖励恢复后再次退出覆盖候选”的已知问题，详见[已知问题](KNOWN_ISSUES.md)；新保存流程不能把已有基础等同于新规则已验证。

首关先按进场名单结清经验，再生成并完成普通五选二；抽卡精英成功时保留五选三，同样先完成选卡。随后进入艾玛剧情，剧情结束后才提交艾玛获得与入池，新流程生成的首关候选没有她。旧档已生成候选按原组保留，不为套用新顺序而重抽。读档不能重复赠送艾玛或把赠送再次算成升级。恢复到赠送前的旧档时按整份快照恢复，依当时进度继续完成选卡和剧情。剧情按事件和稳定句 ID 保存阅读位置，加载可回到该句；推进保存失败时停留本句并允许重试，完成或跳过后提交事件结果并清除断点。

已完成节点的剧情回顾是只读观看：从首句开始，不记录回顾位置，也不修改正式剧情断点、当前节点、人物与资源、奖励、路线或行军日志，不触发原事件结算或写盘。待选奖励期间可从见闻进入回顾，返回后仍保留原组候选与已选进度。回顾使用当前版本脚本及其背景、立绘和音乐，不改变首次观看的保存与结算规则。

阅读当前段时，上滚打开“历史对白”并定位到最新内容，继续上滚查看更早的句子；下滚至底部后再次下滚返回。打开时暂停当前句打字，关闭后恢复原句和已显示位置；Esc、右键、返回按钮、Enter 或 Space 均只关闭历史，不推进对白。PageUp 可打开历史，打开后 PageUp／PageDown／Home／End 用于浏览。调整窗口时保留本次历史面板状态、滚动位置和打字进度。历史不保存、不修改正式断点或结算效果，读档到中句按当前脚本重建此前句子。

## 本作存读档方式

用户要求存档机制参考《兰斯10》，并确认当前退出续玩方案。按多个手动档加自动续档落实；允许读回旧档尝试另一条发展。自动保存与手动槽分开，不能自动覆盖玩家另留的手动档。槽数、分页和命名方式属于界面实施细节，暂不锁定。

| 保存位置 | 恢复结果 |
| --- | --- |
| 天下图、路线、关间整备与剧情节点 | 恢复到对应进度、人物状态和配置；剧情的具体可恢复断点随事件制作明确。 |
| 尚未获胜的实时战斗 | 恢复本关进场前状态，不保存怪物、弹幕和战斗进行到一半的现场；本次尝试的经验、升级回血、拾取和场域选择均撤销。 |
| 已胜利、候选已生成但尚未完成选卡 | 恢复同一组候选与选择进度，不重新抽候选，不丢失已完成的精英收益，也不重复发奖。 |
| 已确认奖励或已经返营 | 恢复提交后的等级、卡牌、装备、剧情及路线状态，不再次领取该节点收益。 |

B06、B15、B16、B17 的胜利结算暂存至战后剧情完成，才开池并生成原规则的选卡；已有剧情断点可续读，B18 仍在相关剧情后生成章末候选。自动续档覆盖进关前、胜利待结算、奖励确认后及路线／剧情／恢复事件提交后的关键状态，以满足已定的逐关保留与退出恢复。具体写盘次数与事务拆分由实现设计决定，不把每一步都做成玩家可见弹窗。

读取旧手动档时，人物拥有、等级、生命魔法、阵亡、装备、开池资格、路线和战果整体恢复至该档时点。旧正式档按已完成节点补齐本轮新增入池资格，不赠送人物，不重掷已生成的候选，也保留已选进度。正式档schema仍为1，不迁移旧UI演练档。旧档之后的收益不叠加回来。因此“已过关不能回刷”约束当前进度中的路线，不禁止手动存读档或只读剧情回顾。回顾入口随当前存档的完成记录变化；当前段历史与跨节点、跨档的统一鉴赏记录分开，后者尚未提供。

本规则只固定恢复已生成候选时不重抽；读取更早、尚未生成候选的存档后随机结果怎样变化，留待随机规则确认，不扩大解释为禁止一切S/L。主动放弃出征与直接退出游戏不同，前者的战役和行动后果仍待确定。

参照核验：[《兰斯10》官方路线说明](https://www.alicesoft.com/information/2017/entry002328.html)同时描述路线只能向前和存读档查看另一分支的玩法，支持两者并存。发售时的[玩家存档记录](https://animalipartner.com/rance10/rance10-3/)确认手动与自动保存并存；本作自动保存时点以已定的实时战斗回退和逐关成果规则为准，不把该记录的版本细节直接照搬。

## 控制、设置与视觉

普攻、常规技能与攻击/技能方向自动处理；关键技能由玩家手动触发，可以有多个。关卡内游玩不需要鼠标，键盘即可完成必要操作。方向处理、移动、切人和技能按键应整体评估复杂度；不能用必须悬停、点击技能图标或鼠标点选目标的交互来补足战斗操作。

手动关键技能只调用当前角色，各角色复用同一组技能按键，切人后显示与输入同步切换。后台支援自行触发，不要求玩家同时操作三套快捷键。魔法仅用于手动关键技能；普攻、常规自动技能与自动后台支援不耗魔法。关键技能应明确区分魔法不足与冷却未完成的状态。

切换采用短暂公共冷却，保留独立生命、魔法和技能冷却，无通用无敌或技能刷新。后台继续冷却和回魔，生命需明确治疗或补给。每人最多2个手动关键技能已定；具体键位和公共切换冷却时长待实玩确认，支持重绑、焦点和显示适配。

主线地图保持苍凉的三国山河与人物主体；框和按钮参考《兰斯10》，采用墨绿底、旧金细边、局部角饰及酒红主按钮，先前一概禁止金属框和雕花的表述不再适用。战斗默认头像按旧版三角排列，HUD浮于战场上，三行版作为可选，详见 [DESIGN.md](../DESIGN.md)。现有四人主菜单插画不代表角色库上限，也不代表四人中任取三人的设定继续有效。

## 音频与发布

## 2026-10-27 实际运行

默认入口 `scenes/chronicle/chronicle_shell.tscn`；菜单使用 Tab／方向键、Enter、Esc，实战使用 WASD／方向键、Q／E、J／K、Esc。新 `battle_*` 动作暂未提供键位编辑页，旧版设置ID和键位保持。

正式档 `user://chronicle_campaign_v1/` 使用独立作用域，包含自动与三个手动槽；旧版、`chronicle_ui_v1` 演练档均不覆盖。战斗退出恢复进关前，胜利保存待结算，候选与选择续存，领取防重复；存盘失败撤销状态并保留胜利重试权。临时文件原子替换并保留有效上一代备份，完整精度JSON与经验单位规范化避免往返漂移。

第一版新行军生成独立奖励种子，当前六个战斗节点使用各自固定关卡种子；读取旧档沿该档的随机流继续。这是当前可调整策略，不改变“恢复已有候选不重抽”的要求。

### 战斗表现复用更新

此前的“底部技能栏”实际将头像横向排列，虽复用了头像等小组件，并未恢复旧版三角头像构图；该阶段验证与截图保留在[双布局实施](implementation/2026-10-27_简洁HUD与双布局.md)。现已按用户要求恢复当前头像居中抬高、切换目标左右下方的构图，HUD浮在全幅战场上并正确叠于怪物之上；三行队伍状态带仍为可选。战场几何、素材比例和新布局验证见[实施记录](implementation/2026-10-27_战场比例与三角头像HUD.md)，不把此前横排验证当作新布局验证。

此前原三行队伍栏、人物头像、HP／MP与冷却小组件已适配新会话，空位不重复显示主角，前台显示J／K、后台关键技能显示备。当时战场跟随当前人物，右上缩略图保留场域与敌人位置；暂停同时冻结动画与战斗。详见[复用记录](implementation/2026-10-27_战斗表现与HUD复用.md)。该阶段未改变正式存档结构。

当前战斗暂停后，如窗口大小或 HUD 布局改变，镜头会静态重算取景；战斗、动画与震动时钟仍保持冻结。
