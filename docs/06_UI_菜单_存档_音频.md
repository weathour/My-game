# 界面、存档与音频

规则见[设计共识](00_当前设计共识.md)，实际完成情况见[当前状态](08_当前实现状态与后续重点.md)。

## 主要界面

标题按主要操作、资料鉴赏和系统入口组织：有自动档时提供继续行军，并可启程、读取存档、查看敌情与音乐鉴赏。标题读档只读取；行军菜单中的行军档提供保存和读取。标题 Esc 打开退出确认，子页返回其来源；敌情和音乐鉴赏关闭后回到入口，音乐恢复此前播放状态。调整与验证范围见[菜单记录](implementation/2026-10-31_标题与行军菜单调整.md)。

天下页展示地区、局势和可参加战役；区域路线按真实连接展示分岔与合流。查看节点不推进，确认前往才进入剧情或整备。战斗、精英和终战节点可查看敌情；整备展示主角、至多两名辅助、人物可用性和全队共享装备。

人物详情区分前台、后台与持有能力；阵亡、未获得和战役禁入必须清楚。战斗 HUD 默认当前头像居中抬高、切换目标位于左右，可选三行队伍状态带，实际队伍不足三人时不补造角色。战斗预警、受伤与盾挡、关键技能及精英收益须清楚表达；精英收益在本关胜利后兑现。

人物页、关末选卡详情和整备后台简述使用同源技能说明。战斗两种 HUD 都可悬停 J／K 查看概要及当前状态，不会因此暂停；“行军暂歇”内的“技能说明”可用键盘选择人物、技能和展开细节。没有对应技能的槽位显示“未配备”。接入及验证状态见[技能说明记录](implementation/2026-11-06_人物技能说明与战斗查阅.md)。

怪群与弹幕升级后，当前操控角色的小红点对应真实半径 4 世界单位的受击圈；区域与冲撞预警与实际判定使用相同几何，普通可辨弹体不逐发绘制预警轨迹。拾取、攻击和推挤范围不随受击圈缩小。验证范围见[本轮记录](implementation/2026-11-03_怪群压力与Boss弹幕升级.md)。

剧情以场景、透明立绘和逐句对白呈现。首玩和只读回顾可查看本段已显示的对白，不泄露未来句。见闻提供符合条件的人物故事及资料；多个故事支持各自断点，已读回顾与资料不重新触发奖励。主线短反应按首次进入时的条件确定，续读与回顾沿用相同上下文。

## 当前战斗镜头与反馈

当前战斗画面通过画布的平移和缩放取景，HUD 单独布置，并非使用 `Camera2D`。用户确认普通及重型小怪危险不再单独推动镜头，精英与 Boss 保留；修复与工程验收已完成，详见[镜头修复](implementation/2026-11-06_普通小怪镜头取景修复.md)。

| 场景 | 当前表现 |
| --- | --- |
| 普通跟随 | 没有 Boss 和需要特别纳入的危险时，镜头平滑跟随角色脚底上方 20 个世界单位；不根据鼠标或移动方向提前偏移。 |
| 普通危险 | 普通及重型小怪的预警与持续危险不单独推动镜头取景或安全点搜索；攻击预警和伤害照常生效。精英／Boss 危险触发搜索时，普通小怪已生效的危险仍用于路线避让。 |
| 精英、Boss 与预警 | 抽卡／装备场域精英和 Boss 的相关危险保留原有取景；最近的存活、可锁定且有独立生命的 Boss 会纳入其当前身体与武器轮廓。镜头尽量同时容纳玩家、相关危险和可到达的安全点，上方、下方及两侧为 HUD 留出空间。极端跨度下优先保证玩家和安全出口，Boss 可能退为只保证锚点，不能保证任何距离都完整显示武器。 |
| 拉远与回近 | Boss 大招预警时会留出更宽视野，拉远比回近快；Boss 初次出现和变相时重新计算取景，不是固定特写。1280×720 下最远缩放约为原来的 0.45，72 世界单位的站姿参考身体约显示 32.4 像素。 |
| 震动与命中反馈 | Boss 区域招式释放、变相及最终击败可触发短促镜头震动；普通普攻不会触发全局震动。受击、盾挡和命中主要使用局部染色、弧线、轮廓或轻微后坐，没有因此设置全屏白闪或全局停帧。 |
| 暂停与结束 | 暂停时镜头和震动进度冻结；暂停中调整窗口会按新尺寸重新投影。切人不重置镜头；最终 Boss 击败后保留约 0.48 秒表现再清理，失败或退场时清理。 |
| 张辽协同 | 高顺的视觉冲阵和陈宫的独立视觉站位会临时纳入取景，必要时带来平移或拉远；模拟位置、伤害落点和预警不随视觉站位改变。 |

代码支持 `reduced_motion` 和 `reduced_flash` 两项舒适设置，默认均为关闭，保存在 `user://settings.cfg` 的 `comfort` 配置中；**当前正式设置菜单尚无这两项开关**。启用低动态效果时不震屏，同一 Boss 战中只按需要继续拉远、不随每招回近，高顺也不做额外视觉冲阵；减闪会降低部分效果的透明度，并非关闭所有特效。镜头平滑、缩放、前瞻和震动幅度目前没有菜单调节项，也没有鼠标、滚轮或按键的手动镜头控制。实现分别见[镜头](../scripts/ui/chronicle/boss_camera.gd)、[画布](../scripts/ui/chronicle/battle_canvas.gd)和[反馈](../scripts/ui/chronicle/boss_feedback.gd)。

## 存档和设置

正式档位于 `user://chronicle_campaign_v1/`，包含自动及手动槽。战斗中退出恢复本关进场前；已获胜但未选完的奖励恢复原候选和已选进度，不重复发奖。手动读档恢复该档全部进度与人物状态。写盘失败提供重试或返回，不以半提交状态覆盖有效存档；临时文件与主备恢复共同保护数据。

维护现有正式档与设置兼容，迁移验证用隔离副本；仓库清理不主动删除用户磁盘上的旧数据。更换项目展示名或用户数据路径前须验证原路径仍可读取。

本地测试包各自使用包内独立的 `test-user-data/` 保存测试进度和设置，与用户正式目录分开；测试进度不自动同步到正式档。最新声音设置测试包入口见[本轮记录](implementation/2026-11-04_战斗暂停与分类音量设置.md)，此前 D2 测试包见[接入记录](implementation/2026-11-04_中国器乐D2游戏接入.md)。

## 输入和声音

菜单用 Tab／方向键、Enter、Esc；战斗用 WASD／方向键、Q／E、J／K 与 Esc。普攻和方向自动，关键技能手动。当前键位编辑能力以设置页面为准。

战斗“行军暂歇”内可进入声音设置，分别调整总音量、音乐、音效总音量和八类音效；Esc 从设置页返回暂停菜单，再按 Esc 继续战斗。标题与行军设定页复用同一组设置，修改后自动保存；操作范围、分类和验证进度见[暂停与分类音量记录](implementation/2026-11-04_战斗暂停与分类音量设置.md)。

从暂歇进入技能说明后，Esc 先返回暂歇、战斗保持暂停；再按 Esc 继续战斗。该入口不要求使用鼠标。

音乐鉴赏目录包含 12 首全曲版本和 4 首保留旧曲，支持播放与拖动；各剧情和界面的分配见[第一章音乐对应表](implementation/2026-11-03_第一章音乐对应表.md)。十二首中国器乐 D2 已接入原有曲目位置，鉴赏页按音乐目录显示种类与场景；验证进度见[D2 接入记录](implementation/2026-11-04_中国器乐D2游戏接入.md)。战斗从所选整曲开头播放，曲终整曲循环；Boss 形态变化继续当前曲目和播放位置，胜利结算也延续战斗音乐。旧短音乐提示已停用；打击、技能、界面和预警等音效按实际事件播放并限频，减闪、减震、音量、静音和暂停需与表现同步。配乐来源见[音乐制作说明](../design/music-20261104-chinese-12/README.md)；技术检查不代替主观听审。

角色能力和敌方动作使用按角色、技能、敌人及形态配置的短音，区分实际施放、命中和需要提示的敌方预警；Boss 另有形态与击败提示。技能未成功施放或未实际命中时不伪造相应反馈，治疗、资源和护盾按实际增量触发。声音使用共享播放池、声像和距离增益，并按危险程度管理并发；一次性音效遵循音效音量和静音设置。覆盖范围及素材来源见[技能音效制作目录](../design/skill-audio-20261103/README.md)。
