# Boss 深化阶段诉求与整体方案

2026-10-29。用户授权的 Boss 深化阶段已按本轮范围完成。本页保留阶段目标、范围和完成判断；四名重点武将的机制、素材、图鉴和吕布独战已接入，四场回放及本机回归已完成。图谱保护更新已执行，因覆盖不足保留 STALE 旧图。设计基线、验证证据与用户审美／听感的反馈边界见[执行记录](../implementation/2026-10-29_Boss深化与双形态战斗.md)。

## 阶段目标与范围

以白门楼重点名将 Boss 为中心，让人物身份、两阶段战斗、夸张表现、队伍构筑和战役资源在完整关卡中共同成立。玩家应能辨认对手、读懂威胁、找到应对和反击机会，也能感受到培养与配队带来的优势；镜头、特效和声音与攻击设计一起服务这场战斗。

用户已明确：可入队的人形名将作为敌人时先以人形登场，打掉第一阶段再变身；吕布这样的最终大 Boss 入关即战、全程无小怪，包括自动刷出和召唤的杂兵；攻击范围和效果要大、夸张。难度采用**构筑与操作并重**：合理队伍配合读招走位能过，强队有明显优势。

本阶段完整制作 **B15 曹休、B16 曹纯、B17 张辽、B18 吕布**四场重点战；以吕布形成可玩的完整样板，再逐个完成其他名将。高顺、陈宫目前是 B17 不可锁定的协同演出源，需要协调其人形、战相与张辽阶段的身份关系，不自动变成三个独立 Boss 血条。其余首章首领按共同反馈、难度梯度与资源衔接回归，不强制 18 场都做双形态。

实施启动前，18 个战斗节点已配置开放，38 人有初版战斗定义、已有六件装备；名将直接以单一战相登场，B18 先刷普通敌人，按时间或击杀门槛出现吕布。这些行为本轮已由两形态与吕布独战取代；最新状态见[当前状态](../08_当前实现状态与后续重点.md)，其他敌人规格见[敌人图鉴](../18_白门楼敌人图鉴与战斗规格.md)。既有角色与装备作为首轮测试基础，仅修复测试暴露的技能、联动、索敌和数值问题；新战役、全地图重绘、全部人物专属美术与补齐所有规划装备留待后续内容工作。

## 六类成果要一起成立

| 成果 | 玩家体验与完成证据 |
| --- | --- |
| **身份与遭遇** | 四名重点武将的人形和战相可辨为同一人物，两相行为有差异；每场从进关到最终胜利形成完整遭遇。 |
| **招式与强度** | 大范围攻击有可辨预告、真实判定、安全路线和反击机会；通过实玩记录受击原因与不同攻击的应对。 |
| **配队与成长** | 控制、护盾、回血、咒伤和输出等能在合理搭配中发挥；普通成长队有机会取胜，强队的击杀速度或容错有明显优势。 |
| **动作与表现** | 两形态的动作、特效、声音和镜头共同呈现威势，画面不会遮挡操作依据；保留真实尺寸演示和素材审看证据。 |
| **战役衔接** | 阶段信息、图鉴、进关资源与胜利奖励一致；以真实 B17→B18 继承状态和实际结算检查，不能默认满资源。 |
| **可靠性与体验** | 转相不误发胜利或奖励；胜负、退出、暂停、重试与存档结算可靠，自动检查和人工实玩分别留证。 |

## 需要先处理的取舍

**完整变身与强队优势。** 第一阶段打空触发转相，完成第二形态才取得胜利。初版按人形／战相 40%／60% 分配总生命，第一阶段结束后有 1.0 秒安全变身、战相有 0.65 秒观察窗；过量和期间伤害暂存，观察窗后结算，标记、咒伤和友方已发攻击保留。安全变身时玩家免受战斗伤害，仍可移动、切人和用技能，旧 Boss 预告、危险区与敌弹取消；之后战相可行动。强队可以缩短两相交战、减少招式轮次，不强制演完固定轮次；细节须按[执行记录](../implementation/2026-10-29_Boss深化与双形态战斗.md)实现并实测。

**吕布独战与原有收益。** B18 取消所有战内场域选择与额外精英召唤入口，保留既有章末基础七选三及至少两张重要候选；不为取消精英补发额外名额，旧档已生成候选及已获收益保持。B17→B18 继承原有跨关资源，不默认回血回魔；战中经验总量和快胜收益仍需实测，不以额外刷怪补洞。

**大范围与现有操作。** 本作一名前台、最多两名辅助，普攻和常规技能自动进行，玩家负责移动、切人与每人最多两个关键技能，没有通用翻滚无敌或弹反。危险区、可达的撤离路线与收招反击须在实际镜头和最低合理移速下成立；不能让某张卡的位移或护盾成为隐性必需。日常取景保持稳定，预兆可适度拉远以容纳安全路，关键命中短促反馈，转相与真正胜利分别表达；高频普攻、后台支援和咒伤不持续震屏，HUD 与小地图保持屏幕层稳定。减少动态和闪光时仍保留功能性预警。停顿、慢动作涉及战斗时钟、冷却和声音，需要一起设计。

**人物与素材。** 人形母版、现有战相及未来入队形象应保留脸、武器和服饰等识别线索；入队能力不要求复制 Boss 的范围和强度。已有战相可作复用候选，尚未逐张得到审美批准。准备具体形态对照图供审看；透明源图、动作、按需头像、Aseprite 导出和真实尺寸／暂停审看按[角色战斗美术流程](../art/角色战斗美术制作流程.md)执行。

## 阶段推进顺序

1. **基线与设计包。** 按真实进关人物、装备与资源，明确四名武将的身份、战斗主题和两相差异。用统一招式条目记录意图、真实形状、预告与锁向、释放判定、收招、应对，以及动作、音效、镜头触发；将样板需要的阶段边界、胜利和终战收益选择细化到可执行。已有研究优先复用，只针对具体缺口补查。
2. **吕布完整样板。** 先用现有或清楚标注的临时素材贯通人形→变身→鬼神→胜利，加入一至两种代表性大范围攻击、取景和反馈，尽早试玩判定、安全空间与镜头。这是早期小样，不把少量招式当最终交付；随后完成吕布两相动作、特效、音效、阶段信息、图鉴、平衡与结算。镜头先基于现有画布做轻量样例，以 [Phantom Camera 等调研](2026-10-29_Boss镜头表现与开源方案调研.md)为参照，只有迁移确有收益时再引入完整插件。
3. **检验差异并完成其余重点 Boss。** 先用曹休的远射、机动与追猎空间检验样板能否支持不同对手，再处理曹纯的长冲与线路压迫、张辽主攻后高顺或陈宫协同及共同回气；这些是初步主题，具体招式待设计。每完成一名，都把程序、两相美术、反馈、数值、图鉴与验证接成完整一战，再扩展下一名。
4. **整章与构筑收敛。** 按真实取得的人物与装备，选择普通成长、成型强队、资源紧张和朴素未成型队等代表情境，覆盖追击、回响、护盾转换、咒伤四个既有方向；从暂定 8—12 套代表组合中挑有意义的样本，不机械跑全排列，也不使用尚未获得或战后才入池的人物。回归其他首领梯度与路线资源衔接。

不同队伍在每场 Boss 的收益不必完全相同。吕布独战下，应逐项核对传播效果和可能存在的击杀触发，检查基础输出或替代搭配能否发挥；不为群攻触发加入小怪，也不抹平单体与群攻差异。抽样检查控制和恢复是否造成永久限制或无代价续航；出现问题时优先局部调整触发、成本或窗口，不预设所有 Boss 免疫控制。

## 完成判断

四名重点 Boss 均完成从进关、两形态、战斗表现到胜负和结算的闭环；人物身份和两相行为可辨，合理的不同队伍能应对，强队优势真实存在。失败应能从读招、位置或资源消耗等方面解释，不因画外威胁或特效遮挡而无从判断。检查战场中央、边角及 960／1280／1920 像素宽画面的几何与可读性，记录每相耗时、受击原因、资源消耗、输出／支援贡献和视野问题；先积累样本再定目标区间，不预设通关率或秒数。

已沿两条 12／15 战连续路线及成熟护盾路线验证真实 B17→B18 资源继承，不改变已通过关卡不能回头刷的规则。正式胜利、失败、退出、暂停、重试、存档和奖励及镜头清理均纳入检查。Godot headless 与图谱保护更新已执行；图谱候选因覆盖不足被拒绝并保留旧图，见 [Graphify 说明](../GRAPHIFY.md)。四场真实录屏和吕布分段代理实际操控不等于用户实时试玩或主观审美、听感确认，详见[执行记录](../implementation/2026-10-29_Boss深化与双形态战斗.md)。
