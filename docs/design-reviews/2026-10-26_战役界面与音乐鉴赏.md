# 游戏设计评审：战役界面与音乐鉴赏

> 2026-10-26整理：本页保留当时的实现、问题或素材来源证据，正文中的“当前”“已定”“后续”指记录时点；不作为新体系要求或当前任务队列。目标以[当前设计共识](../00_当前设计共识.md)为准，新设计尚未实施。


## 0. 决策摘要

沿《兰斯10》的战役界面氛围重做全局 UI：深林绿与酒红底板、古金雕花框、衬线标题、中文无衬线正文，并保留项目自己的场景和角色画面。主页背景定为原创 `assets/ui/campaign/four_heroes_menu.png`，四位当前角色置于右侧，左侧留导航。主页增设音乐鉴赏，可直接浏览、试听现有全部 14 首原创配乐。视觉方向借鉴自[《兰斯10》官方系统页](https://www.alicesoft.com/rance10/system/index.html)，不复用官方素材、文案或玩法规则。

实际框架是接入在真实控件上的原创九宫拉伸 `Node2D` 装饰，不是界面截图或纯背景图。框架不参与布局尺寸、不截获输入。该轮改变表现，不改存档、战斗、AP、势力或既有游戏流程。

## 1. 范围与约束

### 范围内

- 主菜单使用原创 `assets/ui/campaign/four_heroes_menu.png`（1672×941），线性过滤并按比例 cover；左侧为真实导航，右侧为四位角色插画。旧 `assets/demo2.png` 保留为项目资源，但主页不再引用。
- 四人身份参考 `assets/players/` 中剑士、枪手、法师的当前待机图，以及机械师正式设计母图 `design/mechanic-rework-20261013/source/character-master.png`：金发马尾、蓝蝴蝶结、白披风剑士；红发枪手；银紫发法师；蓝发眼镜、红发带、卡其工装机械师。生成素材及来源见 `assets/ui/campaign/README.md`。
- 准备/阅读/记录、人物页、双选档、营地概览、HUD、暂停和奖励等主要界面采用同一战役视觉方向；原有信息结构、键盘焦点、关闭行为与流程合同继续有效。
- 新增首页音乐鉴赏入口：无解锁门槛，直接试听音乐目录全部曲目。

### 不在范围内

- 不复刻兰斯系列的角色、世界观、情节、系统、名词或视觉素材。
- 不改存档格式、战斗规则、AP、势力、成长、模式开放状态或原有菜单流程。
- 不制作新配乐；仅展示项目当前已登记的 14 首原创配乐。

## 3. 设计合同

- 主要信息仍须可读；装饰不能遮挡文本、场景插画、控制或战斗信息。
- 保留现有键盘导航、Tab 焦点、Esc 返回、窗口适配和各界面既有暂停所有权。
- 音乐鉴赏进入时暂停主页 BGM 并保存当前位置；退出停止并释放试听实例，再从保存位置恢复主页 BGM，不产生重叠播放。
- 音乐鉴赏只读现有曲目目录，不设置解锁或进度状态。
- 原创边框可绘制在实际 UI 控件上，不可把界面定格为不可操作的截图背景。

## 4. 实施与验收边界

- 已在 Godot 4.6.2 / Linux / OpenGL Compatibility 下完成实现与图形检查。主页和音乐鉴赏检查了 960×540、1280×720、1920×1080；主页含“继续游戏”时也无导航重叠。战斗两种布局检查了这三种尺寸，并修正窄窗大招、小地图与 Boss 顶栏相互遮挡的问题。
- 11 项相关 smoke 通过：`menu_ui`、`music_room`、`music_context`、`character_panel_ui`、`story_ui`、`story_reading`、`endless_camp`、`hud_widget_lifecycle`、`skill_info_ui`、`level_up_scroll_reopen`、`combat_wave_flow`。Godot headless、项目配置、架构合同、文档链接检查通过。
- Linux PCK 导出成功；从项目外的独立目录加载导出包，已验证新背景、雕花纹样、14 首试听以及包内容排除规则。该结果不等于完整通关或其他系统平台验收。
- 音乐检查覆盖播放器状态、切曲与恢复，尚未人工听音；未执行完整战局体验与 Windows 图形检查。既有存档奖励恢复问题继续由原问题记录跟踪，本轮未改其逻辑。
- Graphify 安全更新已执行；当前安装版本缺少 GDScript 提取能力，候选图缺失 143 个运行时脚本，已拒绝替换并保留原图为 STALE。不能将其视为本轮有效代码索引。
- 本轮改动已单独提交，未推送或发布。提交前的检查摘要、素材哈希与边界见 [verification.json](evidence/2026-10-26/ui-campaign/verification.json)，原始检查输出见 [logs](evidence/2026-10-26/ui-campaign/logs)。
