# 敌人体系跨游戏调研

用户希望先广泛研究敌人，再讨论本作小怪、大怪、精英、首领和衍生单位怎样共同构成可玩的战场。本报告围绕具体遭遇比较：敌人做了什么、玩家能看见什么、有哪些不同代价的应对，以及不同构筑从中得到什么。它是资料研究与设计分析，不是本作已批准的怪物规则，也不声称本轮逐作实机复现。

本作目前是一名前台加至多两名辅助，自动普攻、手动关键技和后台支援同时存在。玩家没有通用翻滚无敌、弹反键或鼠标指定目标；已经有的蕾娜守势属于人物能力。当前四类普通敌人是近战追击、远程射击、突进和高生命慢速近战；六个可玩战斗节点使用组合与数值不同的通用首领模型。敌方护甲、独立物魔抗性、分裂、召唤、治疗支援、敌人招式打断等并未因此自动存在。具体运行事实见[当前状态](../08_当前实现状态与后续重点.md)，本报告中对它们的扩展均为推论或提案。

## 阅读方式与证据

下表按设计问题分组，而不是按游戏名排列。共比较 23 款作品或系统参照，深度不同：其中虹龙洞、斑鸠、挺进地牢和吸血鬼幸存者以系统或场景为对照，不冒称逐招研究了特定首领。**来源 A** 指官方规则、开发者公告或作者本人说明；**A′** 指官方作品经社区转录或翻译；**B** 指攻略、社区机制表或玩家资料。部分 B 来源正文无法完整访问，只能核对搜索索引，表中明确标出，细节不能当作精确规格。游戏版本和来源发表时间分别标明；未列构建号时不能默认适用于全部平台的最新版本。

“应对”栏在有资料支持的机制基础上解释不同选择；“本作启发”是我们的推断。原作不一定有与本作相同的配队、自动攻击或胜利条件，因此不能从一个成功案例推导出本作照搬后也一定好玩。全篇不按宣传截图的弹量、怪物数量或手感主观评分排名。

## 六、从案例比较得到的设计判断

**危险的语言先于危险的数量。**《只狼》的危险符号需要结合动作辨别类别，《Furi》用不同光声信号和收招帮助远镜头读招，《陷阵之志》则展示攻击目标与类型。三者的信息密度和输入方式不同；由此推断，本作应优先让玩家看懂危险覆盖、何时生效、何时结束，而不是先规定每屏最多几颗弹。颜色之外还要有形状、动作或音效区分。

**防守可以改变局面，而不仅抵消伤害。**截全的大戟被反制后不留下同样的地面压力，圆真的突刺可让玩家获得架势收益；绕开依旧是有效选择，但会错过靠近或反击机会。对本作而言，可以研究“蕾娜预先布置守势后换取回击”的价值；取消敌方后续攻击或打断其动作还需要新机制，不能写成已经发生。

**处理眼前危险与处理制造危险的来源，是两种任务。**《陷阵之志》的 Blob 和 Blobber、《Ravenswatch》的触手及本体、《Curse》的援军与治疗首领都让玩家权衡当前局面和未来压力。这里的差别不是怪物血量：玩家清子体可能立刻获得空间，处理源头则减少后续负担。移植前必须明确子体是否独立存续、是否再产生资源、能否被自动攻击可靠命中，以及来源死亡时已产生威胁是否保留。

**保护者和支援者要能被拆掉，也要能被看见。**盾兵、远射和治疗者的组合让优先顺序产生意义；但若自动索敌把火力永久锁在正面无效的目标上、支援者又长时间离屏，就不是有意义的目标判断。优先考虑可接近、有恢复间隙或可从侧面处理的设计，同时允许通过清前排、安全站位或承受有限压力继续推进。

**敌人的反应应当对应玩家真正有权决定的行为。**尖塔的玩家能选择这张技能牌何时打出；本作后台追击和持续伤害可能自动发生。若敌人把所有不可控的自动命中都视为挑衅，后果会由系统替玩家决定。可以考虑只观察可主动选择的关键技，或给玩家清楚的预警和可结束的状态，但这些仍须新实现与实测。

**阶段既可以改变目标，也可以改变时机。**《杀戮尖塔》1 的[史莱姆首领](https://slaythespire.wiki.gg/wiki/Slime_Boss)跨过血线会改变意图与后续单位；图书管理员的书堆使对象同时承担“遮挡”与“时钟”。前者来自社区敌人表，未标具体构建号。它们的原作中玩家控制目标或行动次序的条件较强；本作要先保证自动攻击不会强迫越过需要精确停止的阈值，也不要用强制锁血掩盖不同火力构筑。

**弹幕是一种空间问题，不只是数量问题。**红魔乡的定向射击与暂停后重启的弹、风神录的弹墙、地灵殿的分拍压缩、绀珠传的移动掩护，分别要求诱导、重判、提前换位和维持相对位置。这个分类是本报告的归纳，不是东方系列对所有招式的统一官方分类。同样数量的弹，只要发射源、飞行时间和安全路线不同，玩家面临的任务便不同。

**胜利条件决定反制的价值。**《陷阵之志》的保护对象、回合上限和非致命操控，使“挡住这一轮”本身就有意义；本作仍以击败 Boss 为胜利条件。由此推断，本作可以借目标优先顺序和危险信号，不能假定永久拖住小怪本身会推进胜利。延迟对手需要同时换来安全、资源或后续输出机会。

## 七、回到本作：需要先成立的条件

1. 普通敌人大多维持容易理解的追击、远射或站位压力；大范围危险与复杂职责只占其中一部分，清群与经验反馈保留。可拆解的支援／组织关系应在处理后确实降低压力，而不是立即用其他单位补回。
2. 任一特殊对象或后排单位都要能被实际触及。自动索敌、攻击形状、范围技能和敌方位置共同决定玩家能否执行目标选择；有“弱点”不等于玩家真的能瞄到它。
3. 对连续危险设置可读的先后与恢复，限制互相矛盾的同拍封路。预警要匹配实际覆盖与时间；现有冲锋等预警与命中几何并非完全一致，不能拿现状当作已经精确实现。
4. 召唤与分裂分别定义单位来源、场上寿命、击杀收益和计数。既定规则是 Boss 到场停止普通刷怪、保留场上既有敌人与额外精英，允许有限 Boss 援军且经验有总限；当前 Boss 召唤还未实现。Boss 死亡立即胜利，未击败的场域精英不发相应额外奖励。
5. 每种敌人尽量给出移动保守处理和资源换优势的不同路径；不能强制指定人物、装备或某一属性。护盾、回响、咒伤、追击能提供不同优势，但不能以目前不存在的物魔抗性、格挡标签或通用打断为前提。

这些结论是本次研究对后续设计的建议。白门楼的具体敌人、数量、调度参数和采用范围，另见[敌人体系提案](2026-10-28_白门楼敌人体系提案.md)；在讨论通过及实施前均不改变现行规则。
