# 实施前规则确认

本页保留核心规则的确认结果。用户随后授权完成操作界面大框架，已实现独立界面演练，见[新制作记录](2026-10-27_操作界面风格与制作方向.md)；真实战斗内容仍按下述规则后续实施。此前36张白门楼卡方向已获认可，新增艾玛并保留后续女剑士后暂计37张；具体能力和事件继续细化，见[卡池目录](2026-10-26_白门楼人物卡池与剧情解锁.md)。已定规则的权威入口仍为[当前共识](../00_当前设计共识.md)，本页组织剩余确认顺序。

## 已确认的实施规则

| 项目 | 用户确定的规则 | 对第一批实现的影响 |
| --- | --- | --- |
| 普通关抽卡 | 随机5张候选中获得2张，不按新人物／重复／支援固定分组。 | 同页选择与确认；抽卡场域精英成功时多取1张。 |
| 随行与编队 | 开局仅贾苇索，两辅助位为空；随行无限，关间可配置至多两名辅助，空位合法；后期战役可禁入特定人物。 | 首关不要求切人，第二关才承接艾玛及抽到的人物；删除初始赠送两辅助的前提。 |
| 首位同伴 | 艾玛：从西方走失而来的异世魔法师，去白门楼途中遭遇；首关剧情直接获得，同时正常五选二。 | 复用现有魔法师角色素材；直接获得不占抽卡名额，入池后可重复升级，剧情加入和随机奖励分别提交且只发一次。 |
| 新卡与重复卡 | 新人物按剧情解锁阶段设置初始等级；重复卡升1级并保留经验进度。 | 首次获得与重复升级分别处理；不按当前队伍等级自动追平。具体初始等级和经验保留的数值口径待细化。 |
| 手动技能 | 每人最多2个，普通N卡可只有1个；复用同一组按键。 | 设计两个技能位置，空位／未解锁状态要清楚。普攻、常规技能与瞄准继续自动。 |
| 装备 | 全队共享护甲、武器、饰品3槽，关间可换装；武器改变主角攻击形态，饰品给攻击附魔，护甲增加受击相关效果。 | 不逐人配装，不再限制为基础数值加成；武器形态只改主角；数值作用本关队伍，附魔默认当前人物直接攻击，护甲作用实际承伤者。 |
| 战斗经验 | 按进关时实际配置人数均分：单人全得、两人各半、三人各三分之一；阵亡仍分且不改变分母，候补与战后加入者不分。 | 首关经验归贾苇索，艾玛战后加入不追分；辅助阵亡不将其份额转给存活人物。 |
| 经验拾取 | 局内靠近拾取经验物后立即获得经验；通关自动收取场上剩余经验。 | 已击败敌人与Boss应得经验结清，存活敌人不补算；通关吸收仍可触发升级恢复。 |
| Boss阶段刷怪 | Boss出现后停止普通刷怪，保留已有敌人及额外精英；可有有限的Boss专属援军。 | 援军经验设总量限制；定时与提前出现采用同一规则。 |
| 候补计时 | 候补状态冻结，只有本关已配置人物按规则回魔和冷却。 | 换人保留状态；重复卡升级、泉水等明确事件仍可改变候补状态。 |
| 升级恢复 | 经验或重复卡升级时回满生命与魔法，不复活阵亡人物。 | 存活候补重复升级也可恢复；阵亡人物仍不可出场或提供后台支援。 |
| Boss结算 | Boss被击败立即通关，未击败的额外精英奖励放弃。 | 不要求清除精英，也不胜利后补打；已完成挑战正常结算。 |
| 额外抽卡 | 完成抽卡场域精英后普通关五选三；章末同样多取1张为七选四。 | 候选数量不增加，同页完成选择。 |
| 章末奖励 | 七选三，七张候选中至少两张重要卡。 | 保底须遵守剧情入池；可为重复卡，玩家不被强制领取。具体重要名单另定。 |
| 临时效果与召唤 | 切人不清理，小关结束清理普通临时效果和召唤物；HP／MP／阵亡／技能冷却保留。 | 召唤者阵亡和长期剧情效果的特殊规则另写。 |
| 存读档与续玩 | 多个手动档加自动续档；战斗中退出从本关进场前继续，成功待结算恢复同一候选。 | 读旧档整体回退人物、装备和战果，不合并之后收益；当前路线仍不可回刷。 |

关内切换仍仅限本关的主角和两辅助，不能在战斗中从全库换入第四人。候补不提供本关后台支援，但持有被动按已有规则生效。战役禁入默认描述能否出征／配置，是否另有对持有效果的限制，须由对应战役明确设计。

“按解锁阶段设初始等级”的落实建议：给人物配置与首次登场阶段相称的基础等级；不因玩家拖到后续关卡才抽到而自动变高。初始等级的具体数值需和第一批经验曲线一起试算。

## 五选二带来的开场池修正

前稿开场只开放4人，不足以展示5名不同候选。建议开场先开放6名N卡：乡勇刀手、乡勇枪手、猎户弓手、游方符师、行脚郎中、随军伙夫。猎户与伙夫从原鬼市／夺寨阶段提前到出发前背景交代，这些是候选资格，不是开局赠送人物；开局只有贾苇索，首关剧情直接获得艾玛并将其加入池中，再正常五选二。暂定目录因此由原36张增加到37张。

这是一项配套建议，尚不等于用户已确定6人名单或同组必须去重。建议同组候选人物不重复，但候选可以是玩家已经拥有的人物；不同关卡或不同抽取组仍可重复出现同一个人。后期战役禁入先只限制出场资格，不自动缩小已解锁抽取范围，否则还需处理有效池不足5人的情况。

按12—15场战斗且其中1场为章末估算，没有额外抽卡精英时普通结算共获得25—31张卡（普通每场2张，章末3张），另有首关艾玛直接加入1张，总计26—32次人物获得；每完成一次抽卡场域精英再多获得1张。重复卡计入获得次数，不计为独立人物。这个预算随实际路线场数调整。

## 剩余细节与确认顺序

上表中的奖励、跨关清理和退出规则已经确认，不再列为待选方案。单人开局、首关直接加入艾玛和三槽类别已经确认。接下来设计主角与艾玛的首批可玩技能、护甲／武器／饰品的具体效果，再给第一版可调数值。

2026-10-27已确认空位经验按实际配置人数均分、局内拾取并通关补收，以及Boss出现后停止普通刷怪、保留有限专属援军；不再作为待选项。详见[人物成长](../04_人物卡_成长与装备.md)与[关卡规则](../05_敌人_Boss_关卡_难度.md)。

奖励仍需具体的重要卡名单、候选去重和权重；保存仍需手动槽界面、未生成结果的随机、主动放弃出征及旧档处理。战斗还需同时击杀判定、召唤者阵亡和具体Boss援军预算等细节。能由一致规则解决的实现细节随方案确定，不逐项增加玩家确认负担。

## 随后：输入、装备与首批内容

- 输入试行建议为WASD移动、1／2／3选择主角与两辅助、J／K释放当前人物关键技能，支持重绑定。该键位仍是提案。
- 三槽现已确定为护甲、武器、饰品。下一步为主角攻击形态、攻击附魔和受击效果各做少量有区别的选择；具体首批件数不锁定为8件。
- 持有被动需明确哪些作用全队、哪些只对某类攻击／关卡生效，同类数值相加，必要上限另定。驱散、复活、代伤必须占本关辅助位。人物差别不能仅靠无限堆百分比形成；具体公式留到首批数值设计。
- 先设计贾苇索与首关后加入的艾玛的普攻、常规技能、最多两个关键技能，以及艾玛的后台与持有能力；女剑士、枪手和机械师按后续遭遇陆续设计。
- 先完成两关验证，再完成入城至夺寨的一条4战路线。角色、技能与素材按这一可玩段落制作，后续沿同一内容补齐全章。
- 女剑士与吕玲绮的具体同伴事件、名将可调用理由及终战去向属于内容设计；不影响先用简化剧情验证卡池开锁和结算。

## 保存与开发边界

已通关不可回刷约束当前路线。战斗中退出恢复本关进场前，前关成果保留；待结算恢复同一候选。采用多个手动档加自动续档，读旧档整体回退主线养成和战果，不累加后来收益。具体语义与《兰斯10》来源见[存读档说明](../06_UI_菜单_存档_音频.md)。未生成结果的随机与主动放弃出征另定。

旧存档迁移不是新机制实现的默认前置要求；建议新玩法使用独立版本存档并保留旧档，具体交付方式另定，不自动删除用户保存数据。

当前不要求先确定所有后续州域、全部人物的满级技能或整部主线。进入第一批实施前，需要完成第一段可玩内容的角色能力、基本数值、战斗目标、奖励和状态保存规则，并给出可以实际检查的通过条件。

2026-10-27补充已确认：七项基础属性为生命、魔法、攻击、防御、攻速、移速、回魔；物理/魔法是伤害类型。后台或召唤物继承装备附魔须明确注明。具体角色能力、数值与复活条件仍未定。
