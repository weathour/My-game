# 桥段取材与兰斯剧情资料路线

用户希望剧情自然流畅，尽量沿用成熟场景本来的文字与戏剧逻辑，只做必要的白门楼适配。先找人物关系和位置贴合的**完整场景**，再按[最小适配写作计划](2026-10-30_剧情最小适配写作计划.md)选择可用底本；以下保留的是来源定位与研究，不能把梗概或目录当成已取得的原文。

本文件是**选材研究和后续阅读路线**，不是已批准剧本。实际写法以[最小适配写作计划](2026-10-30_剧情最小适配写作计划.md)为准；[整章提案](2026-10-30_白门楼整章内容体量与参考设计.md)此前自拟的具体戏和对白仍是可替换示例。既定主线、36 个节点及入池与获得等规则以[设计共识](../00_当前设计共识.md)和[实现状态](../08_当前实现状态与后续重点.md)为准。各条来源的定位、实际阅读范围和缺口另见[来源索引](evidence/2026-10-30/story-sources/source-index.json)。

## 目前能读到什么

- **官方摘要和免费旧作入口。**Alicesoft 的[发行说明](https://www.alicesoft.com/about/)列有原版《兰斯》I—IV、4.1、4.2、《鬼畜王》等可按条件免费分发的作品；这些不是全系列公版。开发商的[前作介绍页](https://www.alicesoft.com/rance6/rance.html)提供 I、II 的可运行剧情摘要入口；原开发者 TADA 的 [Rance 02 v1.01 说明](https://hannylaboratory.blogspot.com/2023/04/blog-post.html)记录了获许可的免费发布及其条件。摘要不等于完整台词，02 的版本也要与其他改写版本分开。本轮只读页面，没有下载、安装或运行这些游戏。
- **试玩与已持有版本。**《[兰斯9》官方试玩页面](https://www.alicesoft.com/rance9/special/)区分试玩和仅供运行环境测试的 benchmark；本轮没有取得或运行试玩，也未核实它覆盖哪些场景。选好事件后，可从已经合法持有的相应版本或适用的官方入口回看；不要以某个下载按钮或版本名称替代实际阅读。
- **事件目录与玩家整理。**下表的玩家攻略、日记与参与式 Wiki 可以定位任务、人物链和剧情梗概，适合选哪些片段值得回看；它们不是官方逐字剧本，作者的感想也不是角色原话。本轮没有找到并核验**官方授权且覆盖 VI、战国、Quest、IX、X 的整套逐字脚本**，这只是本轮检索结果，不断言此类资料绝不存在。
- **技术工具。**[alice-tools 作者文档](https://github.com/nunuhara/alice-tools/blob/master/README-ain.md)用 `Rance10.ain` 展示消息导出，输出按函数组织，分支、人物和实际演出顺序仍需回游戏核对；[xsys35c 作者文档](https://github.com/kichikuou/xsys35c)列出支持的部分旧引擎作品。工具不是剧情来源，本轮没有安装、执行工具或提取原稿。

免费发行的旧作仍有权利方，免费取得整作也不等于可以把拆出的台词另行发布。研究时记录作品和版本；本轮保存来源定位、简要分析与研究用适配，不放整部小说、游戏提取文本或现代译注全文。古典原著与现代翻译、校注及影视改编分别对待。

## 《兰斯》：八个可定位的候选

下表**全部是本轮读到的二手事件梗概或攻略，不是已读游戏逐字场景**。它们是选材入口；“可借”是对本作的判断，须先回到对应版本读完事件及其前后，再决定是否采用。

| 作品与事件定位 | 玩家资料中可见的动作 | 可借的结构及下一步核对 |
| --- | --- | --- |
| **Rance VI**：金烛台委托、观察场与反抗组织；[故事详细段](https://seesaawiki.jp/rance-world-note/d/Rance%20VI) | 兰斯讨回烛台后与雇主冲突，被制服关入观察场，反抗组织成员发现他的战力。 | 小差事引出主角脾气、社会秩序和新人物。适合想 S03 的私人争执怎样牵出鬼市局面；仍需读委托、被捕和招募的连续对话，不能从梗概编原话。 |
| **Rance VI**：第五章“魔剣カオスを取得”及废弃迷宫；[任务目录](https://als.sakura.ne.jp/ko-ji/alice/r6/ninmu.html)与[故事梗概](https://seesaawiki.jp/rance-world-note/d/Rance%20VI) | 队伍需要魔剑对敌，保管者却要废弃它；争论之后再去追索。 | 紧急需要的器物与持有者的理由相撞，能让战术问题变成人物戏。回原作核对保管者为何坚持、追索如何展开；目录只定位任务。 |
| **战国兰斯**：铃女人物条目 1—2；[角色事件攻略](https://www2s.biglobe.ne.jp/~m-keiji/datas/rance7/) | 攻略先记她前来刺杀，下一轮又列出她觉得织田有趣并加入。 | 敌意、好奇和乐趣可成为同伴关系的入口；刺杀怎样收场、何种条件下加入，都要看原场景。 |
| **战国兰斯**：乱丸条目 4、5、7；[同一攻略](https://www2s.biglobe.ne.jp/~m-keiji/datas/rance7/) | 条目把共同出阵、旧战友情和婚事列在一条人物事件链里。 | 两人可以有不围着主角转的旧关系，主角甚至能搅局；婚事前提、人物语气及路线条件尚待核对。 |
| **Rance Quest**：“若き親衛隊戦士”；[玩家事件日记](https://monokuror.hatenablog.jp/entry/2021/04/12/000000) | 玩家写新人チルディ自信、试探兰斯并想利用他，试验任务后成为可用人物。 | 初遇先通过比试、算计或本事让人记住她，再谈加入；“利用”的动机带玩家解释，须回原作确认。 |
| **Rance IX**：“眠る巨壁”；[单事件日记](https://retorohide.blog.fc2.com/blog-entry-95.html) | 面对双子砦，进攻者以诱饵配合潜入；守将知道上层腐败，却仍要挡路。 | 一人并非看不见问题才为敌，职责或资格本身也能令双方必须交战。老将的深层政治意图是玩家解读，须复核前后对话和结果。 |
| **Rance X**：“ホーネット奪回”；[任务日记](https://manga-games.com/rance10-play-diary-19/) | 记录有诱饵救援、救出后双方立场仍有差别，以及第三人的劝说。 | 获救、同行、合作、认同可以是不同阶段；要核对救出与回城场景，也不要把剧情在场直接当成持卡时间。 |
| **Rance X**：闘神ゼータ食券 A；[玩家事件整理](https://manga-games.com/rance10-play-diary-214/) | 兰斯催城移动、踢闘神，闘神却为被吓跑的小鸟抗议；转述提到他如今才有机会亲近动物。 | 严肃战事中可有具体的个人爱好与突然拐弯的笑点。这个节奏、收尾语气和演出仍须回原事件核对；只选本条，不把同页其他事件都当候选。 |

这些候选既有冒险和战事，也有人惹祸、斗嘴、争夺与意外的私人趣味。后续不必把非露骨的欺骗、强取、狡诈或权力压力一律抹平：关键是看原场景怎样让人行动、吃亏、反击或继续讨价还价，再判断与本作人物是否相称。原作梗概中的评价和本作的改写选择应分开。

## 古典作品：十个已读选段

以下链接是维基文库所载原文；研究已读的是**表中标明的选段或短篇**，并非宣称通读整部小说。每条的“原文动作”是对所读文字的概括，后列才是本作启发。版本、回次及原文中夹带的评语要分清；小说叙事也不直接等于历史事实。

| 作品、位置与已读范围 | 原文动作 | 本作可借什么 |
| --- | --- | --- |
| C01 [《三国演义》第十一回](https://zh.wikisource.org/wiki/三國演義/第011回)：北海被围至解围后离别。 | 孔融欲救别人却先被围；太史慈报恩而来，转为突围请援，合力解围后仍去做自己的事。 | 让勇力从硬冲转向求援；帮过一场与永久归队可以分开。 |
| C02 《三国演义》[第十九回](https://zh.wikisource.org/wiki/三國演義/第019回)末与[第二十回](https://zh.wikisource.org/wiki/三國演義/第020回)初：禁酒、部下离心、白门楼处置至张辽降曹。 | 同为败将，高顺沉默、陈宫拒活、吕布求用、张辽反斥；刘备与关羽插手，曹操释缚，张辽再招安旧部。 | 同一场所连续显出不同立场，旁人一次插话就改变处置。张辽真正降曹在第二十回开头；本作不照搬各人的死亡结局。 |
| C03 [《三国演义》第四十一回](https://zh.wikisource.org/wiki/三國演義/第041回)：携民撤离至求援、断后。 | 刘备让愿随百姓同行，襄阳拒纳，行军因人多变慢，众人继续分派援救与护送。 | 胜败之外有生计和行动速度的代价；不把本作主角改写成刘备。 |
| C04 [《水浒传》百回本第十一回](https://zh.wikisource.org/wiki/水滸傳_%28100回本%29/第011回)：柴进推荐、朱贵接应至王伦设投名状。 | 林冲有介绍信和接引人，却遭寨主以粮少房稀推拒；王伦对新人的能力既需又忌。 | 同一来客在引荐者、接待者和掌权者眼中不同；一次入伙不必顺理成章。 |
| C05 《水浒传》百回本[第十九回](https://zh.wikisource.org/wiki/水滸傳_%28100回本%29/第019回)后段及[第二十回](https://zh.wikisource.org/wiki/水滸傳_%28100回本%29/第020回)前段：宴上火并至推座、安家和分职。 | 吴用借王伦拒客和林冲旧愤促成火并；林冲持刀推晁盖上位，之后旧头目留任，安排家属、钱粮和守备。 | 夺寨后接着写谁坐主位、谁管旧部和仓粮；原作让座有武力压力，并非人人自然拥戴。 |
| C06 [《西游记》第五十九回](https://zh.wikisource.org/wiki/西遊記/第059回)：问热糕与地方生计、两次借扇至假扇败事。 | 一块热糕引出火焰山和当地人的生计；悟空借扇碰上红孩儿旧怨，取得假扇后反而把火扇大。 | 用一件日常小事带出地方难题，让旧怨、强求和表面成功接连改变局面。 |
| C07 [《聊斋志异》卷二《聂小倩》](https://zh.wikisource.org/wiki/聊齋志異/第02卷#聶小倩)：全篇。 | 小倩受妖物役使，主动告警并请求迁葬；得到帮助后仍有安顿与旧威胁。 | 鬼也能有自己的条件与麻烦；救下一个人还要考虑她之后如何生活。 |
| C08 [《聊斋志异》卷一《种梨》](https://zh.wikisource.org/wiki/聊齋志異/第01卷#種梨)：正文全篇。 | 市集讨梨引起争执，旁人买梨解围；道士当众种树分梨，散场后卖梨人发现车中梨和车柄都没了。 | 让道具和围观者一起完成笑话：争执、热闹、散场、发现吃亏。 |
| C09 [《聊斋志异》卷一《劳山道士》](https://zh.wikisource.org/wiki/聊齋志異/第01卷#勞山道士)：求师至归家撞墙，全篇。 | 王生吃不了苦又想学奇术，试成一次就回家夸口；演示时撞墙，妻子笑他，他反怪师父。 | 夸口、物件、旁人反应和嘴硬可以构成一段短喜剧；该页原题为“劳山道士”。 |
| C10 [《儒林外史》第三回](https://zh.wikisource.org/wiki/儒林外史/第03回)：报捷前后胡屠户、邻人和乡绅的连续段。 | 胡屠户先贬范进，中举后改口称赞；邻人记得他先前的话，乡绅也赶来送礼。 | 地位变化可通过称呼、站位与递钱收钱表现，不必单靠旁白宣布。 |

优先细读 C05、C02、C06、C08、C09：前两条直接解决夺寨和战后处置，后三条能给鬼市、生活和主角胡闹找到节奏。C04 的林冲初上梁山和 C05 的火并隔着多回，不能拼成原作中次日连续发生的两场。

## 后续选材与样板

此前为 S03 至夺寨自行串联的三套剧情方案不再作为默认样板。先为鬼市交锋、夺寨后处置和休整斗嘴分别寻找合适的完整场景；一场用一个主要底本，优先看《水浒传》《儒林外史》的白话段落，也保留《兰斯》作为研究和用户提供片段后的候选。已有的八条《兰斯》资料是二手定位，不能当成已读原稿；古典作品的具体版本、回次与读到的范围仍见上表。

对可直接适配的完整场景，核对本作人物、地点、所知和相邻节点，尽量保留原有措辞、对答与因果；需要改变角色关系、动机或结果才能成立时，换场景或标记缺口。记录原文、适配稿、改动原因和因果映射；不要用新编说明把前后不接处糊平。底本范围、三段样板与语言验收以[最小适配写作计划](2026-10-30_剧情最小适配写作计划.md)为准。

## 接下来的阅读顺序

1. 依据上表定位并阅读完整语境，区分公版原文、用户提供的片段和目前仅能分析的受版权保护材料；游戏文件、摘要或工具本身不等于提供了待改写文字。
2. 比较候选和本作的身份、关系与位置，选择一段自然贴合的主要底本；必要适配优先于重新编排，改动太大就换源。
3. 三段样板完成后连读并记录原因，再为 22 个承载点建立来源表；不为填满体量而增加闲话，也不删除原作中有作用的闲话、犹豫或留白。
4. 研究和选材可按既有授权自主推进，样板成稿供用户审看；后续进入实施任务时接入并做游戏内验证。本轮未写剧本或接入剧情。
