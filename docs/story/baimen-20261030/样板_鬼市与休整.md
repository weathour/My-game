# 白门楼剧情样板：鬼市与休整

以下是两个独立的试写场景。主对答由贾苇索和在对应地点公开相遇的人物承担；艾玛的可选短反应另列，须核对已获得、存活且实际到场。出现在公开场景不等于直接获得人物。

## 一、鬼市交锋：一卷布的价钱

### 连读稿

（鬼市檐下，田秀给一名伤者换药，旁边还有人等着包扎。）

**田秀：** 别动，这布都粘住了。钱绮罗，那细布你给我留着没有？

**钱绮罗：** 留着呢。药钱你还欠着，布可得另算。

**贾苇索：** 美人都有难处，本大爷来付！掌柜，你这细布、粗布各多少钱？

**钱绮罗：** 细的十二文，粗的八文。你要多少？

**贾苇索：** 嘶，这么俊的姑娘，开口就要宰人。细的十文，粗的六文，我现钱给你。

**钱绮罗：** 价钱依你，钱得给我好的。缺角的我不要，成不成？

**贾苇索：** 好钱好布才成。你先把布拿来，我看看。

（钱绮罗把两卷布放在摊上。贾苇索扯开一卷，拿胳膊比了比。）

**贾苇索：** 这一卷怎么比那卷短？掌柜不会悄悄剪了一截，留着给本大爷做荷包吧？

**钱绮罗：** 两头的印还在，你自己看。再说你这胳膊有多长，心里没数？

**田秀：** 长短先放一边，这卷也太窄了。旁边那位伤在胳膊上，绕一圈就没了。

**钱绮罗：** 窄的也能卖啊。你嫌它窄，挑宽的就是。

**田秀：** 这卷留给他包胳膊，那卷裁开，给等着的人用。你，水壶在脚边，替我烧壶水。

**贾苇索：** 钱是我出的，水也要我烧？那你这手让我看看，本大爷会看手相。

**田秀：** 等你把水烧开，我再看你的。

**钱绮罗：** 先别走，钱还没数清。你给的这几枚成色不一，当面点好，出了摊子可不换。

**贾苇索：** 数就数。本大爷在这地方混惯了，数钱的事还能叫你占便宜？

**钱绮罗：** 那你慢慢数，炉火可要灭了。

（钱绮罗收了钱，把布递给田秀。贾苇索拎起水壶，走到炉子边又回头看了一眼。）

**贾苇索：** 大夫，看手相的事你可别忘！

**田秀：** 水开了再说。

### 底本与逐处对应

底本为公版古代汉语会话教材《老乞大》卷下，维基文库所载文本的“店主人家引将几个买毛施布的客人来”至买家取布离开这一完整买布单元。已连读前面的卖人参、随后的买回货；选用的是古代教材正文，不是现代译文、校注或改编。可回查[卷下固定版本](https://zh.wikisource.org/w/index.php?title=%E8%80%81%E4%B9%9E%E5%A4%A7/%E5%8D%B7%E4%B8%8B&oldid=2551541)，并在页内查“又店主人家引将几个买毛施布的客人来”。该数字文本页未说明所据纸本印次，本稿不把它冒称某一已核实的纸本、初刊或现代校注本。

原单元的高丽行商卖布，中国买主议价，中间有牙家；报价、还价、谈银色、检验布的长短宽窄、清点钱货、对真假银提出担保，最后买家拿布离去。并非几个不相干的桥段拼接。本稿删除大宗转卖和牙家，把买方压缩为贾苇索，卖方改为当地商人钱绮罗；删去异乡卖主请牙家担保这一角色关系，布改为病人用的包扎布。

| 底本可回查的短句 | 样板对应 | 调整及原因 |
| --- | --- | --- |
| “细的价钱，粗的价钱” | 贾苇索问细布、粗布；钱绮罗报十二文、八文 | 保留先问两档、卖方分别报价的次序；把大宗银两换成零买的文数。 |
| “我不赊你的” | “细的十文，粗的六文，我现钱给你。” | 保留买方还价并以现付作条件；价格缩到本场规模。 |
| “价钱依着你” | “价钱依你，钱得给我好的。缺角的我不要。” | 卖方让价，同时守住收款条件。 |
| “这布里头长短不等” | 贾苇索摊开布，问为何两卷长短不同；钱绮罗让他看印记 | 保留成交前检查与卖方辩解，将他好色的荷包玩笑嵌在同一问句里。 |
| “这几个布忒窄” | 田秀指出窄布包不住伤者的胳膊；钱绮罗让她挑宽的 | 原文争论布幅是否影响用途；改为医者在场包扎的具体用途。 |
| “出门不管退换” | 钱绮罗坚持当面点钱、出摊不换，贾苇索自己数钱 | 仍是交割时要看清钱货。原文是异乡卖主不认银，请牙家作见证；这里改为当地商人与本地客人当面点钱，删去牙家担保。 |

**因果、在场和桥接。** 贾苇索为正在处理的伤口买布，钱绮罗要做成买卖但不收有缺的钱，验货后支付，田秀收到布去换药；成交结果与底本同向。田秀、钱绮罗是 S03 的公开相遇人物：本场完成后方有入池资格，入池不是已获得，也不是本关配置。贾苇索是当地人，说自己在这一带混惯了，并能自己点钱。

**艾玛可选短反应。** 如她已获得、存活且确实到鬼市诊摊，在田秀最后一句后可插入：

（艾玛走到檐下。贾苇索伸手想拉她跟上。）

**艾玛：** 别拽我！我自己走。

S02 的剧情结束后艾玛直接加入，但她此前有可能阵亡；没有满足在场及存活条件时，上述动作和台词全部不出现，买布的主对答与付款照常成立。她的抗拒也不因救助伤者而自动消失。

**兼容桥接。** 若旧档中田秀或钱绮罗已经持有且阵亡，不能强行演成活人在场：须用现场普通医者／商贩接替其对应工序与称谓，并保留不依赖抽卡的交易；商贩接替钱绮罗时，田秀首句中人名改为“掌柜”；具体只读回顾、复活与入池门槛属于接入时要验证的桥接，本文没有改事件数据。

## 二、休整斗嘴：一碗还不够

### 连读稿

（寨中夜里起风。火边的锅刚烧开，守夜人给来问路的女子盛了一碗粥，留下一只空碗，便起身去添柴。）

**柳晚晴：** 我叫柳晚晴。旧楼里有几个人走散了，你们从那条路来，可见过一个系青布发带的姑娘？

**贾苇索：** 没见着。漂亮姑娘，你先坐下喝口热的，说清她往哪边走，我替你留心。找着了，给本大爷唱一曲怎么样？

**柳晚晴：** 找着了再说。她叫小荷，前日还在旧楼后街，昨儿就没消息了。她胆子小，见生人就躲；你先叫她的名字，别把人吓跑。

**贾苇索：** 旧楼后街、青布发带，本大爷记下了。锅里还有粥吧？

**柳晚晴：** 有，你自己盛。找人可别认错了。

（贾苇索盛了一碗粥，几口下去，碗就空了。）

**柳晚晴：** 这就没了？你把粥倒衣服里了？

**贾苇索：** 吃了！不信再给我一碗，叫你瞧清楚。

**柳晚晴：** 来，张大嘴，我可看着呢。

（柳晚晴接过勺子，又给他盛了一碗。贾苇索端起来一气喝光。）

**柳晚晴：** 你这喉咙怎么长的？不烫么？

**贾苇索：** 再添一碗！美人盛的粥就是好喝。

**柳晚晴：** 少吃点，外头守夜的还没回来。锅里还有，等他们盛过，再给你添。

**贾苇索：** 那也快叫他们进来！明天到旧楼后街，本大爷先去问。

**柳晚晴：** 小荷右手腕上还有道烫伤。你若真找到她，唱一曲的事我认账。

**贾苇索：** 小荷、青发带、手腕有伤，本大爷都记下了。你那碗还没喝完？

**柳晚晴：** 想喝自己盛，不许碰我的。

（柳晚晴把碗挪到自己身边。门外守夜人抱柴回来，笑着揭开了锅盖。）

### 底本与逐处对应

底本为公版《西游记》第四十七回“圣僧夜阻通天水，金木垂慈救小童”，维基文库所载古典正文中陈家庄设饭，至八戒再要饭这一完整吃饭单元。已连读其前的借宿、上席，以及饭后众人问出陈家将以孩子祭妖、行者与八戒商量代替孩子的后续。[可公开回查的原文](https://zh.wikisource.org/zh-hans/%E8%A5%BF%E9%81%8A%E8%A8%98/%E7%AC%AC047%E5%9B%9E)：查“那和尚与老者一问一答的讲话”开始的长段。页面题吴承恩，所载数字文本未注明所据纸本版次；这里不把该页称作经核实的某一刻本或现代译本。

原场面是客人受主人款待，八戒吃得快，旁人怀疑他把饭藏了；他要求再添一碗演示，吃得更多，行者劝他，主人说尚可再蒸，他立刻叫再蒸。本稿保留这一对答次序；饭后祭妖、替孩子出战是原作的后续，并未移作本场已发生之事。

| 底本可回查的短句 | 样板对应 | 调整及原因 |
| --- | --- | --- |
| “不曾笼，吃了” | 柳晚晴疑他把粥倒在衣服里；贾苇索答“吃了！” | 八戒与小童的问答换给贾苇索、柳晚晴；保留吃得过快引起的误会。 |
| “再吃与你看” | “再给我一碗，叫你瞧清楚。”柳晚晴盛碗，他又喝光 | 按原来的证明方式接续；柳晚晴作为在场来客接过递碗动作。 |
| “少吃些罢” | 柳晚晴提醒外面的守夜人还没回来 | 行者劝八戒少吃，改为来客柳晚晴提醒他给守夜人留饭；不引入必须随军的第三人。 |
| “如不饱，再教蒸去” | 柳晚晴看见锅里有粥，请他等守夜的人盛过再添 | 原作由主人再允添饭；寨中有守夜人，来客不替主人另开粮仓，添饭需等实际用饭的人先盛。 |
| “再蒸去，再蒸去” | 贾苇索催守夜人进来，并接着说次日去旧楼后街问人 | 留住要添饭的急切，再用短转场回到柳晚晴的来意。 |

**因果、在场和桥接。** 柳晚晴自己到寨门寻人，公开报了姓名和线索；她得到的是贾苇索明日去问的承诺，并未在本场找到人、自动跟随或被获得。她在 S05 完成后才具入池资格。艾玛直接加入队伍不代表她每次都参与出战，也不代表她当下必然在场或存活。场景不提任何人刚在 B06 作战，可选关跳过也说得通。

**与底本的承接差别：** 陈家庄主人备斋，其后引出祭妖与救孩；寨里的这锅粥属于守夜人安排的休整饭，转向柳晚晴找走散的同伴。原作后续目的没有移植，这是明确的出口桥接，不把本场宣称为原作整条救孩情节的等价改写。下场还须实际兑现或另行说明贾苇索许下的问人承诺，不能用“已找到”跳过。

**艾玛可选短反应。** 如她已获得、存活且确实来到火边，可在柳晚晴挪碗后插入：

（艾玛从门边走到火旁，贾苇索朝她伸手。）

**艾玛：** 别拽我！明天去不去旧楼，我还没答应。

**贾苇索：** 天亮再说。

否则整组动作和对答不出现；主要找人、吃饭和添饭的对话不依赖艾玛。柳晚晴如果在兼容旧档中已被持有且阵亡，则不能照此重演为活人；应延后她的具名相遇至复活且实际到场，或另做不授予其相遇／入池事实的普通来客版本，相关只读回顾与门槛需要接入时核实。
