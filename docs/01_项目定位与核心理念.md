# 项目定位与核心理念

设计依据：[当前设计共识](00_当前设计共识.md)。2026-10-26更新；本文描述目标，运行版本尚未重构。

## 核心体验

征战、人物成长与女性角色的暧昧和亲密陪伴共同构成游戏的吸引力。用户希望后者约占整体体验的一半，以“醒掌天下权，醉卧美人膝”表达期待。人物关系需要从首段就进入内容规划，具体推进机制、时长配比和女性阵容来源尚未确定。

风格直接参考《兰斯》的欲望驱动、夸张人物互动与成人冒险。人物事件可以直接、胡闹、风流，并与重要剧情穿插；不把细腻恋爱养成或人人循序渐进的关系流程作为要求。

关内是连续的实时肉鸽战斗：操控、杀敌、接近或绕开收益点、应对Boss。关外是沿主线前进时的人物培养与配置：抽人物卡、利用重复卡升级、安排本关练谁、选择两名辅助和装备，并考虑下一段路线。

男主贾苇索维持玩家身份和稳定的强近战基础。名字结合苇索缚鬼与“假猥琐”的双关，大事上极其正义、极有正气；具体身世仍待确定。辅助可以留在后台帮助，也可以由玩家切换操作。两名辅助的配置不等于角色收集上限；较大的角色库需要在长期主线中逐步体现价值。

主线采用三国已经覆亡的架空世界，天下遍布遗迹与鬼怪，名将主要以亡魂或异变形态重现。以《黑神话：悟空》作为风格参照之一，结合其他气质，具体组合见[背景讨论](16_世界背景与风格.md)。天下图以州或大模块展示全局，用于查看信息、局势与选择大战役；进入后在一大片具体区域的战役路线图上，沿小关、精英关和其他节点推进到最终Boss。一次大战役对应一次出征，主线阶段有有限出征机会，返营全员恢复。首战确定为白门楼鬼城：贾苇索为吕玲绮而来，沿途夺地壮大、抵御鬼曹军救城，最后对战吕布，踏上诸侯起家之路；具体节点和战后归属待定。

## 有差异的角色价值

人物可以在战斗输出、配合、针对性功能和持有加成上各有所长。强场外功能可以对应较弱的战斗能力；培养一个当前不上场的角色也可以有意义。主线不同关卡逐步提供这些差异发挥作用的场合。

向玩家明确展示能力、条件、代价与当前状态，让玩家自己权衡。无需将角色统一成等价输出，也不使用系统提示替玩家规定抽卡、练级和上场的最优答案。

## 节奏与成长

技能随人物等级自动解锁，减少战斗中频繁开卡面选择。小关内以场域和额外精英提供收益选择；小关结束抽人物卡，间歇可以换人换装备。生命与魔法跨关延续，泉水承担恢复作用。

成功关卡不能回头，培养、恢复和装备的取舍服务于后续推进。失败只撤销本关尝试，回到进关前状态；不靠额外死亡惩罚建立压力。

## 参考与创作

《兰斯10》是人物卡、培养、持有角色收益和主线组织的机制参考，也保留其战役档案式界面的视觉参考价值。具体本作规则由[共识](00_当前设计共识.md)定义；不把参考游戏的AP、回合、属性公式或角色技能直接当作本作规定。

美术、音乐、文字和界面素材沿用本仓库的制作与来源记录，视觉规则见 [DESIGN.md](../DESIGN.md)，资源要求见[资源规范](07_资源_美术_特效规范.md)。
