# 当前设计共识

更新：2026-10-27。依据用户讨论整理；前两关及夺寨段四个战斗节点、泉水、成长与正式主线保存已经接入，共六个可玩战斗节点，单次路线因分支互斥实际经过四场或含可选精英五场。当前范围见[状态入口](08_当前实现状态与后续重点.md)；界面演练样例不自动成为正式数值或剧情。

## 游戏方向

以实时肉鸽战斗为关内体验，以人物收集、培养、编队、装备和战役路线为长期选择。保持连续战斗，减少频繁选技能卡造成的打断。玩家从角色差异和关卡需求中自行权衡；界面说明事实和效果，不替玩家指定正确培养顺序或最优队伍。

征战与女性角色的暧昧、亲密陪伴共同构成核心体验。用户以“醒掌天下权，醉卧美人膝”表达期待，希望大量女性角色及相关氛围约占一半；具体内容量与游玩时长的衡量方式未定。当前先讨论整体体验，女性阵容的来源暂不限定，也未决定好感数值、关系推进和多段关系组织方式。

人物互动与成人氛围直接以《兰斯》为风格参照：可以直白、好色、夸张、胡闹，与征战冒险穿插。用户已纠正过度讲究的恋爱设计；此前细腻恋爱养成及人人经历统一关系成长流程的建议撤回，不作为后续设计前提。

男主确定名为**贾苇索**：“苇索”为缚鬼之索，并谐音“猥琐”，“贾”谐音“假”；他在大事上极其正义、极有正气。日常风流胡闹与重大抉择形成反差。他是这个世界的原住民，行事无法无天；具体身世、存在形态与事件仍待创作，不能从《兰斯》的风格参照推导他的大事立场。

后续用户明确增加贾苇索对成年吕玲绮的侵犯，要求主角更不正派。因此人物同时保留抵御鬼曹军、救城的正义选择与实际严重恶行；不能用“假猥琐”将已经发生的伤害解释为无害表象。

天下的残酷血腥与主角的实际庇护形成重要反差：人物可以依附一个好色、霸道、会越界的保护者。具体人物对保护、依赖和越界的感受与行为仍待创作，详见背景文档。

成年角色的性关系情节统一以“抱”代称，具体过程淡出或跳过，后续承接已经发生的事件。省略不改变是否强迫等剧情事实，人物感情与态度按具体事件发展，不由发生关系自动推导。

《兰斯10》可以作为人物卡、人物成长、持有角色的场外价值、主线战役与路线的机制参考，不再限于视觉参考。本作采用实时战斗；具体规则以本文为准，不直接套用其回合战斗、行动点或数值。

长期目标体量以《兰斯10》第一部为参照，分阶段开发。用户进一步确定：白门楼自成完整大章，主要参考《兰斯10》的节奏，开篇兼顾新手入门；完整首章与最先开发的可玩片段分别规划。用户认可此前女性人物方向，并要求跨战役复用、增加重要名将卡，旧14张卡上限撤回。此前36张卡的构成方向已获认可；新增艾玛并保留女剑士后，暂按37张预算，女剑士具体所属关卡仍待确定。具体能力和原36路线节点继续讨论，不以原作格数或跨篇收藏卡数直接设定制作量。

白门楼明确加入吕布、张辽、高顺、陈宫及虎豹营将领等人物卡。张辽、高顺、陈宫须在吕布之前的精英关及对应剧情通过后入池；“对应剧情完成后入池”作为全游戏规则沿用。普通N卡可复用素材、微调改色，只有重点人物需要专门绘制；这些人物也可在后续战役继续出场。具体名单和能力见[卡池草案](design-reviews/2026-10-26_白门楼人物卡池与剧情解锁.md)。

首场大战役确定为**白门楼鬼城**：贾苇索听说鬼城有绝色女公主吕玲绮而出征，途中在去白门楼的路上遇到从西方走失而来的异世魔法师艾玛，沿途过关闯将、杀匪杀官、掠地壮大；在抵御鬼曹军之前劫掠并侵犯成年吕玲绮，过程略去。随后抵御鬼曹军救城，间接救了吕布一家，最后对战吕布，从这里踏上诸侯起家之路。救城之恩与侵犯造成的仇怨同时承接；具体节点、人物反应与去留、战后领地仍待讨论，见[首战与开发草案](design-reviews/2026-10-26_首段教程战役与分阶段开发.md)。

采用架空三国背景：三国已经覆亡，天下遍布遗迹与鬼怪，名将主要以亡魂或异变形态重现。《黑神话：悟空》作为风格参照之一，结合已获认可的苍凉威严、山河壮丽、民俗奇趣和英雄情义，并突出女性角色的暧昧与风流气质。具体世界成因、主角身世与存在形态、其他幸存者及场景表现仍待讨论，见[世界背景与风格](16_世界背景与风格.md)。

以天下图和战役区域图两个层次组织主线。天下图按较大的州或模块展示全局、查看信息并选择大战役；战役区域图显示本次出征涉及的一大片区域，用路线连接小关、精英关及其他节点，推进至最终Boss。覆亡后的时代状态、州域数量和边界尚未确定。

开场人物现已改为**艾玛**，复用已有魔法师角色。她在去白门楼的路上与贾苇索相遇；欺骗与强迫下发生性关系，过程略去，后续承接她在陌生世界缺乏依靠、被迫随行的处境。首次剧情入队与普通五选二分别结算，不将关系态度自动写成爱慕。女剑士另在后续某关获救加入；枪手与机械师安排在后续战役的遭遇节点。上述异世来客并不改变贾苇索是本世界原住民的设定，具体事件见[背景文档](16_世界背景与风格.md)。

用户已认可 D 稿的“三国志美术＋兰斯10布局”，并授权直接推进到操作界面大框架完成。用户随后认为现有实现美观不足且冗余，要求逐页研究兰斯10的信息组织；美术方向继续保留。战斗优先旧版简单HUD，可同时保留三行版作为选项，不以三行栏为默认要求。详见[制作记录](design-reviews/2026-10-27_操作界面风格与制作方向.md)。

## 已确定的规则

| 范围 | 当前共识 |
| --- | --- |
| 主角 | 固定男主贾苇索，代表玩家身份，默认是简单、强力的近战攻击型；大事上极其正义、极有正气。取消三人平等的身份设定。 |
| 战斗编队 | 主角加至多两名辅助，允许空位。新游戏开局只有贾苇索，两个辅助位为空；首关后艾玛剧情直接加入，普通五选二照常结算。辅助可在后台提供部分技能帮助，也能切换到前台直接操作。 |
| 操作分工 | 普攻、常规技能及攻击/技能方向均自动处理，关键技能由玩家手动触发，可以有多个。关卡内游玩不需要鼠标；移动、切人和技能的整体操作复杂度不能过高。 |
| 关键技能调用 | 每人最多2个手动关键技能，普通N卡可以只有1个；只调用当前角色，各角色复用同一组按键。后台支援自行触发。 |
| 承伤规则 | 一般只有当前操作的人物直接承伤；允许特殊辅助通过明确的角色能力代主角承伤，具体机制随人物设计。 |
| 切换 | 只有短暂的公共切换冷却；沿用各自生命、魔法和技能冷却，不附赠通用无敌，不刷新技能。特殊角色可以有登场效果，不要求所有队伍频繁轮换触发登场技。 |
| 辅助能力结构 | 每个辅助分别设计前台能力、后台支援，以及不出征也生效的持有被动；三者的作用和条件分别说明。 |
| 人物规模 | 出征随行人数不设上限，不预选有限名单。关间从全部已获得、存活且符合战役条件的人物中选择至多两名辅助；新获得人物也可在下一关配置。后期战役可禁止特定人物进入，具体条件另定。 |
| 独立资源 | 本关实际配置人物的生命、魔法独立；切换不能把它们视作同一份资源。 |
| 魔法用途 | 魔法用于手动关键技能；普攻、常规自动技能与自动后台支援不消耗魔法。常规技能主要由冷却约束，关键技能由魔法与自身冷却约束。 |
| 后台恢复 | 切到后台后技能冷却继续计时，魔法按该人物自身回复属性恢复；生命恢复依赖具体恢复能力或补给。切换本身不回血回魔。 |
| 候补冻结 | 未配置到本关的人物冻结状态，不自然回魔或推进技能冷却；只有本关实际配置人物按规则计时。重复卡升级、泉水等明确事件仍可改变候补状态。 |
| 升级恢复 | 经验或重复卡升级时，存活人物生命和魔法回满；阵亡人物仍保持阵亡、不可出场，不因升级复活或恢复后台支援。 |
| 失败 | 只有主角死亡才判关卡失败。辅助阵亡时切回主角；其阵亡状态在胜利后延续，直到泉水或完成整次出征返营后复活。 |
| 阵亡后的效果 | 辅助阵亡后停止其后台支援，保留因已获得并培养该人物而产生的持有加成。 |
| 跨关状态 | 切人不清除已有临时效果或召唤物；小关结束清理普通临时效果和召唤物，生命、魔法、阵亡及技能冷却继续保留。泉水与返营按规则恢复。 |
| 关内选择 | 每个小关有四角场域，走到其中一处作出选择后，另外三处失效；也可以全部绕开，放弃相应资源。 |
| 场域收益 | 可以是生命/魔法补给、给当前角色增加经验、召唤精英以获得额外关末抽卡机会、召唤精英以获得可穿戴装备。具体配置和数值未定。 |
| Boss与通关 | 固定时间到达后Boss直接出现；提前清理足够敌人可以使其提前出现。出现后停止普通刷怪，已有敌人和额外精英保留；Boss可召唤有限专属援军，援军经验有总量限制。必须击败Boss才通关，限时通过另有经验奖励。 |
| Boss与额外精英 | Boss被击败立即通关，尚未击败的场域精英不发额外奖励；不要求清除精英才能结束，也不继续停留补打。 |
| 关末抽卡 | 普通关五选二，完成抽卡场域精英后五选三；章末七选三且候选至少两张重要卡，完成该精英后七选四。重要卡保底仍受剧情入池条件限制，不保证必为未拥有人物。 |
| 剧情入池 | 对应剧情通过后才加入卡池，未满足门槛不能提前抽到；一般入池不等于自动获得。艾玛是已确认的首关剧情直接加入特例，不占五选二名额，并在此后进入重复抽取培养。张辽、高顺、陈宫仍在白门楼终战前精英关及剧情通过后解锁。 |
| 人物复用 | 人物可在其他战役继续出场；沿用已获得人物和等级。重点人物专门绘制，普通N卡可采用素材微调与改色。 |
| 人物成长 | 新人物按剧情解锁阶段设置初始等级；重复卡升1级并保留已有经验进度。战斗经验按进关时实际配置人数均分：单人全得、两人各半、三人各三分之一；本关阵亡仍分，候补与战后加入者不分本关经验。 |
| 经验拾取 | 敌人掉落经验物，靠近拾取后立即获得经验并按等级规则成长；击败Boss后自动收取场上剩余经验。只结算已击败敌人的应得经验，存活敌人不补算。 |
| 技能成长 | 到人物等级自动解锁相关技能，不另设技能选择。旧技能点、技能卡和天赋选卡流程不再作为新体系前提。 |
| 持有收益 | 人物获得后，即使没有带上场，也可以提供持有加成；等级提升可以增强此类效果，例如魔法回复或经验收益。 |
| 持有叠加 | 同类数值加成相加，必要属性设置明确上限；具体数值与上限另定。 |
| 特殊功能 | 驱散、复活、代伤等明确功能必须配置为本关辅助并满足角色条件；仅拥有或留候补不生效。主角死亡失败规则保持，复活的目标/时机/次数另定。 |
| 基础属性 | 生命、魔法、攻击、防御、攻速、移速、回魔七项；统一攻击属性，物理/魔法属于伤害类型。暴击、吸血、穿透由具体人物或装备提供。 |
| 装备作用对象 | 武器形态只改主角；通用装备数值作用本关队伍。饰品默认附魔当前人物直接普攻和技能，后台支援/召唤物需明确注明继承；护甲效果由实际承伤者触发。 |
| 人物差异 | 场外功能强的角色，战斗能力相对弱。角色可以因针对性驱散、高等级被动、直接输出或组合配合而有价值；不要求人人都擅长输出。 |
| 装备 | 装备可带回并保留，全队共享护甲、武器、饰品3个固定槽，关间可换装。武器可以改变主角攻击形态，饰品给攻击附魔，护甲提供受击相关效果；不再局限于基础数值加成，换辅助无需逐人配装。具体作用范围与数值另定。 |
| 主线推进 | 有大战役、关卡和路线。成功通过的关卡不能回头刷；未通过可以重试。 |
| 两层地图 | 天下图包含全部州或大模块，用于宏观查看、点击信息、观察局势和选择大战役。进入后切换到战役区域图，仅显示相关一大片区域，按节点路线通向最终Boss；不再增加独立的州级地图选择层。 |
| 大战役与出征 | 一次大战役对应一次完整出征，由连续小关、分岔和恢复等节点构成；短支援任务也可作为出征。战斗场景由战役节点进入，不构成第三层战略地图。 |
| 主线行动 | 一个主线阶段有有限出征机会，大战役和短支援任务各按一次行动结算，完成出征返营后更新局势。小关失败重试不消耗额外行动，也不推进天下局势；具体阶段次数与期限未定。 |
| 完全过关 | 指完成整次出征并返回营地，此时全员恢复、辅助复活。普通关间整备不自动恢复，战役途中依靠泉水或角色能力维持状态。 |
| 战役节点 | 区域路线包含普通战斗小关、独立精英关、恢复/事件等节点及最终Boss关。战斗节点沿用小关的Boss通关与关末抽卡规则；非战斗节点不自动发放小关人物卡。 |
| 失败回退 | 不保留失败小关内获得的收益，回到进关前状态。此前已通过关卡的成果保留，不增加额外失败惩罚。 |
| 存读档 | 多个手动档加自动续档；战斗中退出恢复本关进场前，已胜利待结算恢复同组候选。读旧档整体回退当时人物、装备、开池与战果，不与之后收益合并。 |

## 还没有确定的内容

以下不是额外功能清单，只记录会影响后续具体设计的边界；讨论到对应内容时再决定。

- 三国覆亡的原因与时间距离、活人是否存在、名将异变规则、贾苇索的身世与存在形态、具体场景表现；征战与女性人物关系的联系、事件与时长分配、关系推进和并行方式。主角姓名与正气底色、吕玲绮的首战身份已定，艾玛、女剑士、枪手与机械师作为穿越者陆续出现，其余女性来源与具体身份仍待讨论。
- 白门楼后续节点、分岔、泉水布局、吕布终战理由及战后归属；州/模块边界，主线各阶段的行动次数、期限和未参与战事的后果。夺寨段路线已接入，后续官署段尚未制作；大战役对应一次出征、返营恢复与两层地图结构已定，此前固定关数、县城解围和虎牢关首战试排已由白门楼主线替代。
- 后期战役的具体人物禁入条件；候补冻结已定，随行无限，取消容量扩充和满员替换问题。
- 主角及辅助的具体技能与键位、自动索敌、公共切换冷却时长；支援触发、主角后台特性、代主角承伤。手动关键技能上限已定为每人2个。
- 等级上限、经验曲线、各解锁阶段的具体初始等级、满级卡处理与主角额外成长来源；重复卡升1级保留经验、按实际配置人数均分且本关阵亡仍分、局内拾取经验与通关补收已定。
- 普通／额外／章末抽卡数量和章末至少两张重要候选已定；重要卡具体名单、同组去重、阶段权重、未生成奖励的随机规则仍待细化。
- 持有加成的具体数值、上限与个别作用对象；同类相加、强特殊功能须占本关辅助位已确定。
- 场域触发细节、经验场域的具体受益者、Boss出现时间、提前阈值和限时奖励计算；Boss死亡立即结束、未败精英无额外奖励已定。
- 装备的具体形态、附魔与受击效果、具体触发和叠加规则、背包、重复装备处理与入库时点；护甲／武器／饰品三槽、全队共享与跨关保留已定。
- 资源回复与技能消耗数值、召唤者阵亡时召唤物如何处理、长期剧情状态的例外；主动放弃、旧档迁移和未生成结果的随机规则。普通跨关清理及战斗退出回到进关前已经确定。

## 被替代的设计

- 出征前预选有限随行名单、随行容量扩充、满员送回及本次不能召回的方案；已被无限随行、关间自由换辅助替代。

- 三名平等角色轮转的主结构，以及以切换能量、登退场技或旧三层天赋为中心组织整套成长。
- “唯一玩家”被解释为始终同一身体、只借用辅助特性的方案；无需再叠加一套未经确认的“共鸣”系统。
- 升级时频繁抽技能卡、技能点加点、技能5/10级天赋选择、旧108节点树和祝福配方作为新游戏的默认成长入口。
- 固定20波无尽、N层和骨头商店作为主线的必要结构；它们是否还有独立用途尚未决定。
- 旧三关固定剧情、每关重置成长及已通关练习重访作为新主线规则。
