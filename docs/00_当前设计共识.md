# 当前设计共识

更新：2026-10-31。本页记录用户已确定的游戏方向与规则；已实现的范围和未完成事项见[当前状态](08_当前实现状态与后续重点.md)。计划中的跨战役规则不等于已实现。

## 游戏方向

以实时肉鸽战斗为关内体验，以人物收集、培养、编队、装备和战役路线为长期选择。保持连续战斗，减少频繁选技能卡的打断；玩家依据角色差异和关卡需求作选择，界面说明效果，不指定最优队伍。

征战与女性角色的暧昧、亲密陪伴共同构成核心体验。用户希望大量女性人物及相关氛围约占一半，具体内容量、游玩时长与关系组织方式尚未定。人物互动参照《兰斯》直接、好色、夸张和胡闹的成人冒险风格；不强制统一的恋爱成长系统。

背景是三国覆亡后的遗迹鬼怪世界，强调苍凉山河、民俗奇趣和英雄情义。贾苇索是本世界原住民、强势且好色的近战主角，具体身世仍待创作。他既在大事上作出抵御鬼曹军、救城的选择，也实际劫掠并侵犯成年吕玲绮；叙事淡出过程，保留严重伤害和人物后果，救城不自动抵罪或带来原谅。艾玛是迷失于此的成年异乡魔法师，首关先结算选卡，剧情结束后直接加入；她的警惕和拒绝不因入队自动消失。其他人物相遇、入池与实际获得分别计算。

白门楼是第一场自成一章的大战役：36 个路线节点、18 个战斗节点，单次路线 12—15 战。最终吕布独自应战、两阶段且不出现小怪。现行剧本采用吕布留守城内、贾苇索暂驻外署并照看水门外至旧寨粮道的停战安排；这是当前具体写法，不增设内政系统，也不代表用户逐句批准为全作永久设定。具体情节与人物去留见[世界背景](16_世界背景与风格.md)和[人物档案](17_人物档案.md)。

长期规模暂按 120 张可收集人物加主角、48 件装备、约 8 个构筑方向与 30—40 套代表组合规划；白门楼为 37 张可收集人物加主角，装备和组合规模仍随制作与实玩调整。当前只完成首章初版，具体范围见[当前状态](08_当前实现状态与后续重点.md)。

## 已确定的规则

| 范围 | 当前共识 |
| --- | --- |
| 主角 | 固定男主贾苇索，代表玩家身份，默认是简单、强力的近战攻击型；他既有救城的选择，也有真实的严重恶行。 |
| 战斗编队 | 主角加至多两名辅助，允许空位。新游戏开局只有贾苇索，两个辅助位为空；首关五选二或抽卡精英收益五选三结束后播放艾玛剧情，剧情结束后她直接加入。辅助可在后台提供部分技能帮助，也能切换到前台直接操作。 |
| 操作分工 | 普攻、常规技能及攻击/技能方向均自动处理，关键技能由玩家手动触发，可以有多个。关卡内游玩不需要鼠标；移动、切人和技能的整体操作复杂度不能过高。 |
| 关键技能调用 | 每人最多2个手动关键技能，普通N卡可以只有1个；只调用当前角色，各角色复用同一组按键。后台支援自行触发。 |
| 承伤规则 | 一般只有当前操作的人物直接承伤；允许特殊辅助通过明确的角色能力代主角承伤，具体机制随人物设计。 |
| 切换 | 只有短暂的公共切换冷却；沿用各自生命、魔法和技能冷却，不附赠通用无敌，不刷新技能。特殊角色可以有登场效果，不要求所有队伍频繁轮换触发登场技。 |
| 辅助能力结构 | 每个辅助分别设计前台能力、后台支援，以及不出征也生效的持有被动；三者的作用和条件分别说明。 |
| 人物规模 | 出征随行人数不设上限，不预选有限名单。关间从全部已获得、存活且符合战役条件的人物中选择至多两名辅助；新获得人物也可在下一关配置。后期战役可禁止特定人物进入，具体条件另定。 |
| 独立资源 | 本关实际配置人物的生命、魔法独立；切换不能把它们视作同一份资源。 |
| 魔法用途 | 魔法用于手动关键技能；普攻、常规自动技能与自动后台支援不消耗魔法。常规技能主要由冷却约束，关键技能由魔法与自身冷却约束。 |
| 后台恢复 | 切到后台后技能冷却继续计时，魔法按该人物自身回复属性恢复；生命恢复依赖具体恢复能力或补给。切换本身不回血回魔。 |
| 候补冻结 | 未配置到本关的人物冻结状态，不自然回魔或推进技能冷却；只有本关实际配置人物按规则计时。重复卡升级、泉水等明确事件仍可改变候补状态。 |
| 升级恢复 | 经验或重复卡升级时，存活人物生命和魔法回满；阵亡人物仍保持阵亡、不可出场，不因升级复活或恢复后台支援。 |
| 失败 | 只有主角死亡才判关卡失败。辅助阵亡时切回主角；其阵亡状态在胜利后延续，直到泉水或完成整次出征返营后复活。 |
| 阵亡后的效果 | 辅助阵亡后停止其后台支援，保留因已获得并培养该人物而产生的持有加成。 |
| 跨关状态 | 切人不清除已有临时效果或召唤物；小关结束清理普通临时效果和召唤物，生命、魔法、阵亡及技能冷却继续保留。泉水与返营按规则恢复。 |
| 关内选择 | 普通小关有四角场域，走到其中一处作出选择后，另外三处失效；也可以全部绕开，放弃相应资源。B18 吕布独战不提供场域选择或额外精英入口。 |
| 场域收益 | 可以是生命/魔法补给、给当前角色增加经验、召唤精英以获得额外关末抽卡机会、召唤精英以获得可穿戴装备。具体配置和数值未定。 |
| Boss与通关 | 普通遭遇固定时间到达后Boss直接出现；提前清理足够敌人可以使其提前出现。出现后停止普通刷怪，已有敌人和额外精英保留；Boss可召唤有限专属援军，援军经验有总量限制。B18 进关直接面对人形吕布，全程无自动或召唤的小怪；击败人形后变身，战相落败才通关。限时通过另有经验奖励，B18 初版时限为100秒。 |
| Boss与额外精英 | 普通遭遇中Boss被击败立即通关，尚未击败的场域精英不发额外奖励；不要求清除精英才能结束，也不继续停留补打。B18 独战没有场域精英。 |
| 关末抽卡 | 普通关五选二，完成抽卡场域精英后五选三；章末七选三且候选至少两张重要卡。B18 无精英，不补发第4个名额；旧档已生成的七选四候选与选择进度保留。重要卡保底仍受剧情入池条件限制，不保证必为未拥有人物。 |
| 剧情入池 | 对应剧情通过后才加入卡池，未满足门槛不能提前抽到；一般入池不等于自动获得。艾玛是首关选卡后的剧情直接加入特例，剧情结束后获得并入池，不占选卡名额；新流程首关候选中没有她，此后进入重复抽取培养。旧档已生成的候选按原组保留。张辽、高顺、陈宫仍在白门楼终战前精英关及剧情通过后解锁。 |
| 人物复用 | 人物可在其他战役继续出场；沿用已获得人物和等级。重点人物专门绘制，普通N卡可采用素材微调与改色。 |
| 人物成长 | 新人物按剧情解锁阶段设置初始等级；重复卡升1级并保留已有经验进度。战斗经验按进关时实际配置人数均分：单人全得、两人各半、三人各三分之一；本关阵亡仍分，候补与战后加入者不分本关经验。 |
| 经验拾取 | 敌人掉落经验物，靠近拾取后立即获得经验并按等级规则成长；击败Boss后自动收取场上剩余经验。只结算已击败敌人的应得经验，存活敌人不补算。 |
| 技能成长 | 到人物等级自动解锁相关技能，不另设技能选择。升级时不另设技能选择。 |
| 持有收益 | 人物获得后，即使没有带上场，也可以提供持有加成；等级提升可以增强此类效果，例如魔法回复或经验收益。 |
| 持有叠加 | 同类数值加成相加，必要属性设置明确上限；具体数值与上限另定。 |
| 特殊功能 | 驱散、复活、代伤等明确功能必须配置为本关辅助并满足角色条件；仅拥有或留候补不生效。主角死亡失败规则保持，复活的目标/时机/次数另定。 |
| 基础属性 | 生命、魔法、攻击、防御、攻速、移速、回魔七项；统一攻击属性，物理/魔法属于伤害类型。暴击、吸血、穿透由具体人物或装备提供。 |
| 装备作用对象 | 武器形态只改主角；通用装备数值作用本关队伍。饰品默认附魔当前人物直接普攻和技能，后台支援/召唤物需明确注明继承；护甲效果由实际承伤者触发。 |
| 人物差异 | 场外功能强的角色，战斗能力相对弱。角色可以因针对性驱散、高等级被动、直接输出或组合配合而有价值；不要求人人都擅长输出。 |
| 装备 | 装备可带回并保留，全队共享护甲、武器、饰品3个固定槽，关间可换装。武器可以改变主角攻击形态，饰品给攻击附魔，护甲提供受击相关效果；不再局限于基础数值加成，换辅助无需逐人配装。具体作用范围与数值另定。 |
| 主线推进 | 有大战役、关卡和路线。成功通过的关卡不能回头刷；未通过可以重试。 |
| 剧情回顾 | 当前存档已完成、且具有正式剧情脚本的事件、泉水或战后剧情节点可以从路线或见闻重新观看；从首句开始，按句推进。回顾不改变当前进度、人物状态、奖励或正式剧情断点，不重复触发入队、入池、恢复等事件效果，也不写存档。 |
| 历史对白 | 在首玩剧情和只读回顾中，可用鼠标上滚或界面入口查看当前段已显示的对白，按顺序标明发言人或旁白；当前句仅显示已经显现的部分，不能提前看到后续台词。历史面板只读，关闭后回到原句与原显示位置，不推进剧情或触发事件结算。 |
| 两层地图 | 天下图包含全部州或大模块，用于宏观查看、点击信息、观察局势和选择大战役。进入后切换到战役区域图，仅显示相关一大片区域，按节点路线通向最终Boss；不再增加独立的州级地图选择层。 |
| 战役路线浏览 | 白门楼区域图采用横向连续路线，展示当前目录的36个节点及真实连接，分岔纵向展开并在对应节点合流；六段目录用于跳转定位。原创小图标区分战斗、精英、泉水、剧情与终战，类型图标与状态标识分开。可拖动或滚轮浏览、悬停查看、点击节点并在右侧查看详情，支持定位当前节点。查看中的节点与实际行军位置分开，只有在右侧确认前往才推进；已完成剧情仍可只读回顾。 |
| 大战役与出征 | 一次大战役对应一次完整出征，由连续小关、分岔和恢复等节点构成；短支援任务也可作为出征。战斗场景由战役节点进入，不构成第三层战略地图。 |
| 主线行动 | 一个主线阶段有有限出征机会，大战役和短支援任务各按一次行动结算，完成出征返营后更新局势。小关失败重试不消耗额外行动，也不推进天下局势；具体阶段次数与期限未定。 |
| 完全过关 | 指完成整次出征并返回营地，此时全员恢复、辅助复活。普通关间整备不自动恢复，战役途中依靠泉水或角色能力维持状态。 |
| 战役节点 | 区域路线包含普通战斗小关、独立精英关、恢复/事件等节点及最终Boss关。战斗节点沿用小关的Boss通关与关末抽卡规则；非战斗节点不自动发放小关人物卡。 |
| 失败回退 | 不保留失败小关内获得的收益，回到进关前状态。此前已通过关卡的成果保留，不增加额外失败惩罚。 |
| 存读档 | 多个手动档加自动续档；战斗中退出恢复本关进场前，已胜利待结算恢复同组候选。读旧档整体回退当时人物、装备、开池与战果，不与之后收益合并。 |


剧情回顾和已读历史依当前存档及当前版本脚本显示；回顾不执行奖励或改动正式剧情断点。

## 尚待确定

- 三国覆亡原因、时间距离、主角更具体的身世，以及其余战役的人物、冲突和女性人物关系。
- 州域边界、主线阶段的行动次数、期限及未参与战事的后果；当前只实现白门楼区域。
- 后续战役的具体人物禁入条件；首章外的装备、能力、数值与构筑平衡。
- 整章实际游玩节奏、战斗音画听感及人物互动的用户体验，需结合真实反馈调整。
- 召唤者阵亡后的召唤物处理、长期剧情状态例外、主动放弃出征及未生成结果的随机细节。
