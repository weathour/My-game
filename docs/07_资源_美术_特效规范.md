# 资源、美术与特效规范

## 建议规格

- 游戏 UI 与可玩性验收基准分辨率：`1280x720`；`1600x900`、`1920x1080` 为支持档位，不得只按最高档验收
- 角色：`256x256`
- 小怪：`128x128` 或 `256x256`
- Boss：`512x512`
- 子弹 / 小图标：`64x64` 或 `128x128`
- 普通特效：`256x256`
- 大招特效：`512x512` 到 `1024x1024`
- UI 图标：`64 / 128 / 256`
- 按钮：`320x120` 或 `420x140`
- 面板：`512x256` 或 `1024x512`
- 祝福 / 奖励卡片：`420x220`

## 资源格式

- 角色、特效、UI 优先使用 `PNG`。
- 背景大图可使用 `JPG` 或 `PNG`。
- 文字尽量和底图分离，便于后续修改和本地化。
- 不提交 `.DS_Store`、`__MACOSX/`、`._*` 等操作系统或压缩包元数据；这些文件不参与运行且会污染素材目录。

## 特效原则

- 特效必须服务玩法辨识，不只是好看。
- 玩家应能一眼看出是谁的技能、打哪里、和其他技能有什么不同。
- 特效范围尽量贴近真实伤害范围。
- 不允许“看起来打到了但没伤害”。
- 不允许“没碰到却判定中了”。
- 如果特效和判定冲突，优先调整判定贴合特效。

## 替换原则

- 替换资源时优先保持逻辑接口不变。
- 不因为换图就重写整套判定。
- 只有新特效表达方式完全变化时，才调整对应判定逻辑。

## 机械师美术资产与生成管线

- 机械师角色精灵表：`assets/players/mechanic/mechanic-idle.png`（2940×138，12 帧 245×138 横排）/ `mechanic-run.png`（1024×768，12 帧 256×256，4×3 网格），同目录附 `.aseprite` 源文件（12 帧逐帧还原，可用 Aseprite 直接编辑），场景为 `mechanic.tscn`（结构与 wizard.tscn 一致：内部缩放 0.65，外部缩放 1.7，与法师同）。
- 为与现有三角色保持同一画风与体量，精灵直接以法师（wizard）精灵表为底派生，整体形象参考《兰斯》的玛利亚·卡斯坦古：发色替换为明蓝长发（navy 族在原派生基础上 +Δ(14,48,58)），法袍色系替换为米白实验大褂，青色装饰替换为钢蓝，法球替换为琥珀能量核心；当前版本为无外加装饰的干净形象——无圆眼镜、无扳手/电钻、无红领带，由 `scripts/tools/rebuild_mechanic_clean.py` 重新派生（从既有成品表恢复 wizard→mechanic 颜色映射表，剔除工具/领带/眼镜污染后逐像素重映射法师表；法球紫芯与其暖色光晕手工映射为琥珀族，曾被误删的嘴部像素一并恢复）；体型、动画帧与法师逐帧一致。历史上曾经 `scripts/tools/refine_mechanic_maria.py` 二次加工补画圆眼镜、扳手/电钻与红领带，该版本已被干净版取代。
- HUD / 营地头像：`assets/UI/facility/机械师head.png`（36×36，`mechanicchange.tscn`）与 `assets/UI/facility/机械师.png`（128×128，`mechanichead.tscn`），由术师对应徽章派生：发色薰衣草紫→藏蓝、徽章环→琥珀橙；当前版本不含圆眼镜（由 `scripts/tools/rebuild_mechanic_clean.py` 以同样的映射表方式从术师徽章重新派生）；人设草图为 `assets/sketch/人设草图/机械师草图.jpg`（与其他三名角色的草图保持同一手绘风格）。
- 特效序列帧：`effects/mechanic/` 共 10 组（spider 4 帧 128×128 普攻追踪小蜘蛛、drone 4 帧守卫机器人、mine 8 帧、emp_burst 6 帧（旧版跟随力场循环，现力场改为程序化波纹+中央力场塔后该组仅作素材保留）、tulip_turret 3 帧定点机炮、heavy_cannon 3 帧重型炮台（履带底盘+双联炮管）、field_tower 3 帧力场塔（线圈塔+脉动光球循环）、ult_warning 3 帧、ult_explosion 7 帧），除 spider 外全部 256×256、单色数 ≤8；三种塔由 `scripts/tools/gen_mechanic_turrets.py`（PIL 64×64 原尺寸绘制后 NEAREST ×4 放大）生成，机械风琥珀/钢蓝配色，炮口含开火闪光帧与烟雾帧；按帧实测视觉半径并换算 scale，使视觉范围贴合真实伤害半径（落实上方"特效原则"）。普攻蜘蛛经 bullet.gd 的 `custom_sprite_frames` 配置渲染（命中即销毁）。磁滞力场的"一圈一圈的波"为 `mechanic_emp_burst_ability.gd` 内置 `FieldRippleVisual`（Node2D `_draw` 画弧）程序化绘制，半径与 FIELD_RADIUS=450 一致；重型炮台视觉 scale 0.8、偏移 (0,-104)、子弹视觉 3.6 倍，明显大于定点机炮（0.25）。
- 生成管线：本地编译的 Aseprite（headless 后端）+ `aseprite-live-mcp`，Kimi MCP 配置在项目 `.kimi-code/mcp.json`，仅对新会话生效；生成结果经 QA 规格检查后接入。

## 当前阶段

- 当前大量素材仍是测试贴图或测试特效。
- 现阶段目标是可替换、可运行、可验证观感。
- BGM 是非商用占位素材，发布前需要替换或完成授权确认。
