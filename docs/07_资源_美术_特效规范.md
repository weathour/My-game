## 新人物卡的制作分层

用户最新要求：此后新制或重制的人物素材使用带透明背景的RGBA PNG，包括角色设定图、立绘、战斗人物与头像。人物本身不烘入纸底、场景或稀有度色；立绘作为独立人物层直接叠在场景上。

从人物母版到战斗动作、头像、Aseprite导出与游戏验收的步骤见[角色战斗美术制作流程](art/角色战斗美术制作流程.md)。

卡面按稀有度独立制作背景，人物、卡底、边框及文字分层。本轮确定普通蓝、稀有紫、传说金橙，以及非抽取层级的主角专属朱红；新增显式 `rarity` 与人物分类 `kind` 独立，不将“重要人物”自动等同传说，也不改变抽率、剧情资格或章末重要人物保底。暂定分类及实施状态见[本轮记录](implementation/2026-10-27_人物稀有度与编队加成.md)。三张透明图集仍供部分人物使用；九位女性的独立透明母版已接入卡面、人物详情与对白，其余未覆盖人物继续使用现有素材。九人独立战斗头像与 180 帧动作也已接入，见[母版与素材记录](../design/baimen-women-20261028/README.md)。

贾苇索以同一身份分出起家、诸侯与日常用途服装，延续脸部与发色等识别特征；服装参考汉代衣形，具体配色和饰物为游戏创作。资料依据见[主角服饰参考](../design/jia-weisuo-20261027/references.md)。

用户已明确：只有重点人物需要专门绘制，其他普通N卡可用基础素材微调、改色扩充。人物可以跨战役重复登场，不因每章出现而重新制作一套卡。新人物卡目录见[白门楼卡池草案](design-reviews/2026-10-26_白门楼人物卡池与剧情解锁.md)。

建议N卡按刀盾、长兵、弓弩、骑战、术法、后勤等基础轮廓复用，以服饰、武器、头饰、脸部和配色区分。卡面、战斗动作和后台效果分别复用，不要求每张卡拥有独立全套资源。美术相似不等于同一人物；人物ID、能力差别和等级各自保留。具体模板与重点名单仍待人物设计确定。

## 建议规格

- 游戏 UI 与可玩性验收基准分辨率：`1280x720`；`1600x900`、`1920x1080` 为支持档位，不得只按最高档验收
- 角色：`256x256`
- 小怪：`128x128` 或 `256x256`
- Boss：`512x512`
- 子弹 / 小图标：`64x64` 或 `128x128`
- 普通特效：`256x256`
- 大招特效：`512x512` 到 `1024x1024`
- UI 图标：`64 / 128 / 256`
- 按钮：`320x120` 或 `420x140`
- 面板：`512x256` 或 `1024x512`
- 祝福 / 奖励卡片：`420x220`

## 资源格式

- 角色、特效、UI 优先使用 `PNG`。
- 背景大图可使用 `JPG` 或 `PNG`。
- 文字尽量和底图分离，便于后续修改和本地化。
- 不提交 `.DS_Store`、`__MACOSX/`、`._*` 等操作系统或压缩包元数据；这些文件不参与运行且会污染素材目录。

## 特效原则

- 特效必须服务玩法辨识，不只是好看。
- 玩家应能一眼看出是谁的技能、打哪里、和其他技能有什么不同。
- 特效范围尽量贴近真实伤害范围。
- 剑士普攻刀光按传入的斩击长度、宽度缩放，不再固定为 22×77；重剑范围加成同步反映在刀光上。横向翻转使用相同宽度计算偏移；角色到刀光之间的命中补偿区域仍保留。
- 不允许“看起来打到了但没伤害”。
- 不允许“没碰到却判定中了”。
- 如果特效和判定冲突，共同校正视觉与实际判定，保证预告覆盖真实危险并有可达的安全路径；不要为了配合素材擅自扩大未预告的伤害。

## 替换原则

- 替换资源时优先保持逻辑接口不变。
- 不因为换图就重写整套判定。
- 只有新特效表达方式完全变化时，才调整对应判定逻辑。

## 机械师美术资产与生成管线

- 2026-10-13 起使用独立机械师素材。人物参考玛利亚的蓝发、圆眼镜、红发带、米色多口袋工具外套、深色高领和工靴；武器动作改为检查、按压部署控制器。原图与提示词见 [机械师重做记录](../design/mechanic-rework-20261013/README.md)。
- `assets/players/mechanic/`：待机 `mechanic-idle.png`（384×96，4 帧）、奔跑 `mechanic-run.png`（768×96，8 帧）、操作 `mechanic-command.png`（384×96，4 帧），均为 96×96 横排帧，脚底基线 y=88、二值透明、共同调色板不超过 64 色；对应 `.aseprite` 文件可直接编辑。待机/奔跑/操作分别 5/11/12 fps。
- `mechanic_visual.gd` 与 `mechanic.tscn` 提供独立的动画状态。所有源帧朝右，朝左统一水平翻转；操作期间记录移动状态，结束后恢复当前待机/奔跑，重复触发不会不断重播第一帧。普攻释放蜘蛛、五种主动技能、进场和终极技能接入操作动作。战斗和营地外部缩放均为 1.1，待机约 86–88、奔跑约 86–89 场景像素高，接近其他英雄的约 76–93 像素范围；战斗基准位置为 `(0,-4)`，脚底约在角色原点下方 40 像素，不叠加法师式悬浮摆动。
- HUD / 营地头像：`assets/UI/facility/机械师head.png`（36×36）与 `机械师.png`（128×128）来自本次单独生成的近景头像；编辑源为 `mechanic-portrait.aseprite`。角色面板使用待机首帧裁区 `(22,8,44,80)`；备用立绘为 `mechanic-standing.png`。旧手绘草图不再作为当前机械师的运行时回退图。
- `effects/mechanic/` 当前使用 8 组、35 帧：`spider` 4、`drone` 4、`mine` 8（2 帧待机 + 6 帧爆炸）、`tulip_turret` 3、`heavy_cannon` 3、`field_tower` 3、`ult_warning` 3、`ult_explosion` 7。均从 64×64 原生 Aseprite 序列输出，蜘蛛放大到 128×128，其余放大到 256×256，每组至多 64 色。`emp_burst` / `missile_volley` 两组旧 PNG 不参与当前运行时，本次未更新。
- 装置统一为象牙装甲、黄铜/铜件、深色底座和红色郁金香标记；机炮为支脚底座，重炮为履带底座，力场塔为蓝色线圈塔，守卫使用盾牌与推进器。小机炮/重炮/力场塔显示缩放分别为 0.35/0.65/0.4。炮台保留存档中的瞄准角，精灵抵消旋转并水平翻转，以保持底座直立；开火从炮口出弹，动画结束回静止帧。
- 预警/爆炸按导出 alpha 边界实测最大半径 99.8/123.8 像素换算显示尺寸，地雷爆炸同样采用 123.8；技能的判定半径、伤害、冷却、存档结构保持原规则。力场波纹仍由 `FieldRippleVisual` 按真实半径 450 绘制。
- 生成使用内置 `image_gen`，切帧、锚点校准、最近邻缩放、调色板归并和导出由 `scripts/tools/import_mechanic_art.lua` 在本地 Aseprite 中完成。旧法师改色与 Pillow 几何绘制脚本已删除；重新生成原图后必须复核裁区和锚点，不能直接按假定网格覆盖。
- 验证入口：`scripts/tests/mechanic_visual_smoke.gd`（动作切换、朝向、炮台回位和存档恢复）、`scripts/tests/mechanic_roster_smoke.gd`（队伍、技能和存档），以及 `scripts/tests/mechanic_art_preview.gd`（实际 Godot 纹理动画预览）。
