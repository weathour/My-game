# 资源、美术与特效

当前游戏的可玩范围与验收状态见[当前状态](08_当前实现状态与后续重点.md)；素材来源与分发边界见[第三方说明](../THIRD_PARTY_NOTICES.md)。

人物剧情与卡片使用透明立绘；战斗人物和敌人按脚底及可见身体比例对齐。战斗素材、头像和特效应在真实视野下检查，确保攻击接触、敌方预警、人物与背景的区分。特效表达实际战斗事件，不能改变结算；减闪、减震和静音时仍须保留必要信息。

白门楼使用荒道、旧寨、荒祠、城内、河岸水门和楼前广场六种平面地面主题，B01／B04 的荒道已按实玩反馈调整。地面图案不自动代表障碍；建筑布景与碰撞待后续设计。

人物制作从确认角色形象开始，再制作动作、特效和头像，验证浅色、深色、透明底及真实游戏画面；具体操作见[角色战斗美术流程](art/角色战斗美术制作流程.md)。保留当前游戏需要的原画、源工程、许可及出处；参考风格、生成素材和实际授权范围应分别记录。

配乐与短音效以当前目录及来源记录为准：70 个配乐混音资产的工程说明见[音乐制作目录](../design/music-20261030/README.md)，战斗音效来源见[许可清单](../assets/sfx/chronicle-feedback/source-license-manifest.json)。技术检查不能替代主观听审。
