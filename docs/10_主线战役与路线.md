# 主线战役与路线

白门楼是首个大战役，区域图包含 36 个节点和 18 个战斗节点；单次路线为 12—15 战。人物、装备、剧情与战斗结果在正式战役中关联，实际开放及验证状态见[当前状态](08_当前实现状态与后续重点.md)。

## 两层地图与出征

天下图用于查看地区和选择大战役；战役区域图显示本次出征的节点、路径与分岔。节点浏览、查看敌情和剧情回顾均不推进路线，只有确认前往才选择节点。已通过关卡不能回刷；未通过可重试。后续天下局势、行动次数和其他战役仍待制作。

区域路线的关键前段为 S03 鬼市 → B04 运粮道或 B05 冥市暗巷 → B03 匪寨 → S04 → F01 泉水 → 可选 B06 荒祠或直接 S05 → B07 官署。两条前路互斥后合流；泉水为已获得人物恢复并复活。主线、泉水和战后剧情共 22 个承载点；人物故事与地点器物资料在见闻中按条件阅读。

## 战斗与队伍

开局仅主角，允许两个辅助位为空；首关胜利先选卡，再播放艾玛剧情，她在剧情结束后直接加入。其他人物一般先满足剧情或战后门槛进入卡池，再通过选卡获得；入池、拥有和本关配置相互区分。

每关配置主角和至多两辅助，关间可从全部已获得、存活且符合战役条件的人物中更换。候补冻结；小关胜利后生命、魔法、阵亡和冷却按规则延续，普通临时效果及召唤物清理。泉水和整次出征返营负责恢复；失败撤销本关变化而保留此前成果。

普通战斗在固定时间或足够击杀后出现 Boss；普通五选二，完成抽卡场域精英后五选三。B18 吕布入场即战、独自两阶段应战，不设场域精英；章末七选三并保证至少两张重要候选。已生成的历史正式档七选四候选仍保留，不因此增加新流程名额。

## 剧情与终章

贾苇索为吕玲绮而向白门楼进发，途中与艾玛相遇，经过鬼市、匪寨和官署；抵御鬼曹军之前，他劫掠并侵犯成年吕玲绮，过程淡出而后果不被抹去。随后他参与救城并与吕布交战。当前剧本中吕布留守城内，贾苇索暂驻外署并照看水门外至旧寨的粮道，双方以粮食和通行条件停战；吕玲绮仍保留仇怨。这是具体剧本写法，不增设领地或内政系统。

战役中的人物动机、故事与取材见[剧情文本记录](implementation/2026-10-30_白门楼整章剧情与文本.md)及[人物档案](17_人物档案.md)。具体世界成因、其他战役与关系推进仍未确定。
