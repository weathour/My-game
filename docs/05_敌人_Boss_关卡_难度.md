## 小关行动

一关有起点、战斗中的行动过程和击败Boss的终点。可以采用守住一片战场的形式，四角分布可选场域。玩家在清敌和生存之外，决定是否为额外收益移动并承担风险。

普通小关有四角场域。走到其中一处选择后，其余三处失效；也可以全部绕开，放弃这些资源。B18 吕布终战不设战内场域或额外精英入口。普通场域效果可以包括：

| 场域形式 | 作用 |
| --- | --- |
| 场内补给 | 恢复生命、魔法。 |
| 经验 | 给当前角色少量经验，具体受益者规则待定。 |
| 抽卡挑战 | 召唤额外精英，击败后本关选卡多取1张：普通五选三；候选数量不增加。B18 不提供此挑战。 |
| 装备挑战 | 召唤额外精英，击败后获得可穿戴并保留的装备。 |

以上是已讨论的效果形式；是否每关恰好各放一种、触发范围与确认方式、场域有效时间及奖励数量尚未确定。小关里不再额外叠加固定技能卡选择。

## Boss与胜利

以下门槛、刷怪和援军规则适用于普通遭遇。B18 进关即与人形吕布交战，全程没有自动刷出或召唤的小怪，也无场域选择；击败人形后变身，击败战相才通关。曹休、曹纯、张辽也有两形态；攻击与难度已按本轮样本和代理实际操控检查，后续可根据用户体验继续校准，无小怪规则不推广到所有 Boss。

- 到固定时间Boss直接出现，不要求先清空普通敌人。
- 在该时间之前击杀足够敌人，可以使Boss提前出现。
- Boss出现后停止普通刷怪，保留场上已有敌人及额外精英；无论定时还是击杀数提前出现，都采用这一规则。
- Boss可以按自身机制召唤有限专属援军，援军经验设总量限制，不能通过拖延战斗无限培养。具体次数、数量和经验预算随Boss设计。
- 必须击败Boss才算通关，仅存活到时间不算胜利。
- 在时间内通过可得到额外经验；尚未规定超时失败，不能把奖励时限当作强制结束线。
- 主角死亡导致本关失败；辅助阵亡规则见[战斗机制](03_战斗系统与角色机制.md)。

普通遭遇中，额外场域精英与Boss可同时存在。Boss被击败立即通关，尚未击败的精英不发对应额外奖励，不继续停留补打；已经完成的挑战随本关成功结算。B18 以100秒为首版速胜时限，满足时给予额外18点经验；进场不附赠回血、回魔或补给，数值可随用户反馈调整。

## 战斗经验

已击败敌人掉落经验物，靠近拾取后立即分给本关进场名单；一人全得、两人各半、三人各三分之一，阵亡不减少分配人数。击败Boss后自动收取所有尚未拾取的经验，包括Boss应得经验，不再留场捡取；存活敌人不产出补偿经验，未击败精英也不补发挑战奖励。

通关自动收取的经验按同一升级规则处理，存活人物升级回满生命和魔法，阵亡人物仍不复活。战后新加入人物不追分本关经验。

## 通关收益与后续

普通小关通关五选二，完成抽卡精英后五选三；B18 胜利及章末剧情后七选三并保证至少两张重要候选，取消精英不补发第4个名额。旧档已生成的七选四候选与选择进度保留。重要候选仍须剧情解锁。关间可换人换装，泉水按规则全员恢复。

小关与独立精英关位于第二层战役区域图，沿路线和分支推进到最终Boss；区域图从第一层天下图选择大战役后进入。独立精英关是完整的战斗节点，仍遵守Boss通关、四角场域与关末抽卡规则，不能与小关内场域召出的额外精英混为一谈。恢复、剧情等非战斗节点不自动产生小关抽卡。具体精英关的敌人、额外收益及路线位置另定。

最终Boss关胜利完成整次出征，返营全员恢复并复活辅助，随后结算主线行动与局势。普通小关胜利继续推进区域路线，不自动恢复全队。层级与示例见[主线战役与路线](10_主线战役与路线.md)。

成功关卡不能回头刷。失败回到进关前状态重试，不保留本关内收益。地图、场域、敌人和卡池哪些内容在重试时固定、哪些重新随机尚未决定。

## 内容设计范围

后续关卡需要逐步提供输出、驱散、支援配合和资源维持等不同特性发挥作用的场合；18 个战斗节点的现有敌人与顺序见[敌人图鉴](18_白门楼敌人图鉴与战斗规格.md)，仍需按实玩细化。现有敌人、Boss美术、弹幕与技能实现可以评估复用，不以旧三关、20波或N层曲线限定新主线。
