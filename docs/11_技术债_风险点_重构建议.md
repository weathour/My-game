# 当前工程风险与验证边界

更新：2026-10-31。具体代码状态和迁移结果以[当前状态](08_当前实现状态与后续重点.md)为准；下列风险是检查方向，不表示均已复现为缺陷。

| 关注点 | 必须保护的行为 |
| --- | --- |
| 存档与设置 | 现有 `campaign_v1` 和设置可读取；失败写盘不破坏有效数据，读取回退或再次退出不丢候选、不重复结算。 |
| 跨关与人物 | 辅助资源、阵亡和冷却按规则保留，后台支援与持有加成各按对应状态计算。 |
| 模拟与表现 | 施放来源、目标、实际伤害及死亡顺序一致；特效、限频、音频或镜头不改变战斗规则。 |
| 资源与导出 | 动态 JSON、场景、UID、音频及运行纹理在全新导入和独立 PCK 中可用；只依靠静态搜索不足以证明可删。 |
| 对象生命周期 | 暂停、切人、失败和退出后计时、信号、对象池、音效及视觉尾部正确清理。 |
| 工程收敛 | 复用画面、素材与基础设施时先确定当前调用者；每次删改同步相应行为合同，不以减少测试数或通过空断言代替验证。 |
| 用户体验 | 整章节奏、音效和音乐混音、人物故事及画面审美需要实际试玩和主观听审。 |
