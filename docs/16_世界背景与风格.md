# 世界背景与风格

更新：2026-10-28。背景与整体气质来自用户确认；具体场景、关系推进方式与数值仍供讨论。玩法以[当前设计共识](00_当前设计共识.md)为准，当前实现与验收状态见[状态入口](08_当前实现状态与后续重点.md)。

## 已确定的背景

- 世界是架空三国，三国已经覆亡，天下成为遍布遗迹与鬼怪的世界。
- 男主姓名确定为**贾苇索**。“苇索”取缚鬼之索的意象，并谐音“猥琐”；“贾”谐音“假”。用户明确他在大事上极其正义、极有正气，形成表面风流胡闹与重大抉择之间的反差。
- 三国名将主要以亡魂或异变形态重现。不能再默认人物是正在经历汉末史事的在世武将。
- 《黑神话：悟空》作为风格参照之一；整体风格仍需调整、结合其他气质，不锁定为单一黑暗风格。
- 用户认可苍凉威严、山河壮丽、民俗奇趣与英雄情义几种气质，并要求大量女性角色的暧昧氛围，以“醒掌天下权，醉卧美人膝”表达期待；这部分希望约占整体体验的一半，与征战和成长并列投入。
- 用户进一步纠正：风格直接参考《兰斯》，不必把人物互动设计得过度讲究。此前细腻恋爱养成、统一循序渐进关系流程的提议撤回；采用更直白的欲望表达、成人喜剧与冒险群像作为风格参照，具体剧情按事件逐步创作。
- 用户强调天下的残酷与血腥，以及这种处境下主角作为庇护者的相对位置：即使主角好色、会骚扰或有更严重的越界，人物仍可能因其实际保护而依附于他。这种矛盾关系需要进入背景理解，具体行为与桥段未定。
- 女性阵容的来源暂不限定。用户明确先讨论征战与暧昧关系的整体体验，不在当前决定历史女性、原创人物或武将女性化的取舍。
- 长期体量仍参照《兰斯10》第一部，先做入门战役；天下图、战役区域图、实时战斗和人物成长规则沿用已定框架。

开局确定为覆亡世界中的白门楼鬼城战役。历史事件可成为遗迹、人物关系和新战事的来源，不按历史黄巾起义或讨董时期重演；此前“县城解围”方案由白门楼主线替代。

## 男主：贾苇索

贾苇索是本世界原住民，行事无法无天；姓名与“大事上极其正义、正气”的性格底色已确定。名字包含三层含义：

1. **苇索缚鬼**：联系本作遗迹鬼怪世界及护人、制恶的意象。《论衡·订鬼》所引神荼、郁垒传说记载“恶害之鬼，执以苇索”，可作为典故依据，见[原文](https://ctext.org/lunheng/ding-gui/zhs)。
2. **苇索／猥琐**：名字在日常对白中带来滑稽与风流的第一印象。
3. **贾／假**：主角面对大事时显露极强的正义与正气，与名字造成的印象形成反差。

《兰斯》仍是成人冒险、直接欲望和胡闹的风格参考，贾苇索的大事立场以用户新确定的正义底色为准。此前“具体性格未定”现收窄为日常细节、身世、存在形态和具体事件未定，不再把主角是否在大事上坚持正义列为开放问题。

后续白门楼剧情明确：贾苇索在抵御鬼曹军前劫掠并侵犯成年吕玲绮，用户希望以此突出恩怨和他的不正派。人物因此同时包含救城等正义选择与严重恶行；“假猥琐”不表示其全部不义行为都是伪装。侵犯只作非露骨事实交代，略去过程，后续承接人物反应和冲突。

写法建议：平常的好色、嘴欠和胡闹可以保留；关键时刻用实际选择、行动与承担表现他的正气。“假猥琐”不自动意味着所有欲望都是伪装，也不把尚未编写的越界情节预先解释成善行。具体桥段仍待设计。

苇索目前是姓名寓意与可用的视觉意象，尚未确定为实际武器、抓鬼职业、神祇传承或技能机制；默认强力近战的战斗方向保持不变。

## 异世来客与开局同伴

贾苇索是这个世界的原住民，艾玛、女剑士、枪手与机械师是陆续出现的穿越者。她们不必来自同一个原世界，也不要求共享同一种穿越原因；具体来源以后随战役确定。贾苇索并不把追查穿越之谜作为当前动机，人物因相遇、冲突和共同处境进入他的征途。

- **艾玛**：迷失在陌生鬼怪世界的成年异世西方魔法师，复用本仓库已有魔法师角色。首遇发生在前往白门楼的路上，尚未进城。贾苇索轻浮搭讪，擅自做主将她强拉上路；她警惕、恼火并反抗，随行不表示她已信任或爱慕他。此前记录的欺骗、强迫与性关系不在本次相遇片段中展开，具体时点与承接仍待编排，不因省略过程改变事件性质。
- **女剑士蕾娜**：撤回开篇被掳的安排，在 S06 官署事件中获救并相遇，剧情完成后入池；她不自动获得，玩家需在后续选卡时选择。相遇、实际获得和人物相处分别交代，不由救援自动推导亲密关系。
- **枪手、机械师**：在后续某战役的遭遇节点陆续出现，均为穿越者；不默认加入白门楼卡池，也不重新组合成开局四人团。战役、节点和具体加入事件以后落实。

新游戏只有主角、两辅助位为空；首关战后先完成普通五选二，抽卡精英成功则完成五选三，随后进入艾玛剧情，剧情结束后她才直接加入并入池，不占选卡名额，后续可以重复抽取培养。她的剧情处境和人物卡获得分别记录；不是通过选择亲密行为发放角色奖励。复用现有魔法师的角色素材不等于沿用旧技能树或旧成长体系。

本世界已出场人物中，鬼市医者田秀精打细算地维持药摊，寨中匪首马三娘在寨旗落后为旧部安排去留；两人都有各自的目标和与贾苇索合作的条件，详见[人物档案](17_人物档案.md)。S03／S04 是相识和入池条件，不直接赠送人物，也不由此确定她们的存在形态或感情态度。

## 风格组合

古老遗迹和亡者构成共同基础，通过地区、人物与情境形成不同感受。下表气质方向已获认可，具体表现仍是提案，不是完整美术规格。

| 气质 | 可以怎样表现 | 对体验的作用 |
| --- | --- | --- |
| 苍凉与威严 | 被草木吞没的汉阙、断裂的巨型石像、仍列阵的无主军队、埋在地层里的宫城。 | 建立曾经庞大的文明和军势留下的重量。 |
| 山河与壮丽 | 日照下的高台遗址、辽阔江面、青绿山谷、风中大旗；异象可以在明亮环境中出现。 | 让长途行军和地域变化有开阔感，并与阴森地带形成节奏变化。 |
| 民俗与奇趣 | 渡口引路的纸马、会讨价还价的鬼商、替亡者点灯的精怪、遵守古怪规矩的集市。 | 让鬼怪世界有日常关系、可亲近的角色和意外的发现。 |
| 英雄气与情义 | 名将保留性格、野心、骄傲、旧怨与重诺；败亡后的选择重新塑造其形象。 | 支撑招募、陪伴、势力冲突与长期人物培养。 |
| 风流与成人喜剧 | 主角直白的私欲、调侃、争风吃醋、胡闹和各式人物桥段；与战争、冒险和重要剧情穿插。 | 女性魅力与风流内容占据重要分量，事件可以直接、有趣并迅速建立人物印象。 |

场景可使用石灰、铜绿、朱砂、金色、天青和灯火暖色；具体色板尚未决定。现有深绿、酒红和古金界面作为可复用资产保留，不据此锁定新世界所有场景的配色。

### 三个场景试想

- **白昼古关**：断墙间长出大片野草，日光照着高大的残阙，城上破旗依旧飘动；石阶上有身披旧甲的军魂驻守。压迫感来自尺度与秩序。
- **暮色鬼渡**：江面倒映灯笼，舟上有摆渡者和做生意的亡魂；远处水下显出沉城轮廓。这里可以兼有补给、人物会面和未知危险。
- **夜间旧战场**：折断的兵器与军旗间响起行军声，鬼兵从不同方向聚集，最终出现守在遗址中的强敌。这里承担集中、强烈的战斗压力。

这些场景旨在比较气质，不代表首战已经包含三个地点，也不新增昼夜系统、双世界切换或其他玩法系统。

## 征战与女性人物关系

用户要求这部分约占一半，并明确“像兰斯一样就行”。该要求指向作品的重要吸引力和总体风格，具体内容量与时长未定。女性来源仍暂不限定。当前不预设独立恋爱养成系统，也不要求每个角色完整经历相遇、信任、偏爱和告白的统一过程。

### 原作风格核对

- [官方兰斯简介](https://www.alicesoft.com/rance10/chara/rance/01.html)直接把主角写成自我中心、好色、强横的反英雄。他的私欲是鲜明的行动动机，不应把原作概括成温柔、循序渐进的恋爱风格。
- [《兰斯10》剧情介绍](https://www.alicesoft.com/rance10/story/index.html)将大规模战争与主角过往的女性关系联系起来：各地区领导人与兰斯的私人关系直接进入联军统帅的设定。宏观征战与人物关系本就处于同一故事中。
- [官方系统介绍](https://www.alicesoft.com/rance10/system/index.html)明确据点阶段包含日常、会面与成人事件；任务路线也有对应事件节点，食券则用于观看人物片段并获得经验。可以参考事件穿插的位置，不自动照搬食券、阶段数或奖励规则。
- [TADA访谈](https://news.denfaminicogamer.jp/projectbook/190801a)谈到初作的起点就是把喜爱的奇幻RPG与成人题材、女性角色结合。这里核对的是创作方向，不把全部系列桥段视为本作必须复刻的内容。

据这些材料及用户指定的参照，本作按“直白欲望、夸张人物互动、风流与胡闹、宏大冒险中穿插重要剧情”理解风格。该概括是设计判断，不声称原作所有角色或所有桥段采用同一写法。

### 对本作的调整

- 贾苇索日常行动可以直接出于好色、好胜、面子、好奇或想要某件宝物；遇到重大是非时，以已定的正义与正气为人物底色，具体事件随后设计。
- 女性角色用鲜明性格、外形、立场和具体事件建立吸引力。可以安排直接的调情、拌嘴、争宠、闹剧和温情，关系深浅与篇幅因人物而异。
- 人物事件可发生在招募、路途、关末、返营或剧情条件满足后。优先随实际人物与战役编排，不预设一套必须逐级完成的关系仪式。
- 遗迹、鬼怪与天下局势保留苍凉和威压；人物对白与日常允许活泼、粗俗和荒唐，重大事件仍可认真展开。
- 成年女性人物可以保有人形与可亲近的魅力，亡魂、异变等特色按角色表现；具体名单、来源及形态仍未定。

此前“出征—同行—返营相处—再行动”的完整关系循环，以及人人依靠共同经历逐步建立亲密的建议不再作为设计要求。角色等级、重复卡、后台支援和持有加成仍沿用既定规则；是否另设关系数值以后按内容需要决定。

### 残酷天下与庇护者

用户希望利用环境与主角的反差：身处失序、战争和鬼怪威胁中的人物，可能将主角视为更可靠的生存依靠，即使并不认可他的全部行为。随着贾苇索的性格底色确定，他在大事上的正义与实际保护也成为这种依靠的依据；日常缺点与具体事件仍可保留复杂性。

写法建议：把主角实际挡住的危险、提供的落脚处和维持的秩序写出来，同时保留人物对其越界的不满或反抗。庇护来自保护和安全，骚扰或侵犯本身仍会造成伤害；感激、依赖、欲望、喜欢与怨怼可以并存，不必统一解释成爱情。具体人物用行动和简短事件呈现这些差异，无需另建复杂关系机制。

### 亲密事件的文本表达

用户指定：涉及成年角色的性关系情节，以“抱”作为代称，具体过程淡出或跳过，后续按已经发生关系承接。包括剧情明确为强迫的事件，也采用非露骨、略去过程的写法。

省略过程不改变事件性质。后续依人物与情境表现其反应，发生关系本身不自动等于相爱、原谅或好感提升；不另行增加关系养成流程。日常字面拥抱与上述代称由上下文区分。

### 对开发首段的影响

首场战役需要尽早展示主角脾气、女性角色魅力和几段有记忆点的互动，具体数量与位置随剧情决定。优先让玩家从事件中直接感受到这类成人冒险的风格；不要求首段完成一条完整恋爱成长线。

用户已确认剧情采用场景背景、透明人物立绘和底部对白框，按句推进并显示姓名、突出说话者；可按内容安排表情、姿态、转场与音乐。首段对白已经编写，其他人物桥段仍随战役规划；实现和视觉验收以[状态入口](08_当前实现状态与后续重点.md)为准。天下图与战役区域图沿用既定结构，不新增关系专用战略地图层；返营场景的规模由实际事件需求决定。

## 与主线和人物的关系

建议让亡魂、精怪与异变人物仍有各自的欲望和关系：有人维护旧日秩序，有人扩张势力，有人守住一处遗迹，也有人想离开过去。各地冲突可以来自这些不同目标，具体势力与主线目的还未确定。

人物的亡魂或异变形态应和其经历、性格、执念或所在遗迹有关，能从外形和行动中辨认其身份。名将可以拥有各异的形态，普通鬼怪也可以成为盟友、商人或引路者；具体角色不在本轮定表。

天下图仍展示州或较大的地域模块，但地区信息需要按覆亡后的世界编写；不能继续默认是历史在世政权与人口的现状。战役区域图仍承载关卡、精英、恢复和事件节点，地点可选古关、沉城、陵墓、祠庙、旧战场和聚居地等。

首场战役已明确为[白门楼鬼城](design-reviews/2026-10-26_首段教程战役与分阶段开发.md)：贾苇索因绝色女公主吕玲绮而出征，途中在去白门楼的路上遭遇异世魔法师艾玛，杀匪杀官、掠地壮大；过程中抵御鬼曹军，救下城池及吕布一家，最后对战吕布，踏上诸侯起家之路。首位同伴艾玛和单人开局已定，蕾娜在 S06 获救并入池。本轮剧本让吕布和吕玲绮战后存续，吕布留守城内，贾苇索暂驻城外官署并守水门外至旧寨的粮道；彼此定下通行和粮食条件，吕玲绮仍保留对侵害的仇怨。这是本轮具体写法，不表示用户逐句批准或新增内政系统。

## 接下来需要确定的背景问题

1. **覆亡后的世界怎样运转**：灾变的性质、距覆亡多久、是否仍有活人、亡者是否理解自己的状态。先选足以支撑首战的答案。
2. **贾苇索是什么存在**：姓名、男性主角和重大是非上的正气已定；身世、存在形态、与这个世界及三国人物的关系、出发缘由和聚集队伍的原因待定。
3. **天下冲突的主线**：各方争取什么，玩家的行动怎样改变地区和后续路线。
4. **人物与桥段**：参考《兰斯》的直接、胡闹和成人冒险气质，结合贾苇索已定的正气，设计首段日常表现、人物冲突与有效事件；当前不限定女性角色来源，不把完整恋爱系统当作前置设计任务。
5. **白门楼区域与人物**：首战地点、城内外路线、艾玛能力、蕾娜相遇、救城与终战的衔接及起家的具体剧情已按本轮文本落实；后续体验与平衡仍需连续试玩。

人物卡的叙事解释、辅助复活与泉水的世界观解释可以在此基础上补充。当前只改变背景前提，不新增仪式资源、解咒成本或死亡惩罚。

## 2026-10-27 界面风格落实

用户否定了前两张试稿的页游感，明确美术靠拢《三国志》系列、布局与操作组织参考《兰斯10》，并认可朴素化D稿。当前已据此完成操作界面框架，见[制作记录](design-reviews/2026-10-27_操作界面风格与制作方向.md)。这确定了界面材料、地图尺度和人物呈现方向，不自动定稿全部关卡美术与故事。
