# 世界背景与风格

规则依据[设计共识](00_当前设计共识.md)，当前人物见[人物档案](17_人物档案.md)。

三国已经覆亡，天下遍布遗迹和鬼怪，名将多以亡魂或异变形态重现。整体结合苍凉威严、山河壮丽、民俗奇趣与英雄情义；女性人物的暧昧、风流及成人喜剧与征战共同构成重要体验。人物关系直接、有趣，不强制所有人经历统一的恋爱成长程序。

贾苇索是本世界原住民，强势、好色、行事无法无天。“苇索”有缚鬼意象，也谐音“猥琐”；这个名字不是技能或身世的既定说明。他在重大抉择中能挺身救人，也会作出真实的严重恶行，不能把一切越界解释为玩笑或伪装。

白门楼故事中，他听闻吕玲绮而出征，途中与异乡魔法师艾玛相遇，经历鬼市、匪寨和官署，在抵御鬼曹军前劫掠并侵犯成年吕玲绮。叙事对侵害过程淡出，承认事实并保留后果。之后他参与抵御鬼曹军、与吕布交战；救城不自动抵罪或取得吕玲绮原谅。战后，外署义勇、寨众和乡人拥立贾苇索为一方诸侯，他拥有驻地与人马、守水门外至旧寨粮路；吕布守内城，双方分守互盟。该段剧情与场景演出已接入并通过工程检查，不新增内政系统。

艾玛是异乡来客，首战结算选卡后的剧情结束才直接加入；她的抵触和警惕不因入队消失。蕾娜在 S06 相遇并入池，入池不等于拥有。田秀、马三娘等本地人物有各自的处境和合作理由；其他人物的相遇、实际获得、在场及关系各自按事件表达。

成年角色的性关系情节按用户要求以“抱”代称，过程淡出或略去；省略不改变是否强迫等事实。人物可以感激、拒绝、取笑、亲近或怀恨，不由关系发生自动推导好感或原谅。女性角色来源与具体关系推进方式仍可随战役设计。

尚未确定的包括覆亡成因与时间、贾苇索具体身世、其余地域与势力、后续战役和人物关系。世界可以同时呈现开阔山河、破败城郭、热闹鬼市和严肃冲突；具体场景以实际战役与素材为准。
