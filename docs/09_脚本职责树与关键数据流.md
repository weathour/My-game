# 脚本职责与关键数据流

更新：2026-10-31。具体脚本接口以当前代码为准；实现与验收状态见[当前状态](08_当前实现状态与后续重点.md)。

## 战役与战斗

页面选择节点 → 战役服务检查可达性与编队 → 固定进关快照 → `BattleSession` 在工作副本运行 → 成功结果进入待结算或失败恢复 → 奖励确认及路线推进 → 原子保存。浏览路线、敌情或剧情回顾不会推进实际状态。

战斗中自动攻击、技能与支援进入能力和伤害结算，记录施放来源与目标；敌人死亡、经验、Boss 规则和精英结果再由会话推进。当前前台与后台共享本关时钟，各人物拥有独立生命、魔法和冷却。切人不重建人物资源。

战斗画面读取状态及事件，表达命中、盾挡、死亡、拾取、升级和精英收益；合并画面与限频不改变模拟结算。场地只作画面，不额外增加碰撞。

## 剧情与存档

主线、人物故事、条件反应及资料从 `assets/data/chronicle/` 读取。已完成剧情只读回顾；多个人物故事各存逐句断点，已读内容可回顾，锚点反应按首次上下文固定，资料只读。

正式进度位于 `user://chronicle_campaign_v1/`，自动档及手动档保存人物、队伍、装备、路线、剧情与待结算状态。战斗退出恢复进关前；胜利后未选完的奖励沿用同一组候选和已选进度。临时文件、主备回退和写入失败回滚保护由正式保存流负责；设置使用当前游戏共用的设置路径。

迁移须验证既有正式档及设置，不主动删除玩家磁盘数据。用户没有要求将旧故事或无尽档迁入当前游戏。具体动作及控制见[界面与存档](06_UI_菜单_存档_音频.md)。
