## 版本与边界

| 版本 | 用途与范围 |
|---|---|
| C | 现有游戏音色的响度匹配参考，保留现有成品的声音处理。 |
| D1 | 用中国器乐音色重新分配部分声部，保留源音符事件；D1 MIDI 为源 MIDI 的逐字副本。分配写入计划并由渲染器执行，普通 MIDI 播放器不会自动还原试听音色。 |
| D2 | 沿用 D1 的乐器分配与混音设置，仅对选定中国器乐旋律骨干作有限的相邻半音音高调整；它不是将整首所有声部强制五声化。 |

十二首源 MIDI 未覆盖，D2 保留音符数量、起止时间、力度、速度信息，以及鼓、贝司和受保护的吉他骨架。中国器乐使用首轮锁定的琵琶、阮类、古筝、二胡音色；厂商标记与实际采样来源见[音源说明](../../design/music-20261104-chinese-12/THIRD_PARTY_NOTICES.md)。

C 的既有声音处理不随本轮统一改写：The Nobodies、Man That You Fear、Deformography 和 Minute of Decay 的原 C 版已有总线压缩，D1／D2 不使用总线压缩。因此 C 与新版本的动态差异不全来自换乐器；比较有限调式变化时，以相同分部与处理的 D1／D2 为主要对照。具体见[既有处理记录](../../design/music-20261104-chinese-12/reports/C-historical-processing.json)。
