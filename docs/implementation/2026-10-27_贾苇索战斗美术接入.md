# 贾苇索战斗美术接入

日期：2026-10-27。本轮素材已接入并完成程序复验；动作与实战观感仍待用户审看。

## 素材与制作

沿机械师素材制作流程，以用户确认的贾苇索起家立绘为人物母版，机械师动作图仅作像素风格与流程参考。内置 ImageGen 生成透明RGBA源图；Aseprite脚本按连通区域提取、人工量测髋部／地面锚点、固定比例缩放，人物帧使用不超过64色的共同调色板与二值透明。源图、提示词、导出命令及可编辑文件见[素材记录](../../design/jia-combat-20261027/README.md)。

运行目录 `assets/players/jia/` 包含刀／枪各待机4、奔跑8、攻击4帧，共32个人物帧；横斩、突刺、横扫特效各4帧，共12帧。人物帧192×192、锚点 `(96, 176)`；站姿身体80像素乘0.9对应72世界单位，奔跑／攻击俯身不强行拉高。源图中合并或枪头反向的候选未采用，枪攻击第4帧复用准备帧。HUD头像使用单独生成的像素近景，按64像素原生尺寸整理后导出128像素。

## 表现与规则边界

贾苇索战斗形象独立替换旧剑士临时素材，其他角色不变；长枪装备使用持枪动作。沿用现有八向移动与左右镜像，攻击和特效朝实际目标。成功施放才播攻击；失败、冷却或缺目标不触发，手动技能优先普攻。攻击姿态从接触帧开始匹配即时伤害，不锁移动或改变战斗数值。特效跟随战斗时间，暂停与结束清理沿用既有行为，三角HUD使用新头像。
