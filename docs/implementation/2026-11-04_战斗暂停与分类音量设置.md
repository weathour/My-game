# 战斗暂停与分类音量设置

日期：2026-11-04。状态：声音设置已接入，专项、完整工程首轮和修正导出规则后的本地测试包复验均通过；实际听感与操作体验待反馈。

## 操作方式

战斗中按 Esc 打开“行军暂歇”，从“声音设置”进入暂停内的音量子页，无需离开当前战局。子页按 Esc 或选择“返回暂歇”回到暂停菜单；在暂停菜单按 Esc 或选择“继续战斗”恢复战斗。子页也提供固定的“继续战斗”按钮，直接恢复战斗。

标题与行军菜单的“设定”页复用同一组声音设置。音量内容可滚动，在 960×540 窗口下仍保留返回和继续入口；修改后自动保存，不额外播放声音预览。

## 音量范围

十一项滑块均为 0—100%：

- 总音量、背景音乐、音效总音量。
- 角色普攻、角色技能与支援、怪物攻击、Boss 技能与提示、角色受击与护盾、敌人死亡、经验拾取、升级与奖励。

Boss 提示包含技能预警、形态变化和击败音；“敌人死亡”控制非 Boss 敌人死亡音。另有总静音与音乐静音。音效类别用于在音效总音量之下分别调整，未列为独立类别的音效仍遵循总音量和音效总音量。

## 设置兼容与保护范围

沿用既有音乐音量、音效音量与音乐静音设置；新总音量和八项音效分类默认 100%，使旧设置迁移后维持原有效电平。战役存档结构及音乐、音效素材不因本轮变更而替换；十二首游戏音乐文件哈希与 D2 交付一致。
