# 动态战斗卡顿优化

日期：2026-11-05

状态：本轮优化、动态复测和完整工程检查已完成。

用户反馈技能表现升级版实玩卡顿。本轮保留人物、技能、模型、战斗数值与存档规则，处理技能表现缓存与重复复制、镜头避险查询、武将模型读取、HUD 重复刷新、离线透明边界及完全在视口外的弹体／装饰绘制。默认渲染器由 `mobile` 改为 `gl_compatibility`；节奏战斗仍按原决定暂缓。

[同输入动态对照](../../design/performance-20261105/final-default/comparison.json)的三场战斗共 2940 个活动帧，逻辑事件、怪群抽样、切人时刻与基线一致。热身后的墙钟帧时间 p95 分别为：B01 28.446 → 12.958 ms、B12 50.890 → 31.097 ms、B18 30.972 → 13.242 ms。B12 的 1380 个热身后帧中，超过 33.33 ms 的帧为 892 → 49，超过 50 ms 的帧为 85 → 5。全分位数、夹具生命倍率和设备范围见[性能资料](../../design/performance-20261105/README.md)。这不代表所有帧都达到 60 FPS。

角色资源最多保留当前队伍 3 人的 `SpriteFrames`，切人仍新建控制器；本轮未直接测底层纹理身份或 GPU 上传，重复切人的整帧耗时也没有稳定下降，不能声称切人长帧已消除。优化后 `mobile`／Vulkan 结果只作辅助对照，不是优化前基线。

完整 `scripts/check_project.sh` 本轮实际运行并通过 58 项 smoke（54 项源码、4 项隔离 PCK），退出码为 0，脚本输出 `PROJECT_CHECK_OK`，逐项日志经校验器复核，没有复用旧结果。检查前后 1835 项全局输入、58 个测试入口及 Godot／检查脚本哈希均未变；详见[汇总](../../design/performance-20261105/verification/result.json)与[逐项审计](../../design/performance-20261105/verification/full-suite-audit.json)。

使用本次同一 PCK，在源码外脚本与空工作目录下另行完成[边界像素检查](../../design/performance-20261105/verification/sprite-bounds-pack.json)，6228 项通过，未重新导出；专项日志、夹具和完整数据见[性能资料](../../design/performance-20261105/README.md)。本机测试不能代表其他设备或全部实玩场景，此前技能表现升级的工程交付记录保留为当时基线。
