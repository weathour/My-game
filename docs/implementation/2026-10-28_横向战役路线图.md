# 横向战役路线图

日期：2026-10-28。按用户要求重做白门楼战役区域图；核心交互已接入并完成程序回归，最终画面待用户审看。

## 已确认的方向

以本作古地形、墨绿、旧金与酒红界面为基础，参考《兰斯》的路线信息组织，将当前目录的36个节点排为一条横向连续路线。节点连线来自实际 `next` 关系，分支纵向展开并在真实后继处合流；六段目录作为跳转锚点，不将路线切成六个独立页面。移除遮挡路线的大幅艾玛立绘，人物仍在其他页面出现。

为地图制作五类原创 SVG 小图标：交叉刀剑表示战斗，护颊战盔表示精英，古井水波表示泉水，卷轴表示剧情，城楼将旗表示终战。图标表达节点类型，状态外框另行表达进度；图例提供类型说明，短操作提示放在同一工具栏。SVG 为本作自制的矢量图，不从商业游戏搬运素材；最终造型和画面待用户审看。

地图可拖动或以滚轮浏览，支持定位当前节点；悬停查看信息、点击节点后在右侧“行军路线”查看详情。查看选中与实际行军位置分离，只有右侧确认前往才选择节点；锁定和暂未开放节点可以查看，但不能进入。已通过、可前往、尚未解锁、未走支路、待选奖励和暂未开放均应清楚表达，不只依靠颜色。已完成且有正式脚本的剧情或泉水节点保留只读回顾入口。

节点详情依据现有路线和战役服务显示相邻节点、已知作用及人物入池／获得、泉水恢复等信息。合流处的前序路线是可到达来源，不解释为必须走完每条互斥分支。未走分支一旦离开可选范围即不能回刷；B07及后续展示仍不代表内容已经开放。

待选奖励期间先完成选卡，已获胜分支的其他互斥道路显示为未走支路，合流后继暂未解锁；领取奖励后才按进度显示可前往。旧档如处于 B01 奖励待结算、当前节点为 S02 的恢复情形，S02 在完成选卡前显示尚未解锁。上述状态是界面解释，底层 `available`、保存和战役规则不作改变。
