# 田秀、马三娘与战斗特效复用

日期：2026-10-28。本轮先具体化已经出场的女医者与女匪首，并补充艾玛及两人的战斗表现。她们目前仍使用临时人物肖像和已有战斗角色素材，专属美术与画面尚待制作和用户审看。

## 两个人物与剧情

F03 女医者定名田秀，F07 女匪首定名马三娘。她们的身份、性格、目标、弱点、口吻、合作态度和外观建议记录在[人物档案](../17_人物档案.md)；[`character_profiles.json`](../../assets/data/chronicle/character_profiles.json)保存可供游戏读取的资料。人物页展示姓名、职业、代表台词、人物简介、三类能力和合作态度；人物列表可按姓名和职业称谓查找。其余未具体化人物继续使用现有信息。

S03 写出田秀在鬼市诊治伤者与贾苇索拌嘴，S04 写出马三娘在夺寨之后安排旧部的去留并与贾苇索交涉。完成 S03／S04 仍分别使相关人物入池，不直接赠送；角色 ID、稀有度、等级、技能和入池门槛保持原规则。

旧剧情断点 ID 仍然可用：S03 的开场、医者诊治、小吏清点与街口离开保留 `s03_01`—`s03_04`；S04 的旗落、旧部议论、匪首安排去留和主角看井保留 `s04_01`—`s04_04`。新对白另用稳定 ID，不把旧档断点重新指向无关内容。存档仍以人物 ID 保存，显示名变化不替换已保存的成长或拥有状态。

## 特效与边界

[`authored_battle_effects.gd`](../../scripts/ui/chronicle/authored_battle_effects.gd) 从现有特效场景读取 `SpriteFrames` 和贴图，并复用冰片 PNG；它们作为新战斗画布的表现素材，旧场景的弹幕、碰撞与技能逻辑不进入新战斗内核。治疗、护盾及范围提示也包含按当前战斗事件绘制的图形。

艾玛的法术包括施放、飞行、命中与霜环表现；田秀的治疗、护盾和后台支援有对应反馈；马三娘的扫斩、突刺和援斩使用相应刀光。特效按实际方向、位置和范围组织，暂停与清理跟随战斗状态。技能伤害、范围、消耗、冷却、后台支援及持有加成仍由现有战斗规则决定，本轮不因视觉重做增添新效果。

旧素材由 `effects/wizard/`、`effects/sword/` 与现有冰片图提供；本轮没有新增人物母版或战斗动作，也未将田秀与马三娘的外观建议误记成已生产的立绘。演出素材复用和程序检查不代表最终人物美术已经定稿。

| 现有素材 | 本轮用途 |
| --- | --- |
| 法师 `boom` | 艾玛霜环中心爆发。 |
| 法师 `field` | 治疗、护盾与后台支援的法阵。 |
| 法师 `gathering` | 法术施放与命中。 |
| 法师 `wave` 的 11—16 号 PNG | 飞行魔法；不执行原 `wave.tscn` 中的弹幕逻辑。 |
| `ice_shard.png` | 冰晶飞行物和霜环碎片。 |
| 剑士 `fan`、`slash3` | 马三娘的斩、扫和刺。 |
