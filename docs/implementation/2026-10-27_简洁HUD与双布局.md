# 简洁HUD与双布局

2026-10-27。依据用户“用旧版HUD简单布局，或者两个都保留”的调整。与[兰斯10逐页研究](../design-reviews/2026-10-27_兰斯10界面结构与信息减法研究.md)同轮进行；没有把研究中的主线页面提案全部实施。

## 实际行为

- 新战斗读取原有`GameSettings.hud_layout`。未设置时默认“底部技能栏”，已有选择会沿用；“三行队伍状态带”继续可选。
- 新设定页增加战斗界面选项，暂停页也能切换并保存；同一会话更换显示组件，人物、生命、魔法、冷却、时间和正式存档不会因切换而重建。
- 简单栏采用旧底栏的头像切换与横向技能结构，复用原头像、冷却遮罩组件，按新规则展示至多两项手动技能。当前人物显示血魔与等级、经验细线；本关其他人物显示头像、小血魔条和切换键。主角在后台仍带“主”标识，生命保持可见；阵亡明确标字，无辅助时不显示空位大块。
- 不显示自动普攻／支援的连续计时、后台手动技能、重复经验文字、通用能量槽。技能分别显示未到等级、冷却、缺魔或耗魔。
- 战场上方保留关名与时间，Boss出现时才展开Boss血条。Boss门槛与速胜经验时限在暂停中查阅。短事件提示结束后消失，不再持续显示规则讲解或“其他场域关闭”。
- 1280×720的普通阶段，上部约44像素、简单栏108像素，战场分配约79%高度；旧三行适配截图约63%。这些是布局矩形比例，不是扣除每个图形后的净可视面积。

本轮未改玩法内核、数值、卡池、键位、正式保存结构或原HUD组件源文件。主角仍复用原剑士外观，不能把HUD调整当作最终人物美术完成。

## 文件边界

| 文件 | 职责 |
| --- | --- |
| `scripts/ui/chronicle/battle_hud.gd` | 读取显示设置，装配并切换两种呈现，同步所需高度。 |
| `battle_hud_simple.gd` | 简单底栏，只读当前BattleSession与人物定义。 |
| `battle_hud_team.gd` | 保留上一轮三行显示适配。 |
| `battle_view.gd` | 暂停选择、事件提示与战斗头部信息的显示时机。 |
| `chronicle_pages.gd` | 设定页接入既有HUD选项。 |
| `scripts/tests/chronicle_playable_ui_smoke.gd` | 更新已有真实流程测试，覆盖双布局及资源不变。 |

## 验证

证据目录：[hud-layout](../design-reviews/evidence/2026-10-27/hud-layout/)。

- 必需[headless启动](../design-reviews/evidence/2026-10-27/hud-layout/startup.log)通过。
- [真实渲染UI流程](../design-reviews/evidence/2026-10-27/hud-layout/ui-rendered.log)通过：两关真实攻击、纯键盘移动／切人／技能／暂停、关间装备、剧情入队和结算；新增简单栏默认、主角后台生命、缺魔、阵亡、双布局设置保存和暂停切换不改资源／冷却检查。
- 15张截图覆盖1280×720、960×540、1920×1080；简单栏覆盖三种尺寸，三行版另检查960×540适配。
- [完整页面夹具](../design-reviews/evidence/2026-10-27/hud-layout/ui-fixture.log)通过。日志里的`/proc`写入失败是原夹具的故障注入，非HUD失败。
- [既有Graphify受保护更新](../design-reviews/evidence/2026-10-27/hud-layout/graphify.log)已执行；当前安装仍无GDScript提取器，缺169个运行脚本，更新候选被拒绝、原图保留并标为过期。
- 研究图的哈希、尺寸、HTML图片路径和脚本语法另做静态校验。当前CUA没有可用浏览器，因此没有宣称HTML对照板完成浏览器视觉验收；Godot截图已经实际渲染和查看。

本轮没有重复运行未改动的整套战斗数值测试；规则与保存的既有66项结果见前一轮记录，不冒称本轮新测。未提交、推送或发布。
