## 本轮规则

| 来源 | 镜头取景与安全路径 |
| --- | --- |
| 普通／重型小怪 | 其正伤害预警和持续危险不独立触发镜头平移、缩放或安全点搜索；既有预警与伤害仍然生效。 |
| 场域精英／Boss | 抽卡、装备场域精英及 Boss 保留既有危险取景和 Boss 震动行为，不给精英新增震屏。确属存活精英或 Boss 的代理攻击按实际来源处理。 |
| 普通召唤兵 | 不因父级是精英或 Boss 就提升镜头优先级。 |
| 混合危险 | 只有精英／Boss 危险会触发相应安全点搜索；搜索时普通小怪已生效的危险仍参与路线否决，不独立扩张取景框。 |
