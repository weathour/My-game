# 战场比例与三角头像HUD

日期：2026-10-27。本轮调整及自动化复查已完成，战斗画面与遭遇节奏仍需实玩审看。

## 用户反馈与问题

用户指出战斗中人物与怪物大小失配、地图太小，并要求恢复旧版底部三个头像的三角排列。此前[简单HUD与双布局](2026-10-27_简洁HUD与双布局.md)虽然复用了旧头像等组件，实际排列是横排；其截图和验证只说明当时的实现。

调整前参考量测显示：原剑士可见身体约93、法师约50、骷髅法师约130.65世界单位。素材透明空白和临时缩放使它们在同一战场的视觉比例失配。

## 实施内容

- 新增 `scripts/battle/battle_space.gd`，将共享战场从1120×630扩至3200×1800。相机以1280×720基准视野跟随当前角色，HUD覆盖全幅战场，不再挤占战场高度。
- 场域位于 `(440, 320)`、`(2760, 320)`、`(440, 1480)`、`(2760, 1480)`，从墙体位置向内移动；边界、场域及小地图共用战场几何。普通刷怪围绕当前交战区，Boss和额外精英也在角色附近出现，避免扩大地图后在远处空等。
- 沿透明素材的实际身体边界和脚底标定比例：人物待机／跑步统一为72世界单位，普通人形怪64—68、史莱姆32、精英92—96、Boss 112；脚底对齐地面。原有角色、怪物和地图素材继续复用，主角仍为旧剑士外观，未新增地图障碍物碰撞。
- 默认HUD恢复三角头像：当前角色居中抬高，前后切换目标位于左右下方，切人有短动画；单人和两人不重复头像，阵亡者头像仍可辨识但切换时跳过。三行版仍可选。HUD绘制顺序已调整，怪物不会盖住状态面板。

血魔、技能、经验、切换规则以及伤害和波次时序未改变。扩大世界和近场刷怪会影响遭遇节奏，自动化结果不能代替实玩平衡判断。

- `chronicle_playable_ui_smoke`：**PASS，failures=0**，实测前两关输入、暂停、双布局和结算流程。

## 限制

这些测试和截图不等于用户已验收画面，也不能证明扩大世界后的战斗平衡。后续需实玩确认移动、刷怪与遭遇节奏；完整白门楼、其余人物机制与最终主角造型仍未完成。
