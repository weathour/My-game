# 对白历史与滚轮回看

日期：2026-10-28。本轮按用户要求接入当前剧情段的只读对白历史，并完成专项和既有剧情流程回归。

## 交互与范围

首玩剧情和已完成剧情的只读回顾均可使用历史对白。鼠标上滚或“历史对白”入口打开列表，当前舞台保留并暗化；已显示的对白按叙事顺序列出发言人或旁白，当前句只显示已经显现的部分，未读后文不提前出现。打开面板暂停当前句打字，关闭后返回原句和已显示位置。

上滚打开时定位到最新，继续上滚浏览更早内容；下滚浏览，滚到底后再次下滚返回。Esc、右键、“返回对话”、Enter 和 Space 均只关闭历史，不推进当前对白。PageUp 可打开历史；打开后 PageUp／PageDown／Home／End 用于浏览。历史条目不可跳转，也不重复执行事件结果。

历史不写存档，不修改正式剧情断点，也不触发入队、开池、奖励、恢复或路线推进。调整窗口时保留本次打开状态、滚动位置和打字进度；正式存档 schema 不变。读档回到中句时按当前版本脚本重建此前句子，历史范围仅限当前段，不构成跨节点或跨档的全局记录。已有的完成节点整段只读回顾继续保留。

[`chronicle_story_history.gd`](../../scripts/ui/chronicle/chronicle_story_history.gd) 显示只读历史，剧情阅读器根据当前句和已显现字符生成条目；界面重建使用临时阅读快照，并检查事件、句子和首玩／回顾模式，避免将其他阅读状态套入当前段。快照只用于当前界面，不写入正式行军档。
