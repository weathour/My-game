## 保持的边界

- 暂停原因是场景内状态；音乐和 HUD 读取视图，不新增第二套权威战斗状态。
- 敌人身份由当前激活代数区分；同一个 Node 的实例 ID 不能代表不同次出生。
- 伤害队列的等待指标使用墙钟时间，包含暂停时间；分析必须结合暂停状态。完成出队、真正结算与拒绝旧代数分开计数。
- 投射物不能用当前敌人位置补查过去的弹路：那会漏掉已经移开的目标，或误中后来走入旧路径的目标。专项覆盖这两个方向并对照逐帧参考；选择逐步检查，避免维护第二套历史敌人快照。静止弹与方形模型框的圆角交叠也有独立回归。
- 旧 `build_levels` 数值仍会影响合法旧档；旧 `skill_talents` 继续规范化清空。`level_talents` 是独立角色天赋，已有效果与人物页只读展示保留。
- 主线任务/对话 JSON 与战斗关卡数据继续各司其职；没有提前建设第二章引擎或新地图。
