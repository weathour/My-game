# 战斗表现与 HUD 复用

日期：2026-10-27。承接用户纠正：战斗场景、怪物、人物立绘与战斗 UI 可以复用已有设计。新玩法的架构重构不要求重新制作整套战斗美术。

## 实际接入

- B01使用现有 `grassland_3_rgba.png`，B02使用已有grassland_4地图包的整体层图片。保留场景原色；地图包的碰撞／区域脚本没有接入，新核心目前仍是矩形战场。
- 人物直接实例化现有剑士、魔法师、枪手的视觉场景，使用其待机、移动、朝向处理。艾玛使用原魔法师；贾苇索暂用原剑士素材，N卡按职业复用并调色。素材外观不改变人物身份、剧情解锁或技能规则。删除上一批新增的程序绘制人形。
- 怪物使用现有史莱姆、骷髅兵、精英骷髅与骷髅法师视觉场景，保留阴影、行走、受击动画与法师施法姿态。新增、受伤、移除按战斗实体ID同步，不实例化旧敌人AI与伤害脚本。
- 斩击、法术爆发、法阵复用已有特效场景的SpriteFrames，弹体复用已有子弹序列。特效按战斗时间取帧，暂停不推进。像素怪物原来的跨场景命中特效出口关闭，保留本地闪白／受击姿态，避免效果逃出当前战斗视口。
- HUD直接复用 `team_role_status_row.gd`、`switch_portrait_display.gd`、`skill_cooldown_icon.gd`，保留三行队伍栏、原人物头像、HP／MP条、冷却遮罩及经验条的视觉基础。当前人物显示J／K，后台关键技能显示备；无辅助时保留空位，不重复主角。
- 不携带旧切换能量、技能点、技能拖拽换槽、天赋选卡和20波奖励链。仅展示新会话的真实资源与技能冷却。主角切到后台显示待命，辅助后台技能自动；后台普攻没有自动施放提示。
- 战场铺满可用区域，视野在矩形地图内跟随当前人物；右上角缩略图显示视野、当前人物、四角场域与敌人。场域、索敌和伤害仍使用原有1120×630逻辑坐标。小窗口不再为了塞下整张地图缩小人物。

已认可的天下／区域地图、人物页及艾玛大立绘继续保留。这次不生成新图片、不替换已批准的主线界面，不将旧角色人数变回队伍规则。旧战斗组件和素材原文件未改。

## 代码边界

| 入口 | 责任 |
| --- | --- |
| `scripts/ui/chronicle/battle_art.gd` | 集中人物、头像、怪物、地图与特效素材映射。替换最终主角素材只改此处。 |
| `battle_canvas.gd` | 将新战斗实体同步到现有视觉场景，负责视野、场域、动画、特效与缩略图；不拥有战斗数值。 |
| `battle_hud.gd` | 将会话状态适配到已有HUD组件，处理空位、前后台、阵亡、耗魔、冷却、经验与尺寸适配。 |
| `battle_view.gd` | 输入与会话驱动、暂停、胜败信号、HUD与画布装配。 |

`BattleSession → 表现适配 → 已有素材／HUD组件`。表现不调用旧Player，不写成长或存档。本轮没有改战斗内核、内容数值或正式存档结构。
