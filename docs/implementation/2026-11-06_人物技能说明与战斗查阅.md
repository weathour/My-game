# 人物技能说明与战斗查阅

日期：2026-11-06

状态：已完成。用户授权应用到全部人物；人物页、关末选卡、整备及战斗内查阅已接入，专项、完整工程和独立包验证通过。

## 调整范围

针对“人物详情看不明白特性、战斗中无法查看 J／K 说明”的反馈，按[人物特性与技能说明调研](../design-reviews/2026-11-06_人物特性与技能说明调研.md)整理信息层次。38 人各有一句玩法概述及少量效果标签；137 条能力分别提供简短说明，主角刀、枪普攻按装备形态区分。效果类别只是帮助理解的标签，不限制人物或指定队伍。

人物能力页先介绍玩法，再列出自动普攻、实际拥有的常规自动技能以及 J／K，随后展示额外机制、后台支援和持有加成。没有 K 技能的人物显示“未配备”；尚未解锁的现有技能则显示其真实状态。艾玛的免费常规自动技“冰星”仍在出场作战部分，回响的次数、时限与触发条件在首层可见。可展开的细节补充刷新、伤害来源及结算边界，不把必要触发条件藏在折叠内容中。

关末选卡的“人物详情”使用同一人物页，保留卡面概述、后台简述以及持有加成的获得／升级预览。整备的后台简述也读取同源内容，避免人物页与整备对同一机制给出不同说法。后台支援须配置且存活，并处于后台；持有加成在人物获得后生效，未配置或阵亡仍保留。

## 战斗中查看

两种战斗 HUD 的 J／K 图标可用鼠标悬停查看所属人物、技能概要、费用、冷却和当前状态；查看本身不暂停战斗。按 Esc 进入“行军暂歇”后，可选择“技能说明”，用键盘选择人物和技能并展开细节；Esc 先返回暂歇，再按 Esc 恢复战斗。人物／技能下拉选单打开时，导航键和 Esc 先交给选单处理；正文滚动随当前焦点和选单状态处理。未配备的技能槽明确显示“未配备”。

说明采用[统一中文文案](../../assets/data/chronicle/skill_information_copy.json)，并由[信息投影](../../scripts/content/skill_information.gd)结合当前人物、技能和战斗状态生成数值，不从旧版长描述反向解析。技能状态变化时更新显示，不逐帧重建说明布局；提示首显及文本尺寸变化时按最新布局定位，保持屏内。概要使用周围、直线等玩家可理解的描述，不直接显示无单位的引擎距离。

本轮只调整信息和查阅入口，不增加技能、改变伤害或魔法规则，也不增加存档字段。自动普攻与自动方向、Q／E 切人、J／K 耗魔关键技能维持既有规则；已获得人物的持有加成和关末奖励规则不变。猎户弓手后台追击冷却说明改按实际支援冷却显示，不改变支援触发。
