# 剧情回顾与只读重播

日期：2026-10-28。本轮按用户要求接入已完成剧情的只读回顾，并完成程序与界面回归。

## 规则与界面

回顾以当前存档的完成记录为依据：节点须已完成，类型为剧情事件或泉水，并有正式剧情脚本。路线详情和行军见闻提供入口；回顾沿用当前版本的背景、立绘、对白和音乐，从首句开始逐句观看，界面明确标识回顾，并提供结束和返回操作。没有正式脚本的路线摘要不作为可回顾剧情。

回顾不推进节点、不触发原剧情提交；不重复获得或升级人物、开启卡池、恢复状态、结算奖励、追加行军日志或写存档，也不修改正常剧情阅读断点。末句不显示会误以为再次加入或入池的结果提示。待选奖励时可以从见闻回顾，已生成候选及已选进度应保持原样。

读取旧档后入口按该档的完成状态重新判断，不建立跨档统一鉴赏记录。回顾每次从头开始，不保存回顾位置；当前不提供逐句浏览的对白历史。正常首玩剧情的断点和结算规则不变。

回顾使用独立 `replay` 页面与推进回调，资格检查同时核对当前档的 `completed`、节点类型和已创作脚本。见闻按该档完成顺序列出可回顾节点；路线保留当前选中的已过节点。窗口改变尺寸时保留本次观看的临时行号，退出回顾后清除；重新进入从首句开始。回顾结束返回原路线或见闻入口，不通过首玩剧情的存档与事件结算回调。
