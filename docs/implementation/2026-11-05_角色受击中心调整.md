# 角色受击中心调整

日期：2026-11-05

状态：实现及检查完成。

## 目标

用户要求将角色判定红点移到角色中间。本轮已让当前操控角色的红点与真实受击中心一起，从脚底锚点移至稳定的身体中部，保留半径 4 个世界单位的小圆。

## 设计范围

- 共用身体高度为 72 个世界单位，受击中心位于脚底锚点上方 36 个世界单位。该中心固定于身体尺度，不跟随动作帧或武器边界晃动。
- 红点、敌方投射物、区域伤害、近战、冲撞、敌方瞄准与镜头避险路径的安全出口判断使用同一受击中心；移动、玩家攻击、拾取和实体间距仍使用原脚底锚点。镜头构图与屏幕边界继续按脚底锚点和完整身体包围盒处理。
- 受击半径、移动速度、伤害数值与战役存档规则未改，不制作新的战斗美术素材；游戏仍沿用既有自动普攻和手动关键技能。
