# 剧情演出与先选卡后剧情

日期：2026-10-28。本轮接通首段事件演出与首关奖励、艾玛剧情的衔接；完整白门楼及章末战斗仍未开放，画面尚待用户审看。

## 演出与文本

S01、S02、S03、S04、S05 和 F01 使用按句推进的剧情页：场景背景叠加透明人物立绘，底部对白框显示人物姓名并突出当前说话者，旁白不显示姓名。支持逐字显现、首击显示整句、继续、跳过和返回路线；人物出入场与场景淡入遵循减动画设置，大字和音量沿用已有设置。末句的事件结果提示独立于人物对白。

S02 写出贾苇索与迷失的西方魔法师艾玛初遇的拌嘴和强拉同行，艾玛明确拒绝并反抗；入队不表示信任或爱慕。S03／S04／S05 将既有叙述分句，F01 说明泉水的恢复与复活。世界成因、人物身世和后续关系未由本轮另作定论。

剧情配置以 [`story_events.json`](../../assets/data/chronicle/story_events.json) 为已创作文本入口，记录稳定句 ID、说话者、文本和画面人物；[`story_catalog.gd`](../../scripts/content/story_catalog.gd) 负责读取与校验，[`chronicle_story_view.gd`](../../scripts/ui/chronicle/chronicle_story_view.gd) 负责显示，正式主线服务负责状态提交。旧 `events.json` 不再使用；尚未创作事件的路线摘要仅作为预览，不等同于完成剧情。

荒道、鬼市和寨中各使用一张本轮由内置 ImageGen 生成的背景，来源、提示词和哈希见[素材说明](../../assets/story/chronicle/README.md)及其链接的清单。人物复用现有常态透明立绘，部分 NPC 使用已有临时肖像；`expression` 目前仅作为数据字段，尚未接入新表情图或姿态映射。使用现有 `camp_signal` 配乐。没有新增配音、剧情选项、CG 或完整对白回看，现有素材覆盖不等于完整演出素材已经完成。

## 首关与保存

新流程先结清首关经验并完成选卡：普通五选二，击败抽卡精英则为五选三。确认奖励后直接进入 S02，艾玛此时尚未加入；完成或跳过剧情后，她才直接获得并入池，不占选卡名额。新流程首关候选没有艾玛，后续再次抽到按重复卡规则升级。B02 奖励确认后也会进入相应的 S03 事件。

这次调整不改变章末规则：B18 仍先完成影响开池的剧情，再生成七选三或七选四的候选；其重要卡保底继续遵守入池资格，章末战斗本身尚未开放。

正式主线仍用 schema 1，新增可选剧情断点，按事件与稳定句 ID 记录当前阅读位置；旧档不含该字段时按空断点处理。剧情推进先提交阅读位置再显示下一句，保存失败保留原句并可重试；返回路线保留断点，完成或跳过统一提交事件结果并清除断点。泉水在事件完成时提交恢复结果。

旧首关延后奖励若仍停在艾玛加入前，会恢复首关选卡并保留抽卡精英收益；旧档已经生成的候选和已选进度不重抽。已完成艾玛剧情的旧档保留既有人物及进度，不为了新顺序回滚历史结果，也不重复赠送艾玛。
