# 人物卡与主线界面重排

日期：2026-10-27。本轮界面调整及自动化验证已完成；实际画面尚待用户审看。

## 方向与范围

依据[兰斯10界面结构与信息减法研究](../design-reviews/2026-10-27_兰斯10界面结构与信息减法研究.md)，重排奖励、编队、行装、天下／路线与菜单，使人物卡、当前选择和地图成为各页主体。框和按钮参考《兰斯10》：墨绿底、旧金细边、局部角饰与酒红主按钮；地图保持苍凉的三国山河。早期 A/B 方案因页游感过强被否决，之后用户明确要求此类框和按钮，先前对金属框、雕花的全面禁用不再适用。

本轮未改变既定玩法：普通关五选二、精英奖励五选三，章末七选三／四，候选至少两张重要人物但不强制选择；首关艾玛直接加入，不占选卡名额。编队为主角与至多两名辅助，关间可从已获得人物中换人，技能达到等级自动解锁。

## 界面调整

- 奖励卡显示人物、获得／升级变化与选择状态；选中整张卡即可选择或取消，人物三类能力与详情集中展示。键盘焦点移动时同步更新说明。
- 编队同页呈现主角与辅助、候选人物及选中人物的前台能力、后台支援和持有加成；小屏人物详情使用独立页面。行装三槽横向排列，下方比较同类装备；已装备与尚未获得直接标注，已获得但未装备者可换上。
- 天下和路线采用地图上下文信息板；路线默认显示当前、前路和最近已过节点，六段总览按需展开。25条普通战斗／事件节点的重复通用摘要仅在地图上隐藏，节点名、前路、行动入口和有实际内容的摘要保留；事件正文仍在事件页面呈现，艾玛与泉水的正文改为简短叙事及必要效果，艾玛事件不再重复显示入池说明。
- 菜单成为独立页面，“返回”回到打开前的页面；长文弹窗可滚动。主要控件保留键盘焦点、可选择与不可用状态。

实现入口包括 `scripts/ui/chronicle/chronicle_portraits.gd`、`chronicle_card.gd`、`chronicle_party_pages.gd` 和 `chronicle_reward_page.gd`，以及主线 shell、主题和页面模块。地图专用的空摘要保存在 `assets/data/chronicle/route.json` 的 `map_summary` 字段中，不替换原事件内容。

## 卡面来源

新增三张生成图集，共26个肖像单元；38条人物目录通过角色映射和普通兵种改色复用对应素材，艾玛沿用原有图片。八张具名三国人物卡参考《火凤燎原》的造型，属于临时设计，并非逐人定稿复刻；高顺替换版已导入。两项参考来自作者官网，一项高顺参考为新浪转载的次级图源，商业参考图不作为游戏运行贴图。图集、生成清单、提示词和来源见[人物卡素材说明](../../assets/ui/chronicle/cards/README.md)。

## 验证与画面

- Godot 4.6.2 的必需 headless 启动通过。
- 旧 `chronicle_ui_smoke` 返回 `CHRONICLE_UI_SMOKE_OK`；一次 `/proc` 写入失败为预期故障注入。
- `chronicle_playable_ui_smoke` 返回 `PASS failures=0`，实际推进前两关，覆盖剧情入队、奖励、关间换装、战斗键盘操作和HUD切换；[流程检查日志](../design-reviews/evidence/2026-10-27/ui-reflow/logs/mygame-reflow-playable.log)随仓库保留，当时15张流程截图留在本地归档及 Git 历史。
- `chronicle_reflow_visual_smoke` 通过：SubViewport 在 960×540、1280×720、1920×1080 生成30张布局截图，检查关键控件位置、选卡、焦点更新、小屏详情与菜单返回；当前[布局目录](../design-reviews/evidence/2026-10-27/ui-reflow/layout/)保留精选。七张奖励及后期人物来自界面夹具，不代表章末或其余人物玩法已开放。
- 全仓文档链接检查及 `git diff --check` 通过。45张截图的路径、尺寸和哈希见[截图清单](../design-reviews/evidence/2026-10-27/ui-reflow/screens.json)，测试和图谱日志位于[本轮日志](../design-reviews/evidence/2026-10-27/ui-reflow/logs/)。
- 已按要求尝试受保护的 Graphify 更新：命令退出码为0，但安装包没有 Godot 提取器，候选图遗漏173个运行脚本，因此被拒绝，旧图保留并标记 STALE。该结果不是 Godot 代码检查失败；当前代码关系仍以源码为准。

保留的界面示例为[出击准备](../design-reviews/evidence/2026-10-27/ui-reflow/layout/preparation-1280.png)和[菜单](../design-reviews/evidence/2026-10-27/ui-reflow/layout/menu-1280.png)。原人物编队与七张奖励夹具图保留在本地归档及 Git 历史，均非实际玩家进度。
