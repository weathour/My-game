# 白门楼人物系统与联动

本轮将白门楼目录的**37 张可收集人物和固定主角**补齐战斗定义、可阅读档案及人物配合，接入新的开池与登场对白。目录完整不等于整章可玩：当前仍只有 B01、B02、B04、B05、B03、B06 六个战斗节点及六件装备；B07 及以后尚未开放。专项和既有流程回归通过，运行范围以[当前状态](../08_当前实现状态与后续重点.md)为准；数值和游玩感受仍需实玩。

人物、技能与效果由 [`combat_catalog.gd`](../../scripts/content/combat_catalog.gd) 和 [`roster_kit_data.gd`](../../scripts/content/roster_kit_data.gd)提供运行数据；[`characters.json`](../../assets/data/chronicle/characters.json)记录人名、目录说明和入池提示，[`character_profiles.json`](../../assets/data/chronicle/character_profiles.json)提供人物页的简介、台词和合作态度。人物详细性格及外观方向见[人物档案](../17_人物档案.md)。技能效果的当前数值以游戏内实际目录为准，均需后续实玩校准。

## 当前联动的主要规则

- 艾玛成功付费施法留下有限法术记录；她在后台时，其他存活编队人物付费技能可消耗记录产生削弱版回响。回响归属艾玛，不继承当前人物的直接攻击附魔，也不递归触发付费施法。
- 田秀的急救治疗全部存活编队成员，溢出治疗转为各自有上限的护盾；后台治疗生命比例最低的人。马三娘入手即可选择保盾的寨风斩，或支付魔法与冷却后用断阵刺消耗自己的部分盾加强攻击；没有盾也可使用。
- 钱绮罗在后台将队友实际花费的一部分魔法分次返给原施法者，前台结账只提前结清已有余额。陆知微让不同编队人物先后成功付费施法时减免后一次费用；先减耗再扣魔，钱绮罗按实际扣除部分计算返还。切换、自动支援和回响不算一次新付费施法。
- 秦雁有有限箭库存，前台直接攻击命中可带动她的后台追射；有箭强化，没箭仍有普通支援。切换到她可花魔法和库存使用齐射；其他队友的成功付费技能可按规则补箭，空切、自动支援和她自己的齐射不会补箭。
- 祝青蘅可施加并有限传播咒伤；同源刷新和传播次数受限，传播不递归。曹军祭师可通过自身技能提前结算已有咒伤。蕾娜守势承接敌击并反击；陶小满的淬刃改变前台直接攻击覆盖；柳晚晴可在上限内延长仍有效的法术记录或淬刃，不补次数。被动效果不是统一增伤，实际目标和作用时机以各技能说明为准。

临时护盾、记录、箭库存、退款账目、咒伤和强化窗口属于本关状态，结束后清理；人物的生命、魔法、阵亡与技能冷却仍按既有跨关规则保存。切换不复制护盾、不刷新资源或冷却；已在场的部分效果按其来源和持续时间结束，不能借附加攻击无限递归。

## 界面、素材与验证边界

人物页分别展示人物机制、前台技能、后台支援和持有能力，并说明未持有预览、实际编队状态以及技能解锁；编队汇总区分封顶前来源、封顶后的持有加成与装备加成。两种战斗 HUD 均显示回响、特制箭、待返魔法、接续、守势、淬刃与个人护盾等相应人物的状态。人物页和编队汇总保留技能说明、支援条件和属性来源。

人物页沿用已有或临时肖像，剧情沿用现有场景背景与常态立绘；本轮没有新制专属人物母版、透明立绘或战斗动作。后半章已有剧情文稿不等于已制作对应战场、完整场景与所有人物事件；首章 15 件候选装备中的新增部分、完整 18 场战斗及章末仍属后续设计与制作范围。角色强度和配合是否有趣须经实际游玩，自动化通过不等于平衡与美术验收。
