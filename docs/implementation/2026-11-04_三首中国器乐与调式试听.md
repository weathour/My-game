# 三首中国器乐与调式试听

日期：2026-11-04。状态：三首离线试听及音频、MIDI 专项检查已完成，主观听审待进行。试听不接入游戏，不改现有 12 首源 MIDI、游戏音乐文件或路由。

## 对照版本

| 版本 | 目的与边界 |
|---|---|
| C | 当前游戏音色作为基线，制作本轮响度匹配副本；原有 C 文件不覆盖。 |
| D1 | 用中国器乐音色重新分配部分声部，保留源音符的音高、起止、力度、节奏和速度信息；D1 MIDI 是源文件的逐字副本。 |
| D2 | 沿用 D1 的乐器分配与处理设置，仅对选定中国器乐旋律骨干做有限音高派生；保留原有时间、力度、速度、鼓、贝司和受保护的吉他 riff。 |

D1 的民族音色分配由制作计划与渲染器执行，普通 MIDI 播放器打开 D1 MIDI 不会自动还原该编制；应以 D1／D2 的渲染音频及对应计划判断声音。D2 不是把整首所有声部强制变成五声音阶，也不应称为已经证明成功的传统曲谱或风格。

C 沿用现有成品及其既有处理，D1／D2 使用同一新混音流程。尤其《Man That You Fear》的原 C 版已有总线压缩，新版本没有；C 与新版本的动态差异不能全部归因于换乐器，调式影响应优先比较 D1 与 D2。

## 目标与交付

保留电吉他、贝司和套鼓的主要推进作用，在不改源曲事件的 D1 中尝试中国器乐声部。D2 按段落、中心音和旋律／和声关系限制音高变化，保留适当的半音张力与原曲骨架；各曲实际音色与改动如下。厂商的 `LUAN` 为阮类标识，具体阮种未确认。

| 曲目 | 中国器乐分配 | D2 音高调整 | 全曲组内目标响度 |
|---|---|---|---:|
| Disposable Teens | 琵琶 508 音、阮类 108 音 | 19 个 G♯ 音符改为 A | −19.46 LUFS |
| Man That You Fear | 二胡 145 音、古筝 371 音 | 83 个选定音符作有限调整 | −24.81 LUFS |
| The Beautiful People | 阮类 198 音、琵琶 1 音 | 100 个 D♯3 音符改为 D3 | −20.81 LUFS |

每首已交付 C、D1、D2 三个完整版本，共九个全曲版本，各有 48 kHz、24-bit FLAC 和 320 kbps MP3；每曲另有 C／D1／D2 三段各 45 秒的短对照及播放列表。响度按同一首曲子内的共同可达目标做静态匹配，三首之间不强制一致；《Man That You Fear》全曲目标较安静。短片段另作组内静态匹配，不能用其绝对响度推断整曲响度。

D1 与 D2 使用相同的器乐分配及中国声部相对骨架增益，不使用总线压缩或限幅。三个 D1 MIDI 均与源文件逐字一致；D2 保持事件数、时间、力度、速度、鼓、贝司和受保护吉他声部。针对被保留伴奏的半音冲突检查没有发现新增冲突；《Man That You Fear》的 10 组相同源音产生不同输出的约束例外已记录，不能据此声称所有动机完全不变。音色与调式是否适合游戏仍需实际听审。

18 个全曲文件的解码有限性、非静音、时长和真峰值检查通过，真峰值均不高于 −3 dBTP；三首 MIDI 差异、分部与处理分别记录在[音频报告](../../design/music-20261104-chinese-trial/reports/)和[试听清单](../../design/music-20261104-chinese-trial/reports/comparisons.json)中。试听文件位于本机 `/home/weathour/音乐/Marilyn-Manson-伴奏学习/中国器乐首轮_20261104`，目录内的试听说明提供播放入口。

## 音源与记录

当前锁定 DSK Music 的 Asian DreamZ SF2，按厂商原名标记 PIPA、PIPA TREM、LUAN、GUZHEN、ERHU、BAN-DI 与 Chinese Percussion；不将这些名称升级为已独立核验的演奏者、录音场地或完整采样链信息。LUAN 的具体阮种未获证实；当前没有可靠的笙或扬琴音源，因此实际分配以渲染报告为准。长音不能仅凭 SF2 样本头中的循环点断言可持续，普通 PIPA 中部分区域可能自然衰减。

DSK 发布者声明其虚拟乐器可免费用于私人和商业用途；该音源不是 CC0，原 SF2 与导出原始采样留在本机缓存，不进入试听包。保留原 C 所用音源与许可的记录，详见[本轮来源说明](../../design/music-20261104-chinese-trial/THIRD_PARTY_NOTICES.md)和[生产目录](../../design/music-20261104-chinese-trial/README.md)。
