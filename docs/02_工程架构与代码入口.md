# 工程架构与代码入口

更新：2026-10-31。运行实现以源码和测试为准，当前迁移进度见[状态](08_当前实现状态与后续重点.md)。

## 目录与入口

- `project.godot` 指定默认主线场景 `scenes/chronicle/chronicle_shell.tscn`。
- `scripts/ui/chronicle/` 构建天下、路线、整备、剧情、见闻、设置和战斗画面；`battle_view.gd` 驱动战斗表现，`battle_canvas.gd` 与相关模块绘制人物、敌人、地面和反馈。
- 标题与说明页面分别由 `chronicle_home_page.gd`、`chronicle_information_page.gd` 构建；菜单及帮助文案位于 `assets/data/chronicle/menu_text.json`。
- `scripts/campaign/` 管理正式战役、进关快照、奖励、路线、剧情状态和保存事务；`scripts/battle/` 处理本关人物运行态、能力、伤害、敌人及关卡节奏。
- `scripts/content/` 定义人物技能、装备与关卡；`assets/data/chronicle/` 保存路线、人物、剧情、反应和地点资料。`assets/`、`scenes/` 与 `effects/` 存放运行资源；`design/` 保存必要的制作输入和来源。
- `scripts/shared/settings.gd` 与 `window_display_manager.gd` 管理设置及窗口；`scripts/audio/music_player.gd` 和相关目录提供音乐播放与主线音频目录。
- `scripts/ui/shared/` 包含 `ui_theme.gd`、`campaign_frame.gd`、`switch_portrait_display.gd`、`skill_cooldown_icon.gd` 和 `team_role_status_row.gd` 等当前游戏使用的公共显示与提示。

数据路径和保存边界见[关键数据流](09_脚本职责树与关键数据流.md)，当前规则见[设计共识](00_当前设计共识.md)。

## 边界与验证

正式战斗使用进关快照和工作副本；成功结果经战役服务提交，失败或退出恢复进关前状态。显示与短音效消费战斗结果，不承担伤害或奖励计算。动态路径、场景引用、资源 UID 和 JSON 内容必须一并纳入资源依赖检查。

保留当前人物表现、敌人动作、音频、设置和存档基础设施所需的共享实现；移除旧入口时不能误删被正式主线调用的资源。读取或迁移现有正式档与设置应使用隔离副本验证，不擦除用户磁盘数据。测试范围和待办见[状态](08_当前实现状态与后续重点.md)与[发布检查](RELEASE_CHECKLIST.md)。
