# 战斗系统与角色机制

状态：前两关与八人物的基础战斗已实现，其余角色与特殊机制待扩展。依据[当前设计共识](00_当前设计共识.md)，范围见[实施记录](implementation/2026-10-27_前两关真实战斗接入.md)；旧版本行为见[运行基线](implementation/2026-10-26_重构前运行基线.md)。

## 主角与两名辅助

固定男主贾苇索代表玩家，默认采用简单、强力的近战攻击。每关的战斗组合为主角加至多两名辅助，允许空位；辅助可以在后台提供部分技能帮助，也可以切换到前台接受操作。主角身份固定，并不禁止直接操控辅助。姓名中的苇索寓意尚未转为具体武器或技能规格，见[人物背景](16_世界背景与风格.md)。

出征随行人数不设上限，取消预选有限名单和容量扩充。每关配置主角与至多两名辅助，关内只在本关配置人物间切换；关间可从全部已获得、存活且符合战役条件的人物中更换辅助，新人物也可在下一关配置。后期部分战役可禁止特定人物进入。换下不删除状态，换回不自动恢复或复活。

新游戏开局只有贾苇索，两个辅助位为空。首关以单人战斗成立，首关战后艾玛直接加入，普通五选二照常提供其他人物或重复升级选择；下一关开始才可能配置辅助和实际切人。空位不生成虚拟人物、后台支援、生命魔法或可切换目标。

## 操作与切换

- 普攻和常规技能自动释放，攻击与技能的方向由系统自动处理；玩家负责移动、切人和关键技能的释放时机。
- 每人最多2个手动关键技能，普通N卡可以只有1个，不要求人人填满两个。按键与切换频率一起评估，保持低操作负担。
- 手动技能按键只调用当前操作角色的关键技能。各角色复用同一组按键，切人后对应当前人物；后台支援自行触发，不另设同时控制所有人物关键技能的快捷键组。
- 关卡内游玩不需要鼠标，键盘即可完成必要操作；不能设计必须用鼠标瞄准或点选落点才能使用的战斗能力。
- 切换只有短暂的公共冷却，沿用各自生命、魔法和技能冷却，不附赠通用无敌，也不刷新技能。
- 特殊角色可以有登场效果；不把反复切人触发登场技设为所有队伍的通用必需循环。玩家可以持续使用主角，也可以按局势切换辅助。

首版采用0.5秒公共切换冷却，WASD／方向键移动、Q／E轮换、J／K关键技能、Esc暂停；索敌在能力范围内优先保留有效目标。它们是可调的实现初值，每人最多2个手动关键技能仍是已定上限。

## 魔法与后台恢复

- 普攻、常规自动技能和自动后台支援不消耗魔法；常规技能主要由自身冷却约束。
- 魔法用于手动关键技能，由当前操作角色消耗自己的魔法，并遵循该技能的冷却。自动施法不会抢占手动关键技能所需的魔法。
- 切到后台后，该人物的技能冷却继续计时，魔法按自身回复属性恢复；恢复量随人物属性和相关加成计算，具体数值待定。
- 生命恢复来自明确的恢复能力、补给或升级回满；切到后台本身不回血，切人不立即回满生命或魔法。

例如法师释放手动关键技能后换回主角，法师在后台继续冷却和回魔，同时按其后台能力提供自动支援。是否值得切回来使用下一次技能，由玩家判断。

只有本关主角与已配置辅助按规则回魔和推进冷却。未配置候补的状态冻结，不因离场时间恢复；重复卡升级、泉水等明确事件仍生效。首版关间菜单不运行战斗时钟，候补不注册进本关计时。

## 生命、魔法和阵亡

- 一般只有当前操作的人物直接承伤，后台人物不作为普通敌人直接攻击的对象。特殊辅助可以通过自身能力代主角承伤；这类例外的条件、范围和代价随人物设计，不成为全队通用的伤害共享。
- 本关实际配置人物的生命、魔法各自独立，切换时使用被切入角色已有的资源。
- 主角死亡判当前小关失败；若正在操作的辅助死亡，立即切回主角。
- 辅助阵亡后仍可依靠主角完成本关。胜利不会自动复活该辅助，后续小关不可使用它，直到遇到泉水或完成整次出征返营。
- 没有恢复事件时，生命和魔法延续到下一小关。泉水可以全员恢复，并复活阵亡辅助。
- 失败撤销当前小关尝试，恢复进关前状态：本关新发生的阵亡随回退撤销，进关前已有的阵亡不会因此消失。

“完全过关”指完成整次出征返营，全员恢复并复活。切换不清除已有临时效果或召唤物；普通临时效果和召唤物在小关结束时清理，生命、魔法、阵亡与技能冷却保留。召唤者阵亡及剧情长期状态的例外另定。

## 每个辅助的三类能力

| 能力 | 角色所处范围与用途 |
| --- | --- |
| 前台能力 | 切到该角色直接操作时的普攻、常规技能、关键技能与特性。 |
| 后台支援 | 本关所选辅助在后台时提供的帮助，是战斗组合的一部分。 |
| 持有被动 | 已获得人物即可提供，即使没有出征也生效；培养等级可以增强收益。不会仅因该人物出征就失去持有收益。 |

每个辅助都按这三类分别设计，不要求三方面同样强，也不把它们混称为“被动”。角色可以提供针对性驱散、代主角承伤、输出、配合或长期培养价值，效果、触发条件、消耗与作用对象逐角色明确。

辅助阵亡后，其后台支援停止；因已获得并培养该人物而产生的持有加成仍保留。主角是否有后台特性及其具体内容尚未确认，不自动套用辅助的完整三类能力结构。

## 连续战斗与成长

局内经验按进关时实际配置人数均分，单人全得、两人各半、三人各三分之一；本关阵亡仍分且不改变分母，候补和战后加入人物不分本关经验。经验物靠近拾取后立即分配，Boss被击败后自动收取剩余经验；活着的敌人不补算。阵亡辅助须泉水或返营复活才能再次上场，换出再换入不能复活。技能随等级自动解锁，不沿用技能点或技能升级选卡。

存活人物因经验或重复卡升级时回满生命和魔法，候补也适用。阵亡人物可以继续获得本关经验和升级，但仍保持阵亡，须泉水或返营复活。升级没有额外刷新技能冷却的已定效果。

玩家可以通过移动决定是否接近四角场域，获取补给或承担额外精英挑战。Boss出现与胜利条件见[关卡规则](05_敌人_Boss_关卡_难度.md)。本轮不新增其他需要频繁暂停的选择层。

## 待讨论边界

下一步设计贾苇索与首关后加入的艾玛的具体攻击、常规技能及最多2个手动关键技能。切换保留临时效果与召唤物，过关清理普通临时效果及召唤物，HP／MP／阵亡／冷却延续；具体技能数值、召唤者阵亡与长期剧情效果另定。

原有伤害、敌人、对象池、暂停与输入组件可用于后续实现评估；代码入口见[工程架构](02_工程架构与代码入口.md)。保留这些技术模块不代表保留旧成长玩法。

## 已确认的辅助功能边界

驱散、复活、代伤等明确特殊功能必须配置为本关辅助，并满足具体人物条件；持有卡牌或留在候补中不提供这些功能。后台被动可自动触发，阵亡则停止。持有加成以数值为主，同类相加，必要上限另定。主角阵亡仍失败，具体复活的目标、时机和次数待角色设计。装备与七项基础属性的作用边界见[成长与装备](04_人物卡_成长与装备.md)。

新操作界面已实现独立HUD演练，真实战斗仍未重构，不能把演练示例数值视为正式战斗行为。
