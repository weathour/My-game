# 剧情场景背景

三张背景由内置 ImageGen 为本项目生成，均为 1672×941 的 RGB PNG；剧情页将人物立绘、对白与界面分层叠加。

- `road.png`：荒道，供 S01 和 S02 使用。
- `market.png`：鬼市，供 S03 使用。
- `camp.png`：寨中，供 S04、F01 和 S05 使用。

人物继续复用现有常态透明立绘，其他人物部分使用临时图；本轮未制作或接入新表情和姿态变体，已有的主角变体也未用于剧情页。画面待用户审看。背景生成提示词见[提示词记录](../../../design/story-20261028/background-prompts.json)，来源、尺寸和哈希见[素材清单](../../../design/story-20261028/background-manifest.json)。
